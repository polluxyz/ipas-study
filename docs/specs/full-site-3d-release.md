# 完整網站3D整合契約

使用者2026-11-04核可：「先幫我將目前所有東西都弄到正式版 我要看完整的網頁」。
本次授權解除全站與485頁局部面板的先前等待核可狀態。

## 範圍

- 正式 `/map/` 與每個概念頁共用真xyz投影、狀態與載入器。
- 當版 `getData()` 是資料入口；不固定舊680或候選582邊。
- 全站唯一概念、21單元、5種正式關係、可選正文輔助層。
- 概念頁原正文、表格、來源、錨點、自我檢核保持原位。
- 局部面板預設收合；有效共享網址可展開；初始1跳。

## 共同契約

依據 `global-concept-map.md`、局部r2 proposal/plan及Root的r3共用載入契約。
衍生單元使用 `Unit.id`。聚合只由原正式邊回算，不新增類型。
正式方向、note、來源及原位置保真。contrasts雙箭頭，正文無箭頭。
例外從當版驗收清單與正式度數計算，不固定8個ID。
網址只分享 `selected`、`hops=1|2`、`body=1`，正文關閉省略body。
其他query及hash保留；非法selected清除3鍵；篩選退出共享狀態。
右拖 `yaw -= dx*.008`；線透明度.22，箭頭.35，選取線.4，hover為1。

## 載入與生命週期

建置產生1份按來源SHA-256命名的JSON，不含完整MD或PDF。
收合面板只載入小型啟動程式；展開後動態匯入互動程式與圖資料。
同文件同版共用pending/cache與AbortController。
收合保留訂閱，晚回應只存快取；卸載移除訂閱，最後持有人中止請求。
BFCache暫停移除訂閱及事件；恢復驗版ready快取，不自動重試已中止載入。
格式、版本、404、離線、取消均保留伺服器文字入口與原表。
每個元件生命週期最多1次人工重試，收合與BFCache不重設。
程式模組下載失敗明確提供「重新載入本頁」，不把同URL的模組匯入當成可靠重試。
未實際命中3個BFCache場景，報告保留未驗證並禁止宣告完整通過。
建置收據納入例外清單JSON，變更此來源會使舊收據失效。

## 預算與驗收

沿用r2：新增JS≤32KiB gzip、初始loader≤2KiB、圖資產≤224KiB。
每頁HTML增量≤4KiB gzip；共用CSS≤6KiB gzip。
4倍CPU、1440/320、15次暖機＋120影格，draw p95≤16ms。
共享資產ready到可操作≤200ms；快取重開≤100ms。
檢查全部概念各1面板及全站各1入口、逐邊與原資料相等。
原生mouse/keyboard及模擬觸控驗320/375/1440、0水平溢出。
實際persisted=true才算BFCache，未命中明記未測。
不把原型或其他版本證據當本次正式驗收。

## 界線

不改content、PDF/text、ID、答案、分析CSV、相依、鎖檔或CI。
不新建儲存鍵；已讀經attempts介面讀取。
不開服務、不push/PR/merge/部署；Root負責常駐服務與整合。
