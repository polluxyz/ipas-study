### 1.1 v2 需求

使用者原話（2026-11-13）：

> 已經考過的考古題 如果想要回去看之前寫的 目錄中要能再次進入
> 然後重考不用說甚麼開啟第二輪之類的 就直接重新開始就好
> 但前一次的紀錄還是要保留下來

v1 的問題：

- 目錄卡片的按鈕寫「開始第 N 輪」，按下只進到輪次清單，不能從目錄直接回看上次作答。
- 畫面處處寫「第 N 輪」「再考一次」「開始第 N 輪」。
- 作答中「重新考」會刪掉這輪的答案。

v2 目標：目錄可直接回看上次作答、直接重新開始；畫面不再出現「輪」；重新開始不刪任何紀錄。

## 4. 使用者可見的行為

### 4.1 網址

| 網址 | 畫面 |
|---|---|
| `/official/` | 目錄（第 4.2 節）。開頁不建立輪次、不改資料；只有按「開始作答」「重新開始」才寫入 |
| `/official/<題組 ID>/`（考古題） | v2「全部紀錄」：已交卷與未交卷紀錄清單、開始或繼續按鈕。開頁不建立輪次、不改資料 |
| `/official/<題組 ID>/?round=<輪次 ID>` | 這一輪的畫面，依第 4.3 節 |
| `/official/guide-S1/`、`/official/guide-S3/` | 指引練習題，直接作答（第 4.5 節） |

題組 ID 沿用現有的 `114-2-S1`、`115-1-S3` 等，網址不變，書籤照舊可用。

### 4.2 目錄 `/official/`

分 2 區：「考古題」4 份、「指引練習題」2 份。卡片樣式和每日題本目錄一致，細節由 Codex 決定。

考古題卡片（v2）依狀態顯示：

| 這份考古題的狀態 | 卡片內容 |
|---|---|
| 沒有任何紀錄 | 「開始作答」按鈕 |
| 有作答中的一次 | 「作答中・已答 A／T」與「繼續作答 →」 |
| 有交卷紀錄、沒有作答中 | 「已交卷 N 次・最近 X 分」、「查看上次作答 →」、「重新開始」按鈕、「全部紀錄 →」 |
| 有交卷紀錄、也有作答中 | 「已交卷 N 次・最近 X 分」、「繼續作答 →」、「查看上次作答 →」、「全部紀錄 →」。不顯示「重新開始」 |
| 只有未交卷紀錄 | 「重新開始」按鈕與「全部紀錄 →」 |

- 每張卡片都有題組名稱、題數、每題 2 分。
- 「開始作答」只用在完全沒有紀錄時。有任何已交卷或未交卷紀錄時一律寫「重新開始」。目錄與全部紀錄頁用同一個規則。
- 「查看上次作答」指同題組 `number` 最大的 `submitted` 輪次，連到 `?round=<該輪 ID>`。不是清單第 1 列（那可能是未交卷紀錄）。「最近 X 分」也取這一輪。
- 「開始作答」「重新開始」按下即建立新的一輪並導向，不跳確認。同一頁連按 2 次只建立 1 輪。另一頁已先完成開輪時，改導向那一輪。2 頁真正同時按下時可能互相覆蓋，這是第 6.2 節已知限制，不另加跨分頁鎖定。
- 開輪失敗（資料損壞、容量不足）時留在目錄並顯示錯誤，不導向。
- 「已交卷 N 次」只算 `submitted`，未交卷紀錄不算。分數照第 4.3 節。
- 卡片不出現「第 N 輪」「開始第 N 輪」。
- 有舊即時紀錄時，加一行「舊紀錄（即時解析）：已答 X／50・答對 Y」。沒有就不顯示。

指引練習題卡片：題組名稱、題數、已答與答對題數（沿用現有算法），以及「開啟題組 →」。

目錄下方加一句說明。v2 改成：「備份包含已保存的作答與已讀紀錄。考古題只備份已交卷的作答，不含紀錄清單與未交卷答案。清除後再匯入，作答與統計會恢復，紀錄清單與回看不會恢復。」

v2 用詞：使用者看得到的文字（含錯誤訊息、讀取中提示、`aria` 文字）不出現「輪」字。「輪次」改稱「作答紀錄」或「紀錄」，「第 N 輪」直接拿掉。程式內部的名稱（`OfficialRound`、`round=` 網址參數、註解）不改。

讀目錄不觸發任何交卷恢復，也不寫入。只有按下「開始作答」「重新開始」才寫入。

v2 頁首說明改成：「考古題每次作答分開計分，交卷過和中途重新開始的紀錄都會保留。」

### 4.3 考古題的一輪

| 這輪的狀態 | 畫面 |
|---|---|
| 未交卷（`open`） | 作答。答案、不確定標記、位置、用時都保留 |
| 交卷中斷（`submitting`） | 交卷重試流程，照每日題本。只在進入這一輪的網址時恢復 |
| 已交卷（`submitted`） | 唯讀回看：成績、每題對錯、解析 |
| v2 未交卷紀錄（`retired`） | 唯讀回看，依第 4.6 節 |
| 找不到或題組不符 | 「找不到這次作答」與「← 考古題目錄」。不建立輪次、不改資料 |

作答畫面：

- 標題寫明題組名稱。v2 不寫「第 N 輪」。
- 題號是原考卷題號，由題目 ID 對照題庫取得。題目失效被略過時，其他題的題號不變。
- 有「← 考古題目錄」連結，離開前保存答案與用時。
- 有「重新開始」按鈕（第 4.4 節），位置不搶作答按鈕。
- 題卡、題號選單、上一題／下一題／不確定／交卷的位置和互動都照每日題本。
- 程式題的圖片照現有題卡顯示。
- 爭議題交卷前只顯示「有爭議・依官方答案計分」中性標籤（現有題卡標籤，不含答案字母）。爭議說明交卷後和解析一起顯示。
- 用時照 `daily-exam-mode.md` 第 5 節：只計頁面可見時的時間，每 15 秒另存 1 次。畫面寫「本次用時」（v2，原「本輪用時」），不寫成考試經過時間。

交卷後：

- 完整 50 題：顯示「答對 C／50 題」與「2C 分／100 分」。
- 有題目失效：顯示「答對 C／T 題・不是正式考試換算」，和每日題本相同。
- 依每日題本的檢討畫面列出每題對錯，可回看解析。
- v2：這份考古題沒有作答中的輪次時，顯示「重新開始」，按下直接開新的一輪。已有作答中的輪次時，改顯示「繼續作答 →」。開輪的寫入仍會重新檢查，不只靠按鈕狀態。
- 檢討畫面另有「全部紀錄 →」。

`/official/<題組 ID>/`（不帶 `round`，v2 稱「全部紀錄」）：

- 有作答中的輪次：顯示「繼續作答 →」，不顯示開新輪按鈕。
- 沒有作答中、也沒有任何紀錄：顯示「開始作答」。
- 沒有作答中、但有紀錄：顯示「重新開始」。
- 下方列出全部已交卷與未交卷紀錄，新的在上。每列：開始日期與時間、狀態、結果、「查看 →」。
  - 已交卷：結果是分數（第 4.3 節的格式）。
  - 未交卷：結果是「未交卷・已答 A／T」，不顯示分數。
  - 作答中的那一輪不列在清單內，由上方按鈕進入。
- 不顯示「第 N 輪」。時間用台北時間 `YYYY-MM-DD HH:mm:ss`。2 列時間字串相同時，後面加「・同時間第 k 筆」。排序用內部 `number`，不靠時間。
- 「查看 →」的 `aria-label` 帶日期時間、狀態與結果。

開新輪不跳確認。按下後建立輪次，導向 `?round=<新 ID>`，從第 1 題開始。同一頁連按 2 次只會建立 1 輪。

### 4.4 作答中重新開始（v2）

- 只在 `open` 輪次的作答畫面出現。`submitting`、`submitted`、`retired` 都不出現。
- 按下後先確認（決定 13）。確認期間暫停定時保存。
- 確認文字：「這次答案會保留為未交卷紀錄，之後只能查看，不計分。重新開始後，從第 1 題作答。」預設焦點在「取消，繼續作答」。
- 取消：不改資料，恢復定時保存。
- 確認：先把畫面上最新的答案與用時併入（畫面上可見的內容；讀取時已被略過的失效題照第 7 節規則，不另外保留），再同一次寫入把這輪改成 `retired`、建立新的一輪。新輪用新 ID，`number` 是同題組最大值 + 1，從第 1 題開始。
- 這輪 0 題作答時也一樣保留成未交卷紀錄，不另外刪除（保持規則單純）。
- 成功後先停掉舊頁的計時與保存，再導向新輪。舊頁的離頁事件不得再寫入舊輪。
- 寫入失敗：保留原輪次，顯示「尚未重新開始」。資料已被另一頁改過時，改唯讀。

### 4.5 指引練習題

- 作答方式不變：選答案後按確認，立即顯示解析，立即寫 `Attempt`，`mode` 仍是 `official:guide:S<科目>`。
- 版面改成題本的一次一題、題號選單、上一題／下一題。題號顏色顯示對錯。
- 題號選單列出全部已確認作答的題，加上第 1 個未答題。舊紀錄不連續時也全部列出。
- 只選選項、還沒按確認，不算作答，不開放下一題。
- 網址帶超出範圍的 `position` 時，改到第 1 個未答題。
- 沒有交卷、成績、輪次、重新開始、不確定按鈕。
- 開頁從第 1 個未答題開始。

### 4.6 未交卷紀錄（v2）

- 從「全部紀錄」進入，網址 `?round=<ID>`。
- 唯讀：題號選單可跳到任一題，看當時選的答案與不確定標記。不能改答案、不能交卷、不能繼續作答。
- 用時固定顯示當時累計的「本次用時」，不再計時、不保存。
- 導覽另寫唯讀分支，不把 `retired` 當成 `submitted` 處理（`submitted` 會揭露答案）。題號選單顯示不確定標記，不顯示交卷按鈕。
- 頂部寫「未交卷・已答 A／T・不計分」，加「全部紀錄 →」與「← 考古題目錄」。
- 決定 11：不顯示正確答案、對錯、解析、爭議說明。理由：沒交過卷的考古題，這裡顯示答案會讓新的一次失去練習效果。要看解析就交卷，或開已交卷紀錄。
- 「不顯示」指可見畫面、朗讀文字與結果樣式。題卡 HTML 原本就帶答案屬性，這不是防查原始碼的機制。
- 開頁不寫入，不觸發交卷恢復。

## 5. 舊紀錄與其他功能

- 舊 `official:<場次>:S<科目>` 的 `Attempt` 不改、不刪、不搬進輪次。
- 錯題本依每題最近一次作答判斷，不看 `mode`。新輪答對後，舊錯題會依既有規則移出待複習清單；舊作答仍保留。
- 進度頁累計所有作答。重考會增加作答次數，已答題數依題目去重。
- 每日題本的「舊紀錄」只彙整 `daily:`、`booklet:`，不受影響。
- 每日抽題排除所有作答過的題目及其同題群組。官方題本身不是每日候選；同題群組連到官方題時，交卷後可能排除該群組的模擬題。這是既有規則，保留。

## 6. 資料格式

### 6.1 `Attempt`

欄位與鍵 `ipas-attempts-v1` 不變。輪次交卷時寫入，`mode` 是 `official-round:<輪次 ID>:S<科目>`。交卷沿用 `saveAttemptBatch`（依固定 ID 去重，拒絕同 ID 不同內容）。

### 6.2 新鍵 `ipas-official-rounds-v1`

```ts
interface OfficialRoundStore {
  version: 1;
  rounds: OfficialRound[];             // 全部輪次，含 4 份考古題
}

interface OfficialRoundQuestion {      // 每日題本題目欄位，去掉 legacyAttemptId
  id: string;
  rev: number;
  choice: Choice | null;
  unsure: boolean;
  ms: number;
  correct?: boolean;                   // 只在交卷後
}

interface OfficialRound {
  id: string;                          // 隨機，每輪不同
  seq: number;                         // 寫入次數，偵測另一頁已更新
  setId: string;                       // 例如 '115-1-S3'；只接受 4 份考古題
  subject: 1 | 3;                      // 必須與 setId 相符
  number: number;                      // 同題組遞增、不重複；v2 只用於內部排序，畫面不顯示
  createdAt: string;                   // ISO 時間
  attemptMode: string;                 // 必須等於 official-round:<id>:S<subject>
  status: 'open' | 'submitting' | 'submitted' | 'retired';   // v2 新增 retired
  position: number;
  questions: OfficialRoundQuestion[];
  submission?: DailySubmission;        // 沿用題本欄位
}
```

不加每日題本的 `current`、`origin`、`assignedQids`。`subject`、`attemptMode` 可推導，但保留以貼近既有交卷介面，驗證器每次核對。

驗證規則（每條都有會失敗與會通過的測試）：

1. `version` 是 1。`id` 非空且不重複。`seq`、`number`、`position` 是有效整數，`createdAt` 可解析。
2. `setId` 屬於 4 份考古題，`subject` 相符，`attemptMode` 相符。
3. 同題組 `number` 不重複；最多 1 輪 `open` 或 `submitting`（`retired` 不算）。
4. 題目不重複，都屬於該考卷的題目 ID（建立時依原題號排序）。帶 `legacyAttemptId` 的題目一律拒絕。
5. `open`、`retired` 不帶 `correct`、`submission`，答案可以不完整。`submitting`、`submitted` 必須有完整答案與 `submission`，`submission` 的固定作答 ID、總題數、答對數彼此相符。

寫入規則：

- 讀寫只經過 `demo/src/lib/attempts.ts`。
- 每次寫入先重新讀 store，比對目標輪次的 `id` 與 `seq`。不符時丟 `DailyConflictError`，畫面改唯讀。只替換目標輪次，其他輪次保留最新內容。
- 保存時不得改變 `id`、`setId`、`subject`、`number`、`createdAt`、`attemptMode`。
- 狀態只能 `open` → `submitting` → `submitted`，或 `open` → `retired`（只經由重新開始）。`submitted`、`retired` 不得再改任何內容。
- 開新輪：重新讀 store，確認該題組沒有 `open` 或 `submitting` 輪次，再寫入。目錄與檢討頁的「開始作答」「重新開始」都走這條。`number` = 同題組現有最大值 + 1。作答紀錄鍵損壞時仍可開新輪（考古題不需要讀作答來排除題目），交卷時才回報錯誤。
- 作答中重新開始（v2）：函式收目前輪次的參照與畫面上最新的輪次內容。重新讀 store，核對 `id`、`seq`、`open`，再在同一次寫入：舊輪改成 `retired`（含最新答案、標記、位置、用時），加入新的 `open` 輪。新輪 `number` = 同題組最大值 + 1。舊輪不刪除。不呼叫每日的 `discardBooklet`。
- 交卷沿用每日題本的順序：先固定作答 ID、狀態改 `submitting`、寫入 `Attempt`、再改 `submitted`。中斷後重開這一輪，用同一批作答 ID 完成，不重複寫入。
- 損壞或版本未知：顯示錯誤，不覆寫，不建立輪次。
- 回看只讀，不寫入。
- 不需要遷移：新鍵不存在時視為空 store。v2 只新增狀態值，v1 的資料不用改就是合法的 v2 資料，所以 `version` 維持 1（決定 10）。
- 退版與舊分頁風險：v2 寫出 `retired` 後，退回 v1 程式，或部署前就開著、還在跑 v1 程式的分頁，都會把整個 store 判為損壞（4 份考古題都受影響），顯示錯誤、不覆寫。資料不會遺失，重新載入 v2 頁面即恢復。v1 分頁的保存失敗只顯示錯誤，不一定改唯讀，使用者可能以為還在作答。對策：部署後提醒使用者重新載入所有考古題分頁；V1 驗收用 v1 建置實測。不承諾「可隨時退回 v1 繼續使用」。
- 容量不足時顯示錯誤，保留原資料。不自動刪除歷史輪次。
- 交卷入口拒絕 `retired`，不寫 `Attempt`。
- 重新開始時 `latest` 的 `seq` 必須等於 `expected.seq`，重讀到的輪次必須仍是 `open`；`latest` 帶 `correct` 或 `submission` 拒絕。

多分頁的界線：`seq` 比對能擋住先後發生的舊頁保存。2 頁在同一瞬間讀寫，仍可能互相覆蓋。這和 `daily-exam-mode.md` 決策 6 相同，不另外處理。

### 6.3 備份與清除

- 備份檔維持第 1 版。`official-round:` 的 `Attempt` 照常匯出與匯入。輪次清單不進備份。
- 清除資料時一併移除 `ipas-official-rounds-v1`。
- 錯題本頁的備份說明加上「不含考古題輪次」。v2 改成「不含考古題的紀錄清單與未交卷答案」。考古題目錄也有同樣說明（第 4.2 節）。

## 7. 例外

| 情況 | 處理 |
|---|---|
| 另一頁已更新這一輪 | 本頁改唯讀，提示重新載入 |
| 另一頁已開新輪或重新開始 | 本頁下次保存時目標不存在或 `seq` 不符，改唯讀 |
| 清除資料後，舊頁還開著 | 舊頁下次保存時目標不存在，改唯讀，不重建輪次 |
| 題目有效的判斷 | 題組、科目、ID、版本都相符就有效。已驗證題與爭議題都有效。每日的有效題函式只接受模擬題，不可共用 |
| `open` 輪次的題目在建置後改版或移除 | 略過並提示，T 扣除該題。題號仍是原題號 |
| `submitting` 輪次的題目失效 | 沿用固定的交卷內容完成交卷，不重算 |
| `submitted` 輪次的題目失效 | 保留當時的題數與分數。該題只標示「解析不可用」 |
| `open` 輪次全部題目失效 | 不能交卷。提供「重新開始」 |
| v2 `retired` 輪次的題目失效 | 該題只標示「題目已更新，無法顯示」，其他題照常顯示 |
| 瀏覽器容量不足 | 顯示錯誤，保留原輪次 |
| 作答紀錄損壞或版本未知 | 輪次照常開新輪、作答與回看。交卷寫入失敗時保留輪次並顯示錯誤 |
| 匯入的作答含 `official-round:` | 只補 `Attempt`，不建立或修改輪次 |

## 10. 測試策略

單元測試（Vitest，不連外網）：

- store 驗證：第 6.2 節驗證規則 1–5 每條各有會失敗與會通過的案例。v2：`retired` 不完整答案通過；`retired` 帶 `correct` 或 `submission` 拒絕；1 輪 `open` 加多輪 `retired` 通過；未知狀態拒絕。
- 開新輪：已有 `open` 或 `submitting` 輪次時拒絕；`number` 遞增；其他題組的輪次逐字不變；作答紀錄鍵損壞時仍可開。
- 保存：`seq` 過期、輪次已刪都拒絕且 store 不變；只替換目標輪次；改固定欄位拒絕；`submitted` 改答案拒絕。v2：`retired` 改任何欄位拒絕；一般保存不能把 `open` 改成 `retired`。
- 交卷：3 個階段各中斷 1 次，重開後完成，`Attempt` 數量與 ID 不重複。
- v2 作答中重新開始：舊輪改 `retired` 與建立新輪在同一次寫入；舊輪保留最新答案、標記、位置、用時；新輪新 ID、`number` 為最大值 + 1、答案全空；`submitting`、`submitted`、`retired` 拒絕；`seq` 過期拒絕且 store 不變；`Attempt` 逐筆不變；其他題組輪次逐字不變。
- v2 已有 `retired` 時仍可開新輪；`number` 跳過 `retired` 用過的值。
- v2 畫面純函式：目錄卡片 5 種狀態的文字與連結；「已交卷 N 次」不算 `retired`；「查看上次作答」指最近交卷的一輪；全部紀錄清單含 `submitted` 與 `retired`、新的在上、不含 `open`；所有畫面文字不含「輪」字。
- 有效題：已驗證題、爭議題有效；版本改變、移除、題組不符無效。
- 失效規則依狀態：`open` 略過並扣 T；`submitting` 沿用固定內容；`submitted` 分數不變；全部失效不能交卷。
- 原題號：略過題目後，其他題的題號不變。
- 計分：50 題全對 100 分；失效 1 題時顯示 C／49。
- 舊紀錄：舊 `official:` 作答不出現在輪次；舊作答繼續參與錯題判斷。
- 清除資料移除新鍵；匯入不建立輪次。
- 容量：用合成資料量測 50 輪時的資料量與保存時間，記入 plan（不設門檻，供日後判斷）。v2 另量 50 交卷加 50 未交卷（含 0 題）的混合資料。這是記憶體替身的數字，不是使用者瀏覽器的上限。
- v2 交卷函式收到 `retired` 拒絕，`Attempt` 逐筆不變。
- v2 重新開始：`latest.seq` 不符、`latest` 帶 `correct` 拒絕且 store 不變。

瀏覽器測試（Playwright，隔離環境，不碰使用者資料）：

- `/official/`、題組頁開頁不建立輪次，store 前後逐字相同；有 `submitting` 輪次時，讀目錄不觸發恢復。
- 開 115-1 科 3 第 1 輪：沒選答案不能下一題；選單逐題增加；交卷前看不到正確答案標示、對錯、解析、爭議說明；Enter 不揭露答案；朗讀文字不含結果；答完 50 題交卷；顯示分數；交卷後焦點正確；重新整理後仍是檢討畫面；瀏覽器返回快取不復活作答畫面。
- 爭議題：交卷前只有中性標籤，交卷後有說明，照官方答案計分。
- 中途離開再回來：答案、標記、位置、用時保留。
- v2 v1 形狀資料：`open`、`submitting`、`submitted` 混合的 store 升到 v2，讀目錄逐字不變，可續答、恢復交卷、回看。
- v2 舊網址：重新開始後回到舊輪網址是唯讀未交卷紀錄；離頁事件不改 `retired`。
- v2 作答中重新開始：取消不改資料（含暫停期間的定時保存）；確認後新輪第 1 題、答案清空；舊輪成為未交卷紀錄，答案與確認前畫面相同；成功後舊頁不再寫入舊輪；寫入失敗顯示「尚未重新開始」。
- v2 未交卷紀錄：從全部紀錄進入；唯讀；可跳任一題號；看得到自己的選擇與不確定標記；用時不增加；看不到正確答案標示、對錯、解析、爭議說明；開頁與停留超過 15 秒後 store 逐字不變。含 0 題與全部題目失效的紀錄。
- v2 目錄：交卷後卡片有「查看上次作答」「重新開始」「全部紀錄」；按「查看上次作答」到最近交卷的檢討；按「重新開始」直接到新一輪第 1 題，不跳確認；連按只建立 1 輪；目錄開頁 store 逐字不變。
- v2 交卷後重新開始：第 1 次可回看且分數不變；有作答中的一輪時，檢討頁顯示「繼續作答 →」。
- v2 全頁文字：目錄、全部紀錄、作答、檢討、確認視窗、錯題本備份說明的可見文字都不含「輪」字。
- 同一頁連按開輪只建立 1 輪；另一頁先完成開輪後，本頁按開始改導向既有那輪。不驗 2 頁真正同時按下（第 6.2 節已知限制）。4 份題組交錯保存互不影響。
- 2 個分頁：一頁重新開始，另一頁保存時改唯讀。清除資料後舊頁保存改唯讀。
- 指引練習題：作答後立即顯示解析；只選未確認不開放下一題；題號選單顏色正確；非連續舊紀錄全部列出；網址越界改到第 1 個未答題；重新整理後還原。
- 回歸：每日題本、一般測驗、單題頁的 smoke 全過。既有 smoke 裡「`/official/115-1-S3/` 即時解析」的案例改用指引練習題，不刪案例。

## 11. 界線

- Always：讀寫只經過 `attempts.ts`；交卷才寫 `Attempt`；實測用隔離瀏覽器。
- Ask first：加倒數計時；指引練習題改交卷制；把舊即時紀錄轉成輪次；備份改第 2 版；跨分頁鎖定。
- Never：改寫或刪除既有 `Attempt`；刪除輪次（v2：任何流程都不刪）；自動刪除歷史輪次；未交卷紀錄顯示正確答案或解析（決定 11 核可前）；畫面顯示「第 N 輪」；讀取或修改使用者瀏覽器的資料；把官方題放進每日題本；排除爭議考古題；靜默清除無法解析的資料。

## 12. 可驗證的成功條件

1. 4 份考古題都能開輪次、作答、交卷，交卷後顯示成績與逐題檢討。完整 50 題時是 100 分制。
2. 交卷前畫面上看不到正確答案的標示、對錯、解析與爭議說明（和每日題本相同）。
3. 每份考古題可有多輪已交卷輪次，各自分數正確，都能回看；題目失效後已交卷的分數不變。
4. 重新整理、離開再回來，未交卷輪次的答案、標記、位置、用時都不變。
5. v2：作答中重新開始經確認，舊輪保留成未交卷紀錄、答案不變；`Attempt` 逐筆不變；舊頁不復活舊輪。
6. 舊 `official:` 作答逐筆不變，繼續參與既有錯題判斷。
7. 指引練習題仍即時解析，版面有一次一題與題號選單，選單只開放到第 1 個未答題。
8. 每日題本、一般測驗、單題頁行為不變。
9. CI 全綠；瀏覽器測試全過；截圖涵蓋 3 種寬度與亮暗色。
10. 4321 重建後，協調者用隔離瀏覽器走完開輪、交卷、回看、重新開始。
11. v2：交卷過的考古題，從目錄一步進到上次作答的檢討，一步重新開始。
12. v2：`/official/` 底下與錯題本備份說明的可見文字不出現「輪」字，也不出現「再考一次」「重新考」。
13. v2：已上線的 v1 資料（`open`、`submitting`、`submitted`）不需轉換，照常讀取與作答。
14. v2：v1 建置的頁面讀到含 `retired` 的資料時，保存失敗、store 逐字不變；重新載入 v2 後恢復（V1 驗收用 v1 建置實測）。
