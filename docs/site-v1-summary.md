# 學習網站 v1 一頁摘要

完整內容見 `docs/specs/site-v1.md`（規格）、`tasks/site-v1-plan.md`（計畫）、`tasks/site-v1-todo.md`（任務）。本頁只列要點。

## 做什麼

| 內容 | 數量 |
|---|---|
| 評鑑代碼頁 | 21 頁 |
| 概念頁 | 約 150 頁，互相用 5 種關係連結 |
| 題目 | 考古題 200、指引練習題約 89、模擬題 84 |
| 功能 | 測驗、錯題本（存在瀏覽器，可匯出）、搜尋 |

只在本機看，不公開部署。

## 怎麼確保正確

1. 每題答案對照原 PDF 頁面，記下頁碼。
2. Codex 在看不到答案的情況下自己解題，和官方答案比對。不一致的題目標成「爭議」，網站同時顯示官方答案與爭議說明。
3. 內容由 Claude 寫、Codex 審，同一份內容不自己審自己。
4. 檢查程式自動擋下格式錯誤、斷掉的連結、照抄指引（連續 25 字相同）。

## 怎麼做最快

1. 我先定好資料格式與範例，所有 agent 照同一份範例做。
2. 工作拆成約 60 個任務，每個任務只改自己的檔案，不互相衝突。
3. 用 Orca 同時跑：Codex 最多 10 個、Claude 最多 6 個。一個做完就補下一個。
4. 分工：Claude 寫概念頁、解析、模擬題；Codex 負責網站前端設計與程式、檢查、盲解、審查。

## 順序

```text
1. 地基：資料格式、檢查程式、網站骨架、概念總表 ┐
2. 抽題：200 題考古題 + 指引練習題             ┘ 同時開始
3. 概念頁、題目解析、網站功能                    同時進行
4. 模擬題、交叉審查、最終檢查
5. 你實際操作一次，決定要不要加關係圖
```

時間：未實測，粗估 1 天內。
