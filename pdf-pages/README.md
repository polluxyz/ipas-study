# PDF 頁面圖檔

從原始 PDF 渲染出來的頁面圖，給讀程式題、圖表題使用。本機沒有 `pdftoppm`，Claude Code 的 Read 工具無法直接讀 PDF 頁面，所以先存成 PNG。

檔名規則：`<來源>_<科目>_<PDF 頁序>.png`。頁序是 PDF 閱讀器的頁序，從 1 開始，不是印刷頁碼。

| 來源 | 意思 |
|---|---|
| `114-2`、`115-1` | 考卷場次 |
| `guide1`、`guide3` | 學習指引科目 1、科目 3 |

考卷頁序補 0 到 2 位（例如 `115-1_3_05.png`），指引頁序補到 3 位（例如 `guide3_128.png`）。

4 份考卷的全部頁面都已渲染（2026-10-31，130 dpi）。指引只有部分頁面。需要其他頁時，用 `tmp/pdf_runtime/` 的 PyMuPDF 渲染（不進版控），或等 T02 的 PDF 截圖工具完成。
