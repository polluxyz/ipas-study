# 科目 1 與科目 3 考題和學習指引涵蓋度比較

**結論：兩份官方學習指引有涵蓋主要學習方向，但沒有涵蓋全部考點，也不足以單獨支撐所有實務題與程式題。** 科目 1 的缺口集中於模型評估、生成式 AI 的進階方法及系統部署細節；科目 3 的基礎理論較完整，但驗證流程、調參搜尋與 Python 讀碼需要另外補強。

「超出學習指引」與「超出官方評鑑範圍」要分開判斷。簡章的評鑑內容採用自然語言處理、模型調整與優化、系統集成與部署等廣泛主題，不能因為某個 API 或方法未寫入指引，就直接認定考題超綱。

## 比較依據與判定方式

教材指本專案兩份官方學習指引，對照 114-2、115-1 的科目 1 與科目 3 公告試題，共四卷、200 題。以下以具體考點比較教材深度，沒有將 200 題逐題做互斥的涵蓋度評級，因此不提供看似精確的「教材涵蓋率」。程式圖片以原始 PDF 核對；判斷缺口時，亦檢查相關章節，不單憑關鍵字是否出現。

頁碼採指引印刷頁碼，例如「3-29」，不是 PDF 閱讀器頁序。評鑑代碼是依考題要求的能力所作的分析歸類，不是官方公布的逐題分類。

兩份指引序文都明示其用途是提供學習方向與準備參考，並非正式教材或題庫。這符合實際對照結果：它們適合當準備架構，仍需搭配考古題與實作範例。

| 判定 | 意義 | 備考處理 |
|---|---|---|
| 已涵蓋 | 教材已有主要定義、比較或原理，理解後可應用於該類考題 | 以教材為主，搭配情境題練習 |
| 有提及但不足 | 有主題背景，缺少考題需要的操作、限制、計算或選型細節 | 針對缺少的那一層補充 |
| 未明確教授 | 相關大主題有章節，但未見具體方法的實質說明 | 另補一份短筆記與範例 |
| 表述需校正 | 教材簡化或用語容易讓考生形成錯誤理解 | 先校正，再複習與做題 |

## 三處容易影響解題的教材表述

### 晚期融合的層級

科1 §3.4，3-77 將晚期融合括註為「特徵層級整合」。這個寫法容易讓人混淆特徵融合與決策融合。

對照 115-1 科1 第50題，考題明確以「各模態分別預測後再整合」定義晚期融合。備考時應掌握這個操作差別：各模態先產生預測、分數或決策，再加權或投票整合。多模態研究綜述也以 decision-based fusion 描述 late fusion。[Multimodal Machine Learning 的融合分類](https://arxiv.org/html/1705.09406v2#S6.SS1)

### 概念漂移與資料漂移

科1 §4.3 正文 4-30、4-31 有分別介紹輸入分布變化與資料背後關係變化；但 4-47 練習題第10題解析，將 Concept Drift 簡寫成資料分布隨時間改變，辨識性不足。

115-1 科1 第48題要求辨認的是：輸入特徵分布沒有明顯改變，但特徵與目標的關係已改變。應用下列區分複習：

- 資料漂移：輸入分布 `P(X)` 改變。
- 概念漂移：輸入與目標的條件關係 `P(Y|X)` 改變。

此處依指引正文與考題的具體條件理解，不宜只背練習題解析的簡寫。

### Z-score 不會把任意分布變成常態分布

科3 §5.1，5-7 把 Z-score 描述成轉成平均值 0、標準差 1 的「常態分布」。應校正為：在標準差非零時，以 `z=(x-平均值)/標準差` 做尺度轉換；原資料若偏態，標準化後仍可能偏態，也沒有保證全部數值落在 -3 到 3。這可由公式及 [StandardScaler 的定義](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html)理解。

這個區分與 115-1 科1 第38題，以及 114-2 科3 第48題、115-1 科3 第46題對標準化與縮放的考法有關。

## 兩次考試呈現的準備需求

114-2 已有 Attention Collapse、WGAN、ARIMA 殘差、DBSCAN 索引，以及 NumPy／PyTorch／Keras 讀碼，表示「只讀學習指引不夠」並非 115-1 才出現。

115-1 則更明顯要求把多個概念串成完整決策：例如在延遲、資料量、資源與隱私條件下選擇部署方式，或從一段程式判斷資料洩漏、增強副作用與更新順序。這些是本次兩卷對照的觀察，不能據此保證下一次各主題的出題比例。

科3的附圖程式題在 114-2 為第38至50題，115-1「程式題」區段為第40至50題。其中仍包含可用概念解答的題目；反過來，115-1 第20題雖在前面的選擇題區段，也要求理解 PyTorch 的 API 行為。因此不能只按試卷區段決定是否需要程式準備。

| 優先順序 | 補強內容 | 達標方式 |
