# 學習指引覆蓋分析：考題 vs 教材（主報告）

比對範圍：114-2、115-1 兩次考試的科目 1、科目 3，共 4 卷 200 題，對照兩本官方學習指引。
整併日期：2026-10-29（115/10/29）。
來源：原 Claude 關鍵字分析，加上 Codex 的 `analysis/教材涵蓋度比較.md`（保留為比對來源，本檔為主報告）。

---

## 結論

1. 兩本學習指引涵蓋主要學習方向，但不足以單獨應付所有考題。缺口集中在三類：驗證流程細節、生成式 AI 與部署的具體機制、Python 讀碼。
2. 落差最大的是科目 3 程式題。指引全書沒有任何程式碼，但 114-2 科3 第 38–50 題、115-1 科3 第 40–50 題都要讀圖中的程式或執行結果。115-1 科3 第20題雖在選擇題區段，也要懂 PyTorch API 行為。
3. 科目 1 的部署、維運、LLM 微調、Agent 主題，指引有背景章節（3-28、3-29、3-59、3-64、5-14 至 5-21），但沒有教到考題要的操作層級。不能說「指引沒寫」，應說「寫到方向，沒寫到做法」。
4. 兩科互相借用內容。科目 1 會考只在科3 指引展開的 ML 觀念（XGBoost、多重共線性、SMOTE、維度詛咒、聯邦學習）。科目 3 會考只在科1 指引出現的 LoRA、RAG、AutoML。兩本都要讀。
5. 有 5 處教材寫法容易誤導解題：科1 3-77 晚期融合、科1 4-47 概念漂移解析、科3 5-7 Z-score、科3 5-21 Recall 公式、科3 4-13 R² 範圍。詳見第 3 節。
6. 指引練習題多為一行定義題；實際考題是帶數字的情境題。練習題全對，不代表考試能過 70 分。

## 方法、判定標準與限制

### 判定標準

| 判定 | 意義 | 備考處理 |
|---|---|---|
| 已涵蓋 | 指引有主要定義、比較或原理，理解後可解題 | 以指引為主，搭配情境題練習 |
| 有提及但深度不足 | 有主題背景，缺少考題要的操作、限制、計算或選型細節 | 只補缺少的那一層 |
| 未明確教授 | 相關大主題有章節，但沒有這個方法的實質說明 | 另寫短筆記與範例 |
| 教材表述需校正 | 指引的簡化寫法容易造成錯誤理解 | 先校正，再複習做題 |

### 範圍與用語

- 「未明確教授」是指「超出學習指引」，不是「超出官方評鑑範圍」。正式範圍以 `text/brochure_115.txt` §2.5 為準。§2.5 只列評鑑內容名稱（例如 L21302 AI 技術系統集成與部署、L23304 模型調整與優化），範圍很廣。指引沒寫到某個方法，不能據此認定考題超綱。
- 兩本指引序文都說明它們只提供學習方向與準備參考，不是正式教材或題庫。
- 頁碼一律用指引的印刷頁碼（例如 3-29），不是 PDF 閱讀器的頁序。
- 評鑑代碼是依「這題要考生會什麼」所做的分析歸類，不是官方公布的逐題分類。

### 證據來源

- 題目文字：`text/` 下的 4 份考卷文字版。
- 程式題圖片：Codex 已看過原始 PDF 頁面。114-2 科3 PDF 第 10、11、14–19 頁；115-1 科3 PDF 第 11–18 頁。具體發現已併入第 2.4 節與第 5 節。
- 答案：115-1 試卷答案欄排在每頁左側，本次對照 PDF 文字版的頁首答案欄確認（例如 115-1 科3 第34–37題為 D、D、B、A）。
- 指引內容：本次整併時逐項回查 `text/guide_科目1.txt`、`text/guide_科目3.txt`，以頁尾印刷頁碼定位。

### 舊版統計的限制

舊版用 158 個關鍵字考點做粗分類：約 35 個 0 次命中、約 27 個 1–3 次、約 96 個 4 次以上。舊版因此寫「約 4 成考點沒寫到或只提一句」。這個數字有 3 個限制：

1. 它是關鍵字命中的分類結果，不是 200 題逐題涵蓋率。不能換算成考題占比，也不能拿來推估分數。
2. 部分 0 次命中的關鍵字只出現在干擾選項，不是該題考點。例如 Global Average Pooling、Training-Serving Skew、Dying ReLU、MPC、Faiss、浮水印（見第 6 節）。
3. 部分 0 次命中是因為指引用了別的詞。例如標籤偏差在 6-15 稱為「製程偏誤」，抽樣偏差稱為「來源偏誤」。

本報告不再提供整體涵蓋百分比，改用第 1、2 節的逐項判定。

## 3. 教材表述需校正

### 3.1 晚期融合的層級（科1 §3.4，3-77）

- 指引原文：「晚期融合（Late Fusion，特徵層級整合）」。
- 問題：容易把特徵融合與決策融合混在一起。
- 校正：晚期融合是各模態先各自產生預測、分數或決策，再加權或投票整合。115-1 科1 第50題就是用「分別進行預測後再整合結果」定義晚期融合，答案 D 正是把晚期融合誤寫成「輸入階段整合特徵」的選項。
- 依據：多模態綜述把 late fusion 歸為 decision-based fusion。[Multimodal Machine Learning 的融合分類](https://arxiv.org/html/1705.09406v2#S6.SS1)

### 3.2 概念漂移的定義（科1 §4.3，4-47 練習第10題解析）

- 指引正文 4-30、4-31 有分開介紹資料漂移（輸入分布改變）與概念漂移（資料背後關係改變）。
- 但 4-47 練習第10題解析把 Concept Drift 寫成「資料分佈隨時間改變」，與資料漂移分不開。
- 校正：
  - 資料漂移：輸入分布 `P(X)` 改變。
  - 概念漂移：輸入與目標的關係 `P(Y|X)` 改變。
- 115-1 科1 第48題正是「特徵分布沒變、但特徵與標籤的關聯變了」，答案 C 概念漂移。以正文與考題為準，不要背練習題解析的簡寫。

### 3.3 Z-score 不會把資料變成常態分布（科3 §5.1，5-7）

- 指引原文：「將數值轉換為平均值為 0、標準差為 1 的常態分佈」。
- 校正：Z-score 是尺度轉換，`z = (x − 平均值) / 標準差`，標準差須非零。原本偏態的資料標準化後仍然偏態。它也不保證數值落在 −3 到 3。
- 相關考題：
  - 115-1 科1 第38題選項 B「Z-score 標準化使數值落於約 [−3, 3]」是錯的；999°C 的錯誤值要刪除或用中位數填補（答案 D）。
  - 114-2 科3 第48題、115-1 科3 第46題考標準化與縮放的效果。
- 依據：[scikit-learn StandardScaler](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html)

### 3.4 Recall 公式的分母印錯（科3 §5.3，5-21）

- 指引印刷式：`Recall = TP / (TP + FP)`（見 `pdf-pages/guide3_155.png`）。
- 問題：分母 TP+FP 是 Precision 的分母。同頁的定義「實際正類樣本中，被正確預測為正類的比例」才是 Recall。
- 校正：`Recall = TP / (TP + FN)`。分母是所有實際正類。
- 解題影響：考題常用混淆矩陣算 Recall，照印刷式算會得到 Precision 的值。
- 依據：[scikit-learn recall_score](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.recall_score.html)

### 3.5 R² 的範圍（科3 §4.2，4-13）

- 指引 4-13 寫「R² 範圍在 0~1」。
- 問題：同一本指引 5-24 寫 R² 可以小於 0，兩處互相矛盾。
- 校正：R² 最大是 1，沒有下限。模型比「一律預測平均值」還差時，R² 小於 0。在訓練資料上用含截距的最小平方法擬合時，R² 才落在 0 到 1。
- 解題影響：看到驗證集 R² 為負，代表模型比常數預測還差，不是算錯。
- 依據：[scikit-learn r2_score](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.r2_score.html)

## 7. 練習題與實際考題的落差

| 項目 | 學習指引練習題 | 實際考題（115-1） |
|---|---|---|
| 題數 | 科1 30 題、科3 40 題 | 每科 50 題 |
| 題型 | 一行定義題，例如「邏輯迴歸假設目標變數服從哪種分佈？」 | 情境題，題幹 3–5 行，帶具體數字 |
| 能力 | 認得名詞 | 判斷某情境下最適合的做法、找出錯誤原因 |
| 程式題 | 0 題 | 科3 11 題 |

115-1 比 114-2 更常要求把多個概念串成一個決策。例如在延遲、資源、隱私條件下選部署方式，或從一段程式找出資料洩漏與更新順序錯誤。這是兩卷對照的觀察，不能保證下一次各主題的出題比例。

## 8. 補強優先順序（科目 1 ＋ 科目 3）

依「兩科共用程度 × 指引落差 × 出題頻率」排序。

| 順序 | 補強內容 | 達標標準 | 兩科重疊效益 |
|---|---|---|---|
| 1 | 評估與驗證：混淆矩陣、ROC／PR／F1、不平衡、資料洩漏與 Pipeline、分層驗證、Rolling Window Validation | 能說明某指標或切分方式為何誤導，並修正前處理流程 | 高。科1 第8、9、37、41 題與科3 第27、44、45 題共用 |
| 2 | Python 讀碼：NumPy、scikit-learn、PyTorch、Keras | 能辨認資料形狀、輸出與損失、凍結範圍、`backward()`／`step()` 順序、`cv` 預設行為 | 主要是科3；科1 第32題也考 PyTorch 架構 |
| 3 | 調參與模型選擇：Grid／Random Search、正則化、PCA／DBSCAN、模型複雜度 | 能比較方法、算搜尋成本、指出適用條件 | 高。114-2 科1 第36題與兩卷科3 都考 |
| 4 | 生成式 AI：LoRA、SFT 與災難性遺忘、Soft Prompt、RAG 成本與 Hybrid Search、Multi-Agent／ReAct | 能依顯存、知識更新、檢索品質、可靠性選策略 | 中。LoRA、RAG 兩科都考 |
| 5 | 部署與監控：API 傳輸、快取與 Feature Store、斷路器、INT8 量化、GPU 排程、金絲雀與漸進擴量、PSI 與分群監控 | 能從延遲或品質現象找到流程缺陷與下一步 | 主要是科1 |
| 6 | 可解釋性與治理：SHAP（base value、局部／全域）、LIME、Grad-CAM、公平性指標、聯邦學習、同態加密 | 能分辨局部／全域解釋、影像／表格方法、各隱私技術解決的問題 | 高。SHAP、Grad-CAM、聯邦學習兩科都考 |
| 7 | 較專門的延伸：ARIMA 殘差診斷、Stable Diffusion 參數、信用評分卡 IV、WGAN、全景分割 | 知道用途與一句話定義 | 低，最後處理 |

讀法建議：

- 科1 考生先讀科3 指引 §4.2（XGBoost、DBSCAN、樸素貝氏）、§5.1、§5.3（交叉驗證、不平衡、評估指標）、§6.1（聯邦學習）。科3 理論可直接補科1 的數學、評估、分群與正則化缺口。
- 科3 考生讀科1 指引 §3.1（RAG、LoRA）、§4.3（漂移）、§5.1（AutoML）。科1 的 NLP、生成式 AI、部署章節可補科3 的應用背景。
- 先讀通兩科重疊內容，再處理第 7 項的專門延伸。
