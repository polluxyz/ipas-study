## 公式

| 用途 | 公式與符號 | 條件與限制 | 教材與來源 |
|---|---|---|---|
| 迴歸平方誤差 | $\mathrm{MSE}=\frac1n\sum_{i=1}^n(y_i-\hat y_i)^2$；$n$ 為樣本數，$i$ 為索引，$y_i$、$\hat y_i$ 為實際與預測值 | $n>0$；平方會加重大誤差的懲罰 | [均方誤差](/concepts/mean-squared-error/#定義與公式)；科3指引 5-22～5-23 |
| 迴歸絕對誤差 | $\mathrm{MAE}=\frac1n\sum_{i=1}^n\lvert y_i-\hat y_i\rvert$；符號同上，絕對值消除方向 | $n>0$；相較 MSE 較不受極端值主導，仍非完全免疫 | [平均絕對誤差](/concepts/mean-absolute-error/#定義與公式)；科3指引 5-23 |
| 二元交叉熵（補充） | $\ell=-y\ln p-(1-y)\ln(1-p)$；$y\in\{0,1\}$ 為標籤，$p$ 為正類機率，$\ln$ 為自然對數 | 直接代入限 $0<p<1$；真類機率趨近 0 時損失發散，不能把 logits 直接當 $p$ | [交叉熵損失](/concepts/cross-entropy-loss/#二元交叉熵補充)；教材所列 PyTorch BCEWithLogitsLoss |
| 單點輪廓係數（補充） | $s(i)=[b(i)-a(i)]/\max\{a(i),b(i)\}$；$a(i)$ 為同群其他點的平均距離，$b(i)$ 為各外群平均距離的最小值 | 分母非零；$b(i)$ 不是最近外群單點距離；高分表示幾何歸屬較清楚 | [輪廓係數](/concepts/silhouette-score/#同群鄰群與單點分數)；教材所列 scikit-learn 輪廓係數文件 |
| 折扣回報（補充） | $G_0=\sum_{t=0}^{T-1}\gamma^t r_{t+1}$；$T$ 為步數，$r_{t+1}$ 為動作後獎勵，$\gamma$ 為折扣因子 | 有限步可取 $0\le\gamma\le1$；無限期在獎勵有界且 $\gamma<1$ 時保證收斂；一次回報不是期望價值 | [馬可夫決策過程與報酬](/concepts/markov-decision-process/#回報與折扣補充)；教材所列 Spinning Up |
| ε-greedy 選擇（補充） | 唯一最佳動作機率 $1-\varepsilon+\varepsilon/m$，每個其他動作 $\varepsilon/m$；$m$ 為合法動作數，$\varepsilon$ 為探索機率 | $m$ 為正整數，$0\le\varepsilon\le1$；探索也可抽到最佳動作，並列最佳須另定分配規則 | [探索與利用取捨](/concepts/exploration-exploitation/#定義與公式)；教材所列 David Silver Lecture 9 |
| 跨段成效（補充） | $\bar R=\frac1N\sum_iR_i$，$S=\frac1N\sum_i z_i$；$R_i$ 為第 $i$ 段未折扣獎勵總和，$z_i$ 成功為 1、否則為 0，$N$ 為段數 | $N>0$；平均報酬與成功比例不同；折扣平均須另標，評估條件應固定 | [強化學習訓練與成效驗證](/concepts/reinforcement-learning-training/#單段與多段的數字補充)；教材所列 Stable Baselines3 評估文件 |
| 全配對數（補充） | 有方向 $N_o=n(n-1)$；對稱去重 $N_u=n(n-1)/2$；$n$ 為樣本數，$N_o,N_u$ 為點對數 | 均排除自身；第二式須距離對稱且每對只留一次；固定維度時平方級，有限樣本加倍不恰為四倍 | [近鄰搜尋與距離索引](/concepts/neighbor-search-index/#全配對計數補充)（計數）、[近鄰搜尋與距離索引](/concepts/neighbor-search-index/#4816-筆的直接列舉補充)（直接列舉）；教材所列 Python itertools 與逐對列舉 |

## 指標怎麼選

| 條件 | 選擇與查核 | 限制 | 教材與來源 |
|---|---|---|---|
| 類別標籤與分類機率 | 用交叉熵引導學習，決策表現另看精確率、召回率等 | 類別編成數字仍是分類；訓練損失與評估目的要分清 | [損失函數選擇](/concepts/loss-function-selection/#定義與公式)（定義）、[損失函數選擇](/concepts/loss-function-selection/#怎麼用怎麼判讀)（選用）；科3指引 4-4～4-6 |
| 數值預測，特別重視大誤差 | 優先比較 MSE，讓平方代價反映需求 | 對離群值敏感，須確認平方代價符合需求 | [均方誤差](/concepts/mean-squared-error/#怎麼用怎麼判讀)、[平均絕對誤差](/concepts/mean-absolute-error/#算一次)；科3指引 4-4、5-22～5-23 |
| 數值預測，關心平均絕對差距 | 用 MAE 以原單位解釋誤差，和 MSE 比較代價偏好 | 極端誤差仍會線性累加 | [平均絕對誤差](/concepts/mean-absolute-error/#怎麼用怎麼判讀)；科3指引 4-4、5-23 |
| 無參考標籤的指標方向 | 輪廓係數、Davies–Bouldin；前者看高分、後者看低分，搭配群大小（補充） | 須固定資料、表示、尺度與距離；幾何品質不保證業務效益（補充） | [非監督學習的評估方法](/concepts/unsupervised-evaluation/#五種訊號回答什麼)（指標）、[非監督學習的評估方法](/concepts/unsupervised-evaluation/#比較前固定條件補充)（比較條件）；方法名稱見科3指引 4-8，方向與限制依教材所列 scikit-learn 補充 |
| 有參考標籤的分組判讀 | 使用 Rand Index 或 AMI；越接近 1 越一致（補充） | 未標籤樣本不能補成正常；部分標籤的子集須能代表欲評估資料（補充） | [非監督學習的評估方法](/concepts/unsupervised-evaluation/#五種訊號回答什麼)（指標）、[非監督學習的評估方法](/concepts/unsupervised-evaluation/#用同一批顧客比較補充)（子集比較）；方法名稱見科3指引 4-8，方向與限制依教材所列 Rand／AMI API 補充 |
| 壓縮或表示後的重建判讀 | 使用重建誤差；比較時固定欄位與尺度（補充） | 重建誤差不是分群專用指標，也不直接表示分類表現（補充） | [非監督學習的評估方法](/concepts/unsupervised-evaluation/#定義與公式)；方法與應用見科3指引 4-8～4-9，判讀限制依教材所列 MSE API 補充 |
| 連續互動與延遲回饋 | 同看平均累積報酬、成功率、穩定性與收斂速度 | 單步獎勵高不能取代任務完成；跨設定須固定評估條件（補充） | [強化學習訓練與成效驗證](/concepts/reinforcement-learning-training/#怎麼用怎麼判讀)；科3指引 4-11，固定條件依該節補充 |

## 診斷

| 現象 | 先查什麼 | 判讀限制與下一步 | 教材與來源 |
|---|---|---|---|
| 特徵是數字，任務卻判不清 | 目標是類別代號還是有單位的數量 | 回到標籤語意和輸出需求；分類機率是小數也不改變任務 | [分類與迴歸任務](/concepts/classification-regression/#直覺)；科3指引 4-5～4-6（含分類機率輸出） |
| 訓練好、驗證明顯差 | 過擬合線索與資料量、容量、訓練時間 | 回看兩份資料的表現；比較簡化模型、正則化或早停等方向 | [過擬合](/concepts/overfitting/#怎麼用怎麼判讀)；科3指引 4-62～4-63、5-43 |
| 用測試分數反覆挑設定 | 測試資料是否已參與開發決策 | 改用驗證資料選設定；改名無法讓已參與選型的資料重新獨立（補充） | [監督式學習開發流程](/concepts/supervised-learning-workflow/#常見誤解)；資料分工見科3指引 4-5，獨立性依教材所列 scikit-learn Common pitfalls 補充 |
| 分類損失輸入出現錯配（補充） | 核對 logits／機率、標籤型別與形狀 | PyTorch 的 BCEWithLogitsLoss 與 CrossEntropyLoss 直接收 logits；依函式契約處理 | [交叉熵損失](/concepts/cross-entropy-loss/#框架輸入對照補充)；教材所列 PyTorch／Keras 文件 |
| 偽標籤增加，驗證卻沒改善（補充） | 資料來源、信心校準與錯誤回饋 | 高信心也可能錯；暫停加入並人工複核，再與相同標籤預算基準比較 | [半監督學習](/concepts/semi-supervised-learning/#失敗條件補充)；教材所列 scikit-learn 半監督文件 |
| 輪廓係數無法計算或難以比較（補充） | 實際群數 $k$ 與樣本數 $n$、距離尺度 | 需 $2\le k\le n-1$；scikit-learn 對單點群的該點設為 0，換尺度要重看基準 | [輪廓係數](/concepts/silhouette-score/#可用條件與邊界)（可用條件）、[輪廓係數](/concepts/silhouette-score/#公平比較的條件)（比較條件）；教材所列 scikit-learn |
| 報酬上升卻沒有完成任務 | 檢查能否重複得分而不完成任務（補充） | 以任務達成率查核；換獎勵後須固定任務指標，不同獎勵尺度不可直接比高低（補充） | [獎勵設計與獎勵塑形](/concepts/reward-design/#怎麼用怎麼判讀)（漏洞查核）、[獎勵設計與獎勵塑形](/concepts/reward-design/#用相同回報尺度比較補充)（尺度）；科3指引 4-9～4-11 支持任務達成率查核，漏洞與固定指標、尺度依教材補充 |
| 以神經網路判定有模型強化學習 | 網路是在估價值，還是在預測環境（補充） | 分別看有無環境模型、策略式／價值式；兩軸可組合，Q 網路本身不代表環境模型（補充） | [強化學習方法分類](/concepts/reinforcement-learning-methods/#怎麼用怎麼判讀)；分類見科3指引 4-10，兩軸組合與 Q 網路判讀依教材所列 Spinning Up 補充 |
| 選定方法卻不匹配控制輸出 | 動作是有限選項還是連續控制量 | 高維觀測不決定動作形式；標準 DQN 的離散動作限制要另外核對（補充） | [強化學習動作空間與應用限制](/concepts/reinforcement-learning-control/#定義與公式)；動作分類見科3指引 4-10，觀測區分與 DQN 限制依教材所列 Gymnasium／Spinning Up 補充 |
| 建樹後搜尋仍慢（補充） | 查維度、半徑、輸出量及建索引成本 | 高維可能退化；密集鄰接輸出本身可達平方級，索引不能消除輸出成本 | [近鄰搜尋與距離索引](/concepts/neighbor-search-index/#高維退化與記憶體補充)；教材所列 scikit-learn 近鄰搜尋文件 |
