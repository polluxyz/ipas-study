## 公式

模型選擇沒有一條適用所有任務的總公式；先用任務與條件縮小候選，再公平驗證。來源：科目 3 指引 5-11～5-16；[任務與模型配對](/concepts/task-model-matching/#定義與公式)。下列只摘錄教材已有的核算工具。

| 用途 | 公式與符號 | 條件與限制 | 來源與教材 |
|---|---|---|---|
| 容量線索（補充） | $P=H(p+2)+1$；$p$ 為輸入維度、$H$ 為隱藏寬度、$P$ 為參數總數 | 單隱藏層、單輸出；兩層含偏差，激活無可訓練參數。參數多不保證效果好 | 依 PyTorch Linear 的權重／偏差形狀自行計數推得；[資料規模與模型容量](/concepts/model-capacity-selection/#算參數作為容量線索補充) |
| ARIMA 一次差分（補充） | $z_t=y_t-y_{t-1}$；$y_t$ 為原值、$z_t$ 為相鄰差 | $n$ 筆連續觀測留下 $n-1$ 個差；差分不自動解決季節性 | FPP3 第 9 章；[ARIMA 時間序列模型](/concepts/arima/#pdq的角色補充) |
| TCN 感受野跨度（補充） | $R=1+\sum_{\ell=1}^{L}(k_\ell-1)d_\ell$；$L$ 為卷積層數，$k_\ell$、$d_\ell$ 為各層核寬與擴張率 | 每層一個卷積、步幅 1，無改變時間尺度的池化；跨度不保證每點都有覆蓋 | 依 Shang 等人式 (2) 自行作逐層核寬推廣；等核寬時回到原式；[時序卷積網路](/concepts/temporal-convolutional-network/#因果與感受野補充) |
| SHAP 輸出重建（補充） | $f(x)=\phi_0+\sum_{j=1}^{M}\phi_j(x)$；$f(x)$ 為個案輸出、$\phi_0$ 為基準、$\phi_j$ 為各項貢獻、$M$ 為特徵數 | 全部項須在同一輸出尺度；log-odds 貢獻不能直接當機率百分點 | SHAP 原始論文；[SHAP 特徵貢獻與輸出尺度](/concepts/shap/#加法分解與線性小例子補充) |
| 正則化目標 | $J(\mathbf w)=D(\mathbf w)+\lambda R(\mathbf w)$；$\mathbf w$ 為權重、$D$ 為資料損失、$R$ 為懲罰，$\lambda\geq0$ 為強度 | 固定同一損失及懲罰慣例才可比較（補充）；限制過強也會欠擬合 | 科目 3 指引 5-42；[正則化方法選用](/concepts/regularization/#定義與公式) |

## 指標怎麼選

| 要解決的問題 | 選擇或優先比較 | 條件與限制 | 來源與教材 |
|---|---|---|---|
| 輸出是類別或連續值 | 分類與迴歸各列候選，再查線性、非線性與解釋需求 | 模型族相同也不能保證所有資料都勝出 | 科目 3 指引 5-11～5-12；[任務與模型配對](/concepts/task-model-matching/#分類與迴歸的候選) |
| 沒有標籤 | 找群時比較 K-means／DBSCAN；壓縮時比較 PCA／自編碼器 | 群組不等於已知標籤；壓縮後仍要檢查用途所需資訊 | 科目 3 指引 5-12～5-13；[任務與模型配對](/concepts/task-model-matching/#分群與降維的候選) |
| 資料規模不同 | 同看樣本、維度、容量及擴展成本 | 指引筆數區間是候選方向，不是硬性門檻 | 科目 3 指引 5-13～5-14；[資料規模與模型容量](/concepts/model-capacity-selection/#指引的規模起點) |
| 多個候選分數接近 | 合看技術指標、錯誤成本及多輪波動 | 先對齊資料與評估條件；單項最高分不足以定案 | 科目 3 指引 5-24～5-26；[模型比較與綜合評估](/concepts/model-comparison/#怎麼用怎麼判讀) |
| 序列預測 | 比較 RNN／LSTM／GRU、TCN 及 ARIMA 的相依與資源條件 | 固定預測目標；長序列能力不代表無限記憶（補充） | 科目 3 指引 5-13 與教材比較限制補深；[序列模型的選擇](/concepts/sequence-model-selection/#定義與公式) |
| 要能直接追溯決策 | 先驗證係數模型或淺樹是否足夠，再評估複雜模型加事後解釋 | 森林的特徵排序不等於直接讀懂每筆決策 | 科目 3 指引 5-14～5-15；[可解釋 AI 的需求與方法選用](/concepts/explainable-ai/#定義與公式) |
| 要解釋個案或平均趨勢（補充） | SHAP 看相對基準的貢獻，LIME 看局部近似，PDP 看參考資料的平均趨勢 | 三者回答不同問題；預測解釋不能證明因果 | SHAP、LIME 原始論文及 scikit-learn PDP；[可解釋 AI 的需求與方法選用](/concepts/explainable-ai/#同一模型的三個提問補充) |
| 有延遲與記憶體上限 | 先同時通過兩項限制，再比較驗證效果 | 檔案大小不等於峰值記憶體，p95 不保證每次準時（補充） | 科目 3 指引 5-15；教材量測補深；[資源與延遲限制下的模型選擇](/concepts/resource-aware-model-selection/#比較前先定義量測補充) |
| 標註少、已有預訓練模型 | 比較從頭訓練與微調；固定特徵萃取及部分微調另見教材補充 | 要核對領域差異、資料量與成本，不能假定遷移必定受益 | 科目 3 指引 4-82、科目 1 指引 3-26；[遷移學習與預訓練模型選擇](/concepts/transfer-learning/#四種起點與成本) |
| 人力少、時程緊 | 評估 AutoML 原型，再查客製化、費用與隱私條件 | 工具支援範圍不同，人工仍須定義成功條件 | 科目 1 指引 4-24、4-26、5-5～5-7；[自動化機器學習](/concepts/automl/#怎麼用怎麼判讀) |

## 診斷

| 現象 | 先查什麼或怎麼選 | 判讀限制 | 來源與教材 |
|---|---|---|---|
| 訓練與驗證都差 | 對照基準，檢查容量及限制強度 | 尚未收斂、特徵不足與資料問題另見教材補充，不能一律加深網路 | 科目 3 指引 5-16、4-16、5-34；[欠擬合](/concepts/underfitting/#先排除什麼) |
| 訓練好、驗證落後 | 回看過擬合的成因與改善方向 | 一次落差不能直接量出跨訓練樣本的變異（補充） | 科目 3 指引 5-16 與教材變異區別補深；[偏差與變異權衡](/concepts/bias-variance-tradeoff/#怎麼用怎麼判讀)、[過擬合](/concepts/overfitting/#怎麼用怎麼判讀) |
| 正則化越強，兩邊越差 | 比較較弱限制，觀察驗證是否改善 | 強度不是越大越好；維持同一評估條件 | 科目 3 指引 5-42；[正則化方法選用](/concepts/regularization/#定義與公式) |
| 差分後仍有季節性（補充） | 檢查季節項與殘差自相關，區分 ARIMA／SARIMA | 移除趨勢不能保證平穩或已解決季節變化 | FPP3 第 9 章；[ARIMA 時間序列模型](/concepts/arima/#診斷與季節界線補充) |
| 視窗加長仍看不到所需歷史（補充） | 同時核對輸入視窗與 TCN 感受野 | 可見歷史有限，也不能把區塊數直接當卷積層數 | Bai 及 Shang 等人；[時序卷積網路](/concepts/temporal-convolutional-network/#因果與感受野補充) |
| SHAP 貢獻被讀成機率百分點（補充） | 先查輸出尺度，再重建個案分數 | log-odds 總和轉機率，不等於逐項直接相加機率 | SHAP 原始論文及教材 Sigmoid 對照；[SHAP 特徵貢獻與輸出尺度](/concepts/shap/#把總分轉成機率補充) |
| LIME 換種子後重點改變（補充） | 比較擾動、鄰域及多種子的忠實度與穩定性 | 單次局部擬合好，不代表整體或其他個案都可靠 | LIME 原始論文；[LIME 局部替代解釋](/concepts/lime/#怎麼用怎麼判讀) |
| PDP 組合不合理（補充） | 檢查替換值與其餘特徵是否仍符合資料結構 | 相關特徵可能產生不合理組合；平均趨勢不能當介入效果 | scikit-learn PDP；[偏依圖](/concepts/partial-dependence-plot/#相關特徵與因果界線補充) |
| 壓縮後仍未達延遲要求（補充） | 在固定硬體與請求條件下重測端到端及核心時間 | 量化、剪枝不保證每種執行環境都加速 | ONNX Runtime 及 PyTorch Benchmark；[資源與延遲限制下的模型選擇](/concepts/resource-aware-model-selection/#延遲實測設計補充) |
| 自動搜尋分數亮眼（補充） | 查前處理是否只在訓練摺擬合，測試是否封存 | 反覆挑選的最高分不等於獨立評估 | scikit-learn 選模與巢狀驗證；[自動化機器學習](/concepts/automl/#樂觀偏誤的反例補充) |
| 新批多了一欄（補充） | 先處理表示契約，選固定表示或建立新版 | 新增列與新增維度不同；固定欄數仍須對齊順序、單位與語意 | scikit-learn 大資料策略；[增量學習與特徵空間變動](/concepts/incremental-learning/#定義與公式補充) |
| 新批改善、舊情境退步（補充） | 分開檢查新批與歷史留樣，再比較重播或重建 | 固定維度不能保證不遺忘，留樣不能回流訓練後仍稱獨立驗證 | 持續學習與經驗重播研究；[增量學習與特徵空間變動](/concepts/incremental-learning/#怎麼用怎麼判讀) |
