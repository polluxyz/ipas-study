## 公式

### 更新與搜尋成本

| 計算 | 公式與符號 | 條件與限制 | 來源與教材 |
|---|---|---|---|
| SGD 更新 | $\theta_t=\theta_{t-1}-\eta g_t$；$\theta$ 為參數，$g_t$ 為本步梯度，$\eta>0$ 為學習率 | 梯度在更新前參數計算；小批次梯度不是整份資料的精確梯度（補充） | [隨機梯度下降](/concepts/sgd/#定義與公式)、[隨機梯度下降](/concepts/sgd/#為什麼需要) |
| 網格成本（補充） | $C=\prod_{j=1}^{d}m_j$，$N_{\mathrm{fit}}=KC+r$；$d$ 為參數維數，$m_j$ 為該軸值數，$K$ 為摺數，$r$ 有重訓為 1、無則 0 | 單一完整交叉網格，每候選跑完所有摺；平行化不減少擬合次數 | [網格搜尋](/concepts/grid-search/#定義與公式補充) |
| 小批次更新量（補充） | 每輪保留尾批為 $\lceil n/B\rceil$ 次，捨棄尾批為 $\lfloor n/B\rfloor$ 次；$n$ 為訓練筆數，$B$ 為批次大小 | $n,B$ 為正整數；每批更新一次、沒有梯度累積；尾批平均用實際筆數 | [小批次梯度下降](/concepts/mini-batch-gradient-descent/#每輪更新次數與尾批補充) |

### 懲罰與資料處理

| 計算 | 公式與符號 | 條件與限制 | 來源與教材 |
|---|---|---|---|
| 正則化目標 | $J=D+\lambda R$；$D$ 為資料損失，$R$ 為懲罰，$\lambda\ge0$ 為限制強度 | 同一目標定義內才可比較強度（補充）；太強可能欠擬合 | [正則化方法選用](/concepts/regularization/#定義與公式) |
| L1 懲罰 | $R_1=\sum_{j=1}^{d}\lvert w_j\rvert$；$w_j$ 為第 $j$ 個權重，$d$ 為受懲罰權重數 | 促進稀疏；相關欄位的選取名單可能不穩（補充） | [L1 正則化與 Lasso](/concepts/l1-regularization/#定義與公式)、[正則化方法選用](/concepts/regularization/#怎麼用怎麼判讀) |
| L2 懲罰 | $R_2=\sum_{j=1}^{d}w_j^2$；符號同上 | 收縮權重，不以大量歸零為目標；負值平方不能抵銷正值 | [L2 正則化與 Ridge](/concepts/l2-regularization/#定義與公式) |
| Elastic Net | $J_E=D+\lambda_1R_1+\lambda_2R_2$；兩個非負係數分別控制 L1 與 L2 | 先對齊資料損失尺度（補充）；兩項強度都需要驗證 | [Elastic Net](/concepts/elastic-net/#定義與公式)、[正則化方法選用](/concepts/regularization/#定義與公式) |
| Inverted Dropout（補充） | $\tilde h_j=m_jh_j/q$；$h_j$ 為單元輸出，$m_j$ 為以機率 $q$ 保留的 0／1 遮罩 | $0<q\le1$；$q$ 是保留率，框架的丟棄率為 $1-q$；一般推論不再縮放 | [Dropout](/concepts/dropout/#兩種縮放位置) |
| 類別加權平均（補充） | $L_w=\sum_iw_{y_i}\ell_i/\sum_iw_{y_i}$；$w_{y_i}$ 為真類權重，$\ell_i$ 為單筆損失 | 權重非負且總和大於 0；有些 API 除以筆數，不能混比 | [類別權重](/concepts/class-weighting/#加權平均與分母補充) |
| SMOTE 插值（補充） | $x_{\mathrm{new}}=x_i+\lambda(x_j-x_i)$；$x_i,x_j$ 為同類近鄰，$0\le\lambda\le1$ | 只用訓練摺找近鄰；連續距離須合理，類別代碼不能直接插值 | [SMOTE 少數類別合成](/concepts/smote/#近鄰插值規則補充)、[SMOTE 少數類別合成](/concepts/smote/#合成前後的檢查補充) |

## 指標怎麼選

這裡依改善目標選觀察量；先查方法適用條件，再沿教材比較，不以單一訓練分數決定所有配置。[模型優化流程](/concepts/optimization-workflow/#定義與公式)。

| 目標或條件 | 選擇與觀察量 | 限制 | 來源與教材 |
|---|---|---|---|
| 決定深寬配置 | 合看擬合狀況、資料量及資源，對照不同容量 | 過深可能難收斂，過寬可能過擬合；容量須配合資料 | [網路深度、寬度與容量](/concepts/network-capacity/#怎麼用怎麼判讀) |
| 選隱藏層激活 | 比較 ReLU 的活躍情況與 Tanh 的飽和情況 | 零中心或正側不飽和，都不保證整體收斂較好（補充） | [ReLU](/concepts/relu/#怎麼用怎麼判讀)、[Tanh](/concepts/tanh/#怎麼用怎麼判讀) |
| 核對分類輸出契約 | 單標籤多類讀 Softmax，多標籤讀逐項 Sigmoid | 先核對任務與損失 API；接收 logits 時勿重複轉換（補充） | [Softmax](/concepts/softmax/#怎麼用怎麼判讀)、[Softmax](/concepts/softmax/#與損失api配對補充)、[Sigmoid](/concepts/sigmoid/#怎麼用怎麼判讀) |
| 比較優化器 | 看梯度稀疏性、狀態需求、收斂與驗證結果 | Adam 是可試起點，仍需調學習率；訓練快不代表泛化好 | [優化器選擇](/concepts/optimizer-selection/#定義與公式)、[Adam 優化器](/concepts/adam/#怎麼用怎麼判讀) |
| 搜尋方法取捨（補充） | 小離散空間比網格；預算固定、空間大比隨機；單次評估貴比貝氏 | 三者共享驗證規則；有限搜尋不保證全域最佳 | [超參數搜尋策略](/concepts/hyperparameter-search/#定義與公式補充) |
| 稀疏或共線特徵 | L1 側重選取，L2 側重收縮，Elastic Net 比較兩者混合 | 強度太大都可能損害擬合；相關欄位還要檢查選取穩定性（補充） | [正則化方法選用](/concepts/regularization/#怎麼用怎麼判讀)、[Elastic Net](/concepts/elastic-net/#怎麼用怎麼判讀) |
| 選停止與還原規則 | 以驗證指標配合改善門檻（補充）及 patience | 監控方向要明確；停止輪次與最佳權重可能不同（補充） | [早停](/concepts/early-stopping/#定義與公式)、[早停](/concepts/early-stopping/#停止點不等於最佳點補充) |
| 比較不平衡對策 | 固定原分布驗證資料（補充），比精確率、召回率與 PR-AUC（補充），再選採樣比例或損失權重 | 準確率可能掩蓋少數類；各半不代表最佳比例或公平性改善（補充） | [過採樣](/concepts/oversampling/#怎麼用怎麼判讀)、[類別不平衡](/concepts/class-imbalance/#怎麼用怎麼判讀) |
| 辨認大量容易樣本（補充） | 比較類別權重與 Focal Loss 的逐筆調節，再看驗證指標 | Focal 不會修正錯標；難例可能包含雜訊 | [Focal Loss 焦點損失](/concepts/focal-loss/#怎麼用怎麼判讀) |
| 壓縮後能否部署（補充） | 合看預測品質、目標裝置延遲、執行路徑與記憶體 | 固定裝置、批次及輸入條件；低位元可能回退到較慢算子 | [模型量化](/concepts/quantization/#驗收表補充) |
| 判斷蒸餾貢獻 | 比較學生品質、部署成本及教師弱點是否延續 | 還要計入學生訓練成本，並比較同架構硬標籤基準（補充） | [知識蒸餾](/concepts/knowledge-distillation/#怎麼用怎麼判讀) |
| 混合精度是否有效 | 在硬體支援下比較訓練速度、記憶體和效果 | 分開檢查算子精度（補充）與梯度尺度；不會自動得到 INT8 推論模型（補充） | [混合精度訓練](/concepts/mixed-precision-training/#怎麼用怎麼判讀) |

## 診斷

| 現象 | 下一步 | 限制 | 來源與教材 |
|---|---|---|---|
| 訓練好、驗證落後 | 先查資料與評估（補充），再比較容量、正則化、增強及早停 | 單次落差不能證明原因；也可能有切分或模式干擾（補充） | [過擬合](/concepts/overfitting/#怎麼用怎麼判讀)、[模型優化流程](/concepts/optimization-workflow/#為什麼需要) |
| 損失震盪或下降過慢 | 核對學習率、批次大小與訓練趨勢，再比較排程 | 大步長可能震盪，小步長可能耗時；不能只追求更多輪數 | [學習率排程](/concepts/learning-rate-schedule/#為什麼需要)、[小批次梯度下降](/concepts/mini-batch-gradient-descent/#怎麼用怎麼判讀) |
| Adagrad 後期停滯 | 查看累積平方與有效步長是否已很小 | 累積量不會因近期梯度小而自動消失，停滯不等於好解 | [Adagrad](/concepts/adagrad/#怎麼用怎麼判讀) |
| 裁剪後仍出現 NaN（補充） | 找第一個非有限輸入或梯度，查除零、非法對數及低精度溢位 | 範數縮放不能把 NaN 修成有效方向；裁剪放在反傳後、更新前 | [梯度裁剪與迴圈位置](/concepts/gradient-clipping/#怎麼用怎麼判讀)、[梯度裁剪與迴圈位置](/concepts/gradient-clipping/#一般迴圈反傳之後更新之前補充) |
| 搜尋最高分被當成最終表現（補充） | 查是否同一批分數兼做選擇與評估；需要時用內層調參、外層評估 | 外層評估整個流程，不直接產生唯一部署模型 | [巢狀交叉驗證](/concepts/nested-cross-validation/#怎麼用怎麼判讀補充)、[巢狀交叉驗證](/concepts/nested-cross-validation/#最後要交付哪個模型) |
| Dropout 推論結果不穩 | 查訓練模式、丟棄率語意及縮放位置 | 已用 inverted dropout 就不要在推論再乘保留率（補充） | [Dropout](/concepts/dropout/#怎麼用怎麼判讀) |
| 增強後標籤不可信 | 逐項查變換是否破壞原意，必要時同步改標註或拒絕變換（補充） | 形狀合法不足以證明語意保留；變體不能跨評估邊界（補充） | [資料增強與標籤語意](/concepts/data-augmentation/#三種標籤處置補充)、[資料增強與標籤語意](/concepts/data-augmentation/#常見誤解) |
| 欠採樣後誤報增加（補充） | 查重要多數類型態是否被抽掉，改比溫和比例及不同種子 | 刪資料只提高少數類占比，不會新增少數類資訊 | [欠採樣](/concepts/undersampling/#怎麼用怎麼判讀) |
| 剪掉很多權重卻沒有加速 | 查形狀是否縮小、是否仍用密集儲存及算子，並查硬體支援 | 稀疏率不是延遲改善率；剪枝後還要重驗品質 | [模型剪枝](/concepts/model-pruning/#怎麼用怎麼判讀) |
| 量化後品質下降 | 查前處理、校準代表性與飽和（補充），再以驗證資料比較部分高精度或 QAT | 測試集不拿來調尺度；QAT 後仍要轉換及驗收（補充） | [模型量化](/concepts/quantization/#ptq校準與qat補充) |
| AMP 裁剪的尺度不對（補充） | 依序放大損失、反傳、還原尺度、裁剪，再執行更新 | 不重複 unscale；也不是把更新後權重除以尺度 | [混合精度訓練](/concepts/mixed-precision-training/#更新順序補充)、[梯度裁剪與迴圈位置](/concepts/gradient-clipping/#amp先還原再裁剪補充) |
| LoRA 後仍放不進裝置（補充） | 分開查可訓練參數與基底模型的推論容量 | 凍結基底不會自動縮小它；低秩更新不是部署壓縮 | [LoRA 低秩自適應](/concepts/lora/#怎麼用怎麼判讀) |
| 新任務變好、舊能力下降（補充） | 用固定新舊留樣比較更新前後，再評估凍結、限制更新或重播 | 低秩或凍結不保證不忘；還要查資料授權、任務衝突及代表性 | [災難性遺忘](/concepts/catastrophic-forgetting/#怎麼用怎麼判讀補充) |
