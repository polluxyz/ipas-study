## 公式

| 用途 | 公式與符號 | 條件與限制 | 教材與來源 |
|---|---|---|---|
| Min-Max 縮放（補充） | $x'=(x-a)/(b-a)$；$x$ 為待轉換值，$a,b$ 為訓練欄最小、最大值 | $b>a$；新值沿用訓練尺度，結果可能超出 0～1 | [特徵縮放與標準化](/concepts/feature-scaling/#min-max訓練範圍作分母)；教材所列 MinMaxScaler 文件 |
| Z-score 縮放（補充） | $z=(x-\mu)/\sigma$；$x$ 為待轉換值，$\mu,\sigma$ 為訓練平均與標準差 | $\sigma>0$；StandardScaler 採分母為訓練筆數的變異數；不保證常態 | [特徵縮放與標準化](/concepts/feature-scaling/#z-score訓練平均與標準差)；教材所列 StandardScaler 文件 |
| 準確率 | $\mathrm{Accuracy}=(TP+TN)/n$；$TP,TN$ 為判對的正、負類數，$n=TP+FP+FN+TN$；$FP$ 為誤報數，$FN$ 為漏報數 | $n>0$；多數類可能掩蓋少數類錯誤 | [準確率](/concepts/accuracy/#定義與公式)；科3指引5-21；空資料邊界依教材補充 |
| 精確率 | $P=TP/(TP+FP)$；分母為預測正類筆數 | $TP+FP>0$；還須另查漏報 | [精確率](/concepts/precision/#定義與公式)；科3指引5-21；零分母依教材補充 |
| 召回率 | $R=TP/(TP+FN)$；分母為實際正類筆數 | $TP+FN>0$；高召回率仍可能伴隨很多誤報 | [召回率](/concepts/recall/#定義與公式)；科3指引5-21；零分母依教材補充 |
| F1 | $F_1=2PR/(P+R)$；$P$ 為精確率，$R$ 為召回率 | 兩者有定義且 $P+R>0$；固定正類與閾值，不計入 $TN$ | [F1 分數](/concepts/f1-score/#調和平均)；科3指引5-21、5-25；邊界依教材補充 |
| K-fold 平均 | $\bar s=\frac1K\sum_{k=1}^{K}s_k$；$K$ 為摺數，$s_k$ 為第 $k$ 摺分數 | 每摺重新擬合；同看分數波動，不把均值當作獨立測試 | [K-fold 交叉驗證](/concepts/k-fold-cross-validation/#定義與公式)；科3指引5-26 |
| 搜尋擬合預算（補充） | $N=BK+r$；$B$ 為候選組數，$K$ 為摺數，$r$ 為最後重訓次數，取 0 或 1 | 每組完整跑各摺；未含代理模型成本，次數不等於耗時 | [超參數搜尋策略](/concepts/hyperparameter-search/#定義與公式補充)；教材由 scikit-learn 搜尋器實作推得 |
| 網格候選數（補充） | $B=\prod_{j=1}^{d}m_j$；$d$ 為參數個數，$m_j$ 為第 $j$ 軸候選數 | 單一完整交叉網格；只涵蓋列出的點，不涵蓋連續空間 | [網格搜尋](/concepts/grid-search/#定義與公式補充)；教材由 ParameterGrid 實作推得 |

## 指標怎麼選

| 條件或決策 | 選擇依據 | 限制 | 教材與來源 |
|---|---|---|---|
| 要預測金額或離散事件 | 先依目標語意區分迴歸、分類，再建立候選 | 類別機率也有小數，不能只按輸出型態判斷 | [任務辨識與模型選擇](/concepts/task-model-selection/#先看目標的意思)；科1指引5-7～5-9 |
| 要檢查資料能否使用 | 分開查完整、一致、準確、即時、唯一 | 資料不缺漏，也可能是錯值或過期值 | [資料品質檢核](/concepts/data-quality/#定義與公式)；科1指引5-4 |
| 需要簡單且可解釋的預測起點 | 比較線性模型與決策樹，再考慮更複雜的集成 | 要回到相同資料條件比較；複雜度不能補救錯標 | [任務辨識與模型選擇](/concepts/task-model-selection/#3-比較符合任務與資源的候選)；科1指引5-7～5-9、科3指引5-11、5-15 |
| 沒有標籤，想探索結構 | 先選群組、低維座標或潛在表示等輸出 | 分群編號須經業務查核，不能當成真實類別 | [非監督式任務與異常偵測選型](/concepts/unsupervised-learning/#按輸出選任務)；科1指引5-9～5-10 |
| 想壓縮欄位或看低維分布 | PCA 看保留變異；非線性嵌入看鄰近結構 | 變異大不等於預測重要，低維群間距離也不能直接照讀 | [主成分分析](/concepts/pca/#怎麼用怎麼判讀)、[t-SNE 與 UMAP 非線性嵌入比較](/concepts/nonlinear-embedding/#怎麼用怎麼判讀)；科1指引5-5、5-10；距離判讀依教材補充 |
| 分類誤報代價較高 | 優先檢查精確率，再合看召回率 | 只發少量警報可以有高精確率，卻漏掉很多目標 | [精確率](/concepts/precision/#怎麼用怎麼判讀)；科3指引5-21 |
| 分類漏報代價較高 | 優先檢查召回率，再合看精確率 | 不能忽略誤報所需的處理資源 | [召回率](/concepts/recall/#怎麼用怎麼判讀)；科3指引5-21 |
| 少數正類很重要 | 查混淆矩陣、少數類精確率與召回率，需要兼顧時看 F1 | 準確率高不保證少數類表現好 | [類別不平衡](/concepts/class-imbalance/#怎麼用怎麼判讀)；科3指引5-18、5-21 |
| 想比較分數的區分能力 | ROC-AUC 看所有閾值下的整體區分能力，再合看固定閾值的指標 | AUC 不直接選閾值，單一混淆矩陣不能還原整條 ROC | [ROC 曲線與 AUC](/concepts/roc-auc/#怎麼用怎麼判讀)、[混淆矩陣](/concepts/confusion-matrix/#怎麼用怎麼判讀)；科3指引5-22～5-23 |
| 標註量少，已有預訓練模型 | 比較從頭訓練、固定特徵及微調的成本和驗證表現 | 領域差異及凍結範圍仍要核對 | [遷移學習與預訓練模型選擇](/concepts/transfer-learning/#四種起點與成本)；科1指引3-8～3-9、科3指引4-82 |
| 需要生成資料 | 對照 GAN、VAE、擴散的機制及品質、多樣性、速度 | 合成資料不能取代真實評估資料 | [變分自編碼器 VAE](/concepts/variational-autoencoder/#和-gan擴散怎麼選)、[變分自編碼器 VAE](/concepts/variational-autoencoder/#低標註選模補充)；科1指引5-12～5-13；真實評估界線依教材補充 |
| 需要連續與環境互動 | 先定狀態、動作及獎勵，再比較值方法與策略方法 | 高回報可能只是獎勵漏洞，不能直接當成達成目的 | [強化學習的任務與獎勵](/concepts/reinforcement-learning/#定義與公式)、[強化學習的任務與獎勵](/concepts/reinforcement-learning/#抓取有分交付沒分的漏洞)；科1指引5-11～5-12；獎勵投機依教材補充 |
| 搜尋預算有限（補充） | 小型離散空間可用網格；較廣空間可先隨機；昂貴評估可考慮貝氏 | 代理有額外成本，三者都不保證找到連續空間最優點 | [超參數搜尋策略](/concepts/hyperparameter-search/#定義與公式補充)；教材所列 scikit-learn、INRIA 及 scikit-optimize 文件 |
| 多個候選分數接近 | 合看多輪波動、錯誤成本和資源需求 | 單一平均或單一圖形不能證明全面勝出 | [模型比較與綜合評估](/concepts/model-comparison/#箱型圖與平均排名圖)、[任務辨識與模型選擇](/concepts/task-model-selection/#3-比較符合任務與資源的候選)；科3指引5-24～5-25 |
| 要比較少標註與部署資源條件（補充） | 共用訓練子集、固定驗證與測試，再核對搜尋預算及資源門檻 | 成果檔大小不等於推論記憶體；合成文字實測不能外推其他模型 | [模型比較與綜合評估](/concepts/model-comparison/#固定資料才能看資料效率補充)；教材所列 scikit-learn 多指標選模與文字分類文件、合成實測；門檻為例子自訂 |

## 診斷

| 看到的現象 | 優先查什麼 | 處理與界線 | 教材與來源 |
|---|---|---|---|
| 同一鍵出現多列 | 觀察單位、事件版本與重送紀錄 | 確認重送才去重；同顧客的新交易可能合法 | [重複資料與主鍵去重](/concepts/data-consistency/#先看事件再看欄位)；科1指引5-4、科3指引5-3～5-4 |
| 缺值很多，刪除後分布改變 | 缺漏原因、型態與剩下的樣本 | 比較刪除與填補的偏差，不只看缺失比例 | [缺失值處理](/concepts/missing-value-imputation/#怎麼用怎麼判讀)；科1指引5-3、科3指引5-2～5-3 |
| 少量數值遠離大多數資料 | 原始量測、分布形狀及局部鄰近 | 偵測只列候選；真實稀有事件不能直接刪除 | [離群值偵測與處置](/concepts/outlier-detection/#怎麼用怎麼判讀)；科1指引5-4 |
| 縮放後仍有長尾（補充） | 是否把量級調整誤當分布改造 | 比較偏態轉換前先查定義域；Z-score 不保證常態 | [特徵縮放與標準化](/concepts/feature-scaling/#怎麼用怎麼判讀)、[對數與冪次轉換](/concepts/power-transforms/#怎麼用怎麼判讀)；教材所列縮放與 PowerTransformer 文件 |
| 編碼後出現不存在的高低關係 | 類別是否真的有序 | 無序類別比較獨熱編碼，另核對欄數及未知類別規則 | [類別特徵編碼](/concepts/categorical-encoding/#有序與無序)；科1指引5-4～5-5 |
| 自動選出的特徵換批資料就失效 | 候選欄的可用時間、篩選範圍及驗證回饋 | 固定比較條件再修訂候選；自動化不保證提升 | [自動特徵篩選與驗證回饋](/concepts/automated-feature-selection/#走一次流程)；科1指引5-6～5-7 |
| 高基數編碼看起來異常準確（補充） | 訓練列是否使用了自身標籤 | 核對折外估計；外部驗證與測試標籤不得參與編碼 | [自動前處理與目標編碼](/concepts/automated-preprocessing/#擬合邊界補充)；教材所列 TargetEncoder 文件 |
| 增強後的模型只記得來源樣本（補充） | 同源變體是否跨訓練與評估集 | 按來源先切分，隨機增強留在訓練端，並複核標籤 | [資料增強與標籤語意](/concepts/data-augmentation/#從原始來源到可評估的資料流補充)；教材所列 TensorFlow 資料增強與 Torchvision 文件 |
| 高維 DBSCAN 查詢仍很慢（補充） | 維度、距離及索引剪枝效果 | 索引不保證加速；比較實際查詢成本與記憶體 | [近鄰搜尋與距離索引](/concepts/neighbor-search-index/#怎麼用怎麼判讀)；教材所列 scikit-learn 近鄰文件 |
| 低維圖分群很漂亮 | 原始鄰近、縮放及嵌入設定 | 不能把圖形分離當作分類成功；仍需獨立驗證用途 | [t-SNE 與 UMAP 非線性嵌入比較](/concepts/nonlinear-embedding/#怎麼用怎麼判讀)；科1指引5-5、科3指引5-6；距離與群數判讀依教材補充 |
| 採樣後分數大幅上升（補充） | 採樣是否越過切分、合成點是否合理 | SMOTE 只在每個訓練摺使用；評估保留原分布 | [SMOTE 少數類別合成](/concepts/smote/#採樣放在哪裡補充)；教材所列 imbalanced-learn 文件 |
| 各摺分數差距大 | 該摺組成與極端值 | 合看平均、波動及最低摺；標準差不是信賴區間 | [K-fold 交叉驗證](/concepts/k-fold-cross-validation/#怎麼判讀-k-個分數)；科3指引5-26、5-29；個別摺排查與信賴區間界線依教材補充 |
| 搜尋後直接把最佳驗證分數當最終成績（補充） | 同一批分數是否已用於挑設定 | 內層選參、外層評估流程，或保留獨立測試；單摺內外分數可反轉，不用外層反覆挑設定 | [巢狀交叉驗證](/concepts/nested-cross-validation/#走一次流程補充)、[訓練集、驗證集與測試集切分](/concepts/train-val-test-split/#三份資料如何配合)；教材所列 scikit-learn、Inria 巢狀驗證文件 |
| 切摺前已補值、縮放或降維（補充） | 哪些資料參與 fit，驗證是否只做 transform | 把前處理與模型放入每摺 Pipeline；切分前已洩漏的特徵仍須重建，群組與時間另設邊界 | [資料洩漏](/concepts/data-leakage/#直覺補充)、[scikit-learn Pipeline](/concepts/sklearn-pipeline/#走一次流程補充)；教材所列 scikit-learn 洩漏與 Pipeline 文件 |
| 要用過去預測未來（補充） | 擴張或固定窗口、列順序及標籤何時完整可得 | 只用當時可得資料訓練；相同驗證時段比較窗口，前處理仍限訓練段，最終測試留在更晚時段 | [時間序列切分與滾動驗證](/concepts/time-series-split/#走一次流程補充)；教材所列 scikit-learn TimeSeriesSplit 文件 |
| 殘差有曲線或時間規律（補充） | 曲線中心、散布寬度及按時間排列的殘差 ACF | 分別查非線性、變異不齊與時間結構；圖形不唯一決定原因，不能直接指定 ARIMA 的 p/q，修改後須按時間驗證 | [殘差分析](/concepts/residual-analysis/#圖形對照與下一步補充)、[殘差分析](/concepts/residual-analysis/#時間序列殘差與白噪音補充)；教材所列 NIST 與 Forecasting: Principles and Practice 文件 |
