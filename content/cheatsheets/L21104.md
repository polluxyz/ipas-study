## 公式

| 用途 | 公式與符號 | 條件與限制 | 來源／教材 |
|---|---|---|---|
| 圖文方向比較（補充） | $s(\mathbf{x},\mathbf{t})=\mathbf{x}^{\mathsf T}\mathbf{t}/(\|\mathbf{x}\|_2\|\mathbf{t}\|_2)$；$\mathbf{x}$、$\mathbf{t}$ 是圖、文向量，$\mathsf T$ 為轉置，$\|\cdot\|_2$ 為長度 | 兩向量須非零且維度相同；相似度不是正確率 | CLIP 原論文；[跨模態語意對齊](/concepts/cross-modal-alignment/#用餘弦相似度比較補充) |
| 兩路決策加權（補充） | $p=\alpha p_{\mathrm{img}}+(1-\alpha)p_{\mathrm{text}}$；兩個分支分數對應同一正類，$0\leq\alpha\leq1$ 是圖片權重 | 先有各分支預測；加權後不保證已校準，也不等於特徵串接 | NumPy average、融合綜述；[多模態資料、特徵與決策融合](/concepts/multimodal-fusion/#決策加權補充) |
| 語音轉寫錯誤（補充） | $\mathrm{WER}=(S+D+I)/N$；$S$＝替換、$D$＝刪除、$I$＝插入詞數，$N$＝參考詞數 | $N>0$；固定斷詞及對齊規則，可超過 100%；不是自然度 | Hugging Face WER 文件；[語音品質、WER 與延遲](/concepts/speech-quality-metrics/#wer-的分母與對象) |
| 人工聽感平均（補充） | $\mathrm{MOS}=\sum_{k=1}^{K}r_k/K$；$K$ 是有效評分數，$r_k$ 是同一問題的 1–5 分 | $K>0$；比較時固定問題與聽評條件，不能驗證內容真偽 | ITU-T P.800.1；[語音品質、WER 與延遲](/concepts/speech-quality-metrics/#mos-的平均) |
| 密集權重容量（補充） | $B_w=Nb/8$，$B_{\mathrm{total}}=B_w+B_{\mathrm{other}}$；$N$＝參數數，$b$＝每值位元，容量單位 bytes | 僅權重套用位元比例；其他用量包含激活、快取與工作區 | PyTorch Tensor.nbytes；[多模態部署優化與加速](/concepts/multimodal-deployment-optimization/#容量與吞吐補充) |
| 同一視窗的請求吞吐（補充） | $H=n/(D/1000)$；$n$＝該後端視窗內完成請求數，$D$＝視窗長度（ms），$H$ 單位 req/s | $D>0$；須說明視窗起訖；不能用平均完成間隔代替單筆等待 | NVIDIA GenAI-Perf 指標文件；[多模態部署優化與加速](/concepts/multimodal-deployment-optimization/#容量與吞吐補充) |

## 指標怎麼選

| 要驗收的交付 | 選擇 | 限制與配套 | 來源／教材 |
|---|---|---|---|
| 圖文檢索或候選分類 | 比較查詢與候選的匹配分數 | 固定圖對文或文對圖方向；要產生新圖說須另有生成路徑（補充） | 指引 3-75～3-76、CLIP 原論文；[CLIP 圖文共享表示](/concepts/clip/#怎麼用怎麼判讀)、[CLIP 圖文共享表示](/concepts/clip/#圖說生成的校正) |
| 全體分類結果 | 準確率，並對照多數類基準 | 分母是全部樣本；高分仍可能漏掉少數類 | 科目 3 指引 5-21、scikit-learn；[準確率](/concepts/accuracy/#怎麼用怎麼判讀) |
| 推薦命中或在意誤報的分類 | 精確率看預測正類中有多少正確 | 先約定正類；沒有預測正類時不能當滿分 | 指引 3-79、scikit-learn；[多模態應用與評估設計](/concepts/multimodal-application-evaluation/#零售讓每個輸出有對應物件)、[精確率](/concepts/precision/#定義與公式) |
| 情感分類需兼顧精確率與召回率 | F1；多分類先固定平均方式 | 不使用真負類，不能單憑 F1 決定業務價值（補充） | 指引 3-79、scikit-learn；[多模態應用與評估設計](/concepts/multimodal-application-evaluation/#零售讓每個輸出有對應物件)、[F1 分數](/concepts/f1-score/#怎麼用怎麼判讀) |
| 報告或摘要的參考資訊覆蓋 | ROUGE，寫明變體與匹配單位 | 高重疊不保證事實正確，另做人工內容核對（補充） | 指引 3-78～3-79、Lin ROUGE 論文；[多模態應用與評估設計](/concepts/multimodal-application-evaluation/#醫療診斷與生成是不同任務)、[ROUGE 摘要評估](/concepts/rouge/#怎麼用怎麼判讀) |
| 生成文字能否使用 | 分開評流暢性與正確性 | 保留原始評分，重大分歧回來源覆核；平均不能抵銷關鍵錯誤（補充） | 指引 3-67、教材評分規準；[生成人工評估與評分規準](/concepts/human-generation-evaluation/#匿名評分與覆核補充) |
| 語音與手勢互動 | 姿態準確率、WER、回應延遲分開量 | 另查語音與手勢是否對應同一操作，不能用分類標籤替代姿態真值 | 指引 3-79～3-80；[多模態應用與評估設計](/concepts/multimodal-application-evaluation/#互動姿態轉寫速度分開量) |
| 合成語音 | MOS 看聽感，WER 看指定轉寫鏈，延遲看等待 | 量測對象、ASR、斷詞與時間端點須一致（補充） | 指引 3-70、Hugging Face 語音課程；[語音品質、WER 與延遲](/concepts/speech-quality-metrics/#怎麼用怎麼判讀) |

## 診斷

| 現象 | 優先追查 | 判讀限制與下一步 | 來源／教材 |
|---|---|---|---|
| 新增模態後表現反而差（補充） | 配對、來源品質與噪聲 | 固定切分，比較單模態及缺失情況；增加輸入不保證改善 | 多模態綜述；[多模態任務與資料特性](/concepts/multimodal-ai/#怎麼用怎麼判讀) |
| 時間戳相同卻對不上事件 | 採樣頻率、時鐘來源與偏移 | 先查事件及時間，再選對齊；DTW 不會修復錯設備配對（補充） | 指引 3-77、3-80～3-81；[感測器融合](/concepts/sensor-fusion/#頻率與時鐘是兩件事)、[多模態資料對齊、標註與版本](/concepts/multimodal-data-alignment/#怎麼用怎麼判讀) |
| 合併流程的早晚名稱有衝突（補充） | 合併的是資料、特徵或各分支預測 | 回到流程位置判讀；特徵串接不能直接視為決策融合 | 融合綜述及指引用語校正；[多模態資料、特徵與決策融合](/concepts/multimodal-fusion/#指引的名稱校正) |
| 某路資料缺失仍輸出正常（補充） | 可用標記及核可回退路徑 | 缺失不能當有效零值；逐組驗證，並列自動覆蓋與錯誤 | HeMIS、教材回退例；[模態缺失與可靠回退](/concepts/missing-modality/#驗證全部組合補充)、[模態缺失與可靠回退](/concepts/missing-modality/#怎麼用怎麼判讀補充) |
| 融合分數高於單模態（補充） | 各路實際有效樣本與分母 | 先用同樣本共同子集比較；分母不同只能盤點 | 教材固定事件例、scikit-learn；[多模態應用與評估設計](/concepts/multimodal-application-evaluation/#先看分母再談融合補充) |
| 回覆自然卻答錯查詢 | 轉寫、意圖、查詢對象與任務結果 | 沿 ASR 到 TTS 的中介結果追查；朗讀流暢不能證明理解正確（補充） | 指引 3-76、Whisper 論文；[語音辨識、理解與回應串接](/concepts/speech-recognition-pipeline/#怎麼用怎麼判讀) |
| LoRA 更新小，裝置仍放不下（補充） | 基底權重及其他推論用量 | 更新量不等於完整模型容量；合併後仍須載入原尺寸權重 | LoRA 原論文、PEFT；[LoRA 低秩自適應](/concepts/lora/#怎麼用怎麼判讀) |
| 吞吐提高，每筆卻等更久（補充） | 批次等待與量測邊界 | 批次完成率與單筆延遲分開驗收，不能互推 | GenAI-Perf、教材批次例；[多模態部署優化與加速](/concepts/multimodal-deployment-optimization/#批次改善與單筆改善分開看補充) |
| 代理說已完成卻無結果（補充） | 工具是否執行、是否有成功憑證 | 感知、文字回覆與外部動作分開核對 | Anthropic 代理實務、教材元件表；[AI 代理的工具與記憶](/concepts/ai-agent/#定義與公式) |
| 遮住人臉後仍能辨認個人（補充） | 聲音、時點、共同索引與聯結結果 | 檢查整條資料流及輸出權限，不能只看單張遮罩圖 | NIST Privacy Framework；[跨模態隱私與系統安全](/concepts/multimodal-privacy-security/#把風險接到控制) |
| 影音逼真、偵測也未示警（補充） | 發布者、原始證據與獨立核驗 | 偵測未命中不能證明真實；來源憑證也不保證事實 | GAO、C2PA；[虛假生成內容與深偽](/concepts/synthetic-content-authenticity/#偵測與來源驗證的界線) |
| 整體分數好，少數群體仍受不利影響 | 資料來源、標註、目標與決策流程 | 分群差距先作調查線索，追查傷害與處置責任 | 指引公平性內容；[演算法偏見與歧視影響](/concepts/algorithmic-bias/#定義與公式) |
| 已有素材授權卻說不清發布範圍 | 素材、模型條款與輸出用途 | 分層核對並留下證據；生命週期清單接回實際控制與處置（補充） | 指引 3-82～3-83、教材生命週期清單；[生成素材授權與來源追溯](/concepts/generative-content-rights/#定義與公式)、[生成與多模態 AI 治理查核](/concepts/generative-ai-governance/#生命週期清單) |
