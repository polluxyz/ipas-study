## 為什麼需要

字面重疊無法完整判斷語意、語用或文稿是否適合使用。人工評估（Human Evaluation）讓人查看候選，分別判斷讀起來是否自然、內容是否符合事實與任務。

指引常用1至5分或排序法，應用於對話、創意寫作與專業文稿。人工能看細節，但主觀差異與成本也較高，需要清楚的評分規準。

## 直覺

把「好不好」拆成兩個問題：文字能否順暢理解，以及內容能否由依據支持。同一段文字可在流暢度拿高分，在正確性拿低分。

:::supplement[來源：OpenAI Evaluation best practices]
規準中的每個分數應附可觀察的描述，稱為評分錨點（Scoring Anchor）。先用少量例子校準，再評新候選，比只寫「1很差、5很好」更容易對齊判斷。
:::

## 定義與公式

流暢性（Fluency）看語法與閱讀自然度；正確性（指引稱準確性，Accuracy）看內容是否符合事實或上下文。本頁統一用「正確性」。

打分表達各維程度，排序則表達同一任務中的相對偏好。

### 本組1至5分錨點（補充）

下表是教學設計，兩維分開判斷。評分者可看來源、任務與候選，但先不看候選來自哪個系統。

| 分數 | 流暢性 | 正確性 |
|---|---|---|
| 5 | 自然清楚，無需修改 | 關鍵條件全對，必要資訊完整 |
| 4 | 少量措辭可改善 | 無錯誤，但有不影響核心的小缺漏 |
| 3 | 能理解，需明顯調整 | 有次要錯誤，核心結論仍可用 |
| 2 | 多處不順，理解受阻 | 缺重要內容，無法完成任務 |
| 1 | 重複破碎，難以理解 | 核心條件矛盾或關鍵主張無依據 |

本組將錯誤期限、錯誤上課方式列為關鍵錯誤，必須修正，不以平均分抵銷。創意任務可另定原創性等規準，但不能偷偷改變正確性的意義。

### 分維平均（補充）

同一候選、同一維度，可用算術平均整理兩位評分者的分數：

$$
\bar{s}_d=\frac{s_{1,d}+s_{2,d}}{2}
$$

$d$代表維度，$s_{1,d},s_{2,d}$是兩人的該維分數。這只是描述性摘要，不表示1到5分具有經驗證的等距尺度，也不是通過驗收的條件。

## 走一次流程

使用 `L21103-C-generation.json` 的 CS01：來源是三日回覆。A保留三日但省略受詞，B寫成一日；兩位評分者與分數皆為合成，不能當作真實使用者研究。

### 匿名、評分與覆核（補充）

1. 按固定規則把A、B顯示成Q、P；其他樣本交換順序，平衡位置。
2. 兩人先獨立看同份來源，再依兩維錨點評分，不互看分數。
3. 保留原始分數與證據，不只保留平均數。
4. 分歧回到來源與錨點；關鍵錯誤先修正，再由人工確認。

| 候選 | R1：流暢／正確 | R2：流暢／正確 | 分維平均 |
|---|---|---|---|
| A，顯示Q | 4／4 | 5／4 | 4.5／4.0 |
| B，顯示P | 5／1 | 5／3 | 5.0／2.0 |

A的流暢平均為$(4+5)/2=4.5$，正確平均為$(4+4)/2=4$。B的流暢平均5、正確平均2；B的高流暢分不會消除「一日」這個錯誤。

四組「候選×維度」的兩人差距依序為1、0、0、2。共有2組不一致，1組差距至少2分；本組把後者列為重大分歧，需覆核。

B的R2正確性3分是刻意保留的校準前誤判：期限屬核心條件，應依1分錨點處理。覆核依來源採1分，保留原始1／3分及修正理由，不偷偷改掉資料。

### 匿名排序的例子（補充）

若任務先要求事實正確，再比較文稿品質，CS01應排Q優於P，即A優於B；不是因為候選名稱，而是Q保留三日期限。若兩者都不符合硬條件，可一起退回，不必硬選一個發布。

教育 ED01也用相同規準：A的「舉行」是正確改寫，B的「實體」違反來源。不能因兩者ROUGE-1相同，就把正確性評成相同。

## 程式（補充）

標準函式庫直接核算原始分數。從repo根目錄執行，或設定`IPAS_REPO_ROOT`；這段沒有啟動評分服務，也沒有請模型扮演人類評分者。

```python
import json, os
from pathlib import Path
root = Path(os.environ.get("IPAS_REPO_ROOT", "."))
rows = json.loads((root / "content/examples/L21103-C-generation.json").read_text(encoding="utf-8"))["examples"]
s = next(x for x in rows if x["id"] == "CS01")
diffs = []
for key, item in s["candidates"].items():
    r1, r2 = item["ratings"]
    means = [(r1[d] + r2[d]) / 2 for d in ("fluency", "accuracy")]
    diffs.extend(abs(r1[d] - r2[d]) for d in ("fluency", "accuracy"))
    print(key, *(f"{v:.1f}" for v in means))
print("分歧:", sum(d > 0 for d in diffs), "/", len(diffs))
print("重大分歧:", sum(d >= 2 for d in diffs), "/", len(diffs))
print("CS01匿名順序:", s["anonymous_order"])
```
```text
A 4.5 4.0
B 5.0 2.0
分歧: 2 / 4
重大分歧: 1 / 4
CS01匿名順序: {'P': 'B', 'Q': 'A'}
```

:::tip[讀碼重點]
分母4是兩個候選各有兩個維度，不是4篇文件。差距至少2分是本組預設的覆核規則，不是跨任務通用的統計門檻。
:::

## 怎麼用、怎麼判讀

對話要看語意與語用，專業文稿還要查事實與上下文。創意寫作可用排序比較整體偏好，但規準與任務需先說清楚。

### 分歧與成本管理（補充）

各領域先用01–08校準規準，再用09–12保留測試。若看到測試結果後才修改錨點，應另找未使用的例子驗證；本組資料只示範流程，不估計真實平台表現。

可先用自動指標篩查，再按風險抽樣人工審查，對重大分歧安排覆核。對高風險內容不能只抽查高分者，還要涵蓋困難與失敗案例。

24筆、每筆2候選、2評分者，共需96次候選閱讀；每次記2維，共192個維度評分。這是排程工作量，不含校準與覆核時間。

### 換個場景

| 場景 | 資料條件 | 評分重點 |
|---|---|---|
| 對話、創意寫作 | 有語意與語用需求 | 自然度、適切性與相對偏好 |
| 專業文稿 | 有事實或上下文要求 | 由合適的人核對內容 |
| 客服通知（補充） | 時限與承諾不可改 | 分開評流暢與關鍵正確性 |
| 教育教材（補充） | 學習目標與程度固定 | 查內容、難度及誤導風險 |

## 常見誤解

- 「人工評估必然客觀。」主觀差異仍會存在，規準用來使判斷更清楚。
- 「兩人平均就沒有分歧。」平均數可能掩蓋重要錯誤，原始分數仍要保留。（補充）
- 「匿名後就完全沒有偏差。」匿名只減少部分線索，順序與規準仍需控制。（補充）
- 「高流暢分可補低正確分。」關鍵事實須獨立符合驗收條件。（補充）

## 進階

### 本頁不把模型評分當成人工（補充）

由另一個模型當裁判，可以協助擴大檢查，但不是人類受試者。若採模型評分，仍需與人工判斷校準，並說明評分模型與規準；本頁只重播合成人工評分資料。

## 小結

- 人工評估分別看流暢性與內容正確性。
- 用具體的1至5分錨點，或依任務安排排序。（補充）
- 匿名比較後保留原始評分，以來源與規準處理分歧。（補充）
- 成本包含閱讀、校準與覆核，不能只數文件數。（補充）
