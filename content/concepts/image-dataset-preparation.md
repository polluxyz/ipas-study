## 為什麼需要

分類模型只能學到資料提供的規則。若圖片模糊、重複或標錯，即使程式順利訓練，得到的成績也可能沒有實際意義。

指引把清洗、分層抽樣與圖像編碼列為進階資料處理，接著介紹影像分類流程。本頁把兩者接起來：先確認資料可信，再交給模型學習。

## 直覺

整張圖判類的任務，英文稱為Image Classification。收集與標註決定「學什麼」，前處理決定「模型讀到什麼」，驗證則檢查「能否用在未見資料」。

![先清洗並隔離來源，再用一致輸入契約訓練與驗證；同源影格或增強變體不跨集合。](figure:l21102-image-dataset-preparation-flow)

:::supplement[來源：TensorFlow影像分類教學；scikit-learn交叉驗證文件]
圖中的測試隔離與來源分組是補充的評估界線。分類步驟本身不能防止資料洩漏，還要保留來源、切分與轉換紀錄。
:::

## 定義與公式

清洗處理不能用或不可信的圖片；分層抽樣檢查類別分布；編碼把圖片轉成模型可處理的表示。它們分別解決品質、分布與輸入格式問題。

### 張量與嵌入的分工

指引提到張量（Tensor）與嵌入向量（Embedding），例如CLIP嵌入。兩者不能只因都以數字儲存，就視為同一種輸入意義。

:::supplement[來源：PyTorch資料載入教學；Keras影片分類教學]
| 表示 | 來源與內容 | 用途 |
|---|---|---|
| 像素張量 | 解碼、排軸與轉型後的像素 | 送進CNN等影像編碼器 |
| 特徵嵌入 | 模型把影像轉成固定維向量 | 相似搜尋、下游分類等 |

把4×4圖展平成16個數字，仍只是像素重排，沒有因此取得語意。嵌入的意義依編碼器、訓練資料與任務而定；其實作通常也存成張量。
:::

## 走一次流程

### 收集與標註

本組合成零售與製造各12張4×4灰階圖，分別判斷封口與表面是否異常。先定義正常、異常的界線，每張圖保存類別、來源與品質資料。

:::supplement[來源：共用例子L21102-D-vision.json；TensorFlow影像分類教學]
兩域各自建分類任務，不把「封口異常」與「表面異常」視為同一種實際物件。共用索引與種子21102只方便核對，不能證明兩域模型可直接互換。
:::

### 清洗後重新盤點

指引的清洗做法是去除模糊、重複、標錯或低品質的圖片。

:::supplement[來源：共用例子L21102-D-vision.json；資料品質的可追溯修正示範]
若能確認正確類別，修正標籤也是可選的補充做法，並非指引原列的處置。

以下以製造域為例；零售域使用RD前綴，處置相同。類別與切分以清理後的標籤為準，不覆寫原始像素與原標籤紀錄。

| 圖片 | 問題 | 處置與交付物 |
|---|---|---|
| MD11 | 過度模糊、缺乏可判別細節 | 排除並記品質原因 |
| MD12 | 像素與MD01完全相同 | 去重、保留來源指向 |
| MD10 | 正常被標錯，審查確認異常 | 修正衍生標籤並記原因 |
| MD01 | 偏暗且有孤立亮點 | 保留原圖，另記畫質轉換 |

每域原本正常9、異常3。排除兩張正常圖後為7、3；修正一張標籤後為6、4，共10張。修得回的亮度與可信細節，不必一律用刪圖處理。
:::

### 切分前後的類別數（補充）

| 集合 | 正常 | 異常 | 合計 |
|---|---|---|---|
| 清理後全體 | 6 | 4 | 10 |
| 訓練：MD01–04、MD07、MD08 | 4 | 2 | 6 |
| 驗證：MD05、MD09 | 1 | 1 | 2 |
| 測試：MD06、MD10 | 1 | 1 | 2 |

表中編號與清理表一致；JSON的索引從0起算，例如索引0是MD01。已修正標籤的MD10（索引9）屬測試集，類別與切分在訓練前固定，不依測試分數改標籤。

分層的目的是盡量保留類別比例，不會自動平衡成各半。10張中異常占40%，訓練占約33.3%，驗證、測試各50%；小樣本受整數張數限制，不能要求完全相同。

本快照清理後沒有同域跨集合的完全相同像素；實務仍須查近似圖與來源相依。兩段影片全部標為訓練示範來源，不併入這10張的獨立評估。

### 前處理、模型、訓練與驗證

整理完資料後，依序固定大小、做像素正規化、選分類模型、用訓練資料學參數，再用驗證資料評估。CNN是常見選項，能學局部影像特徵。

### 每步留下什麼（補充）

| 步驟 | 本例行動 | 交付物 |
|---|---|---|
| 收集、標註與清洗 | 定義兩類，處理三種問題圖 | 標籤表、排除及修正紀錄 |
| 切分與前處理 | 固定6／2／2及尺寸、通道、尺度 | 來源清單、轉換版本 |
| 模型選擇 | 各域先建小型二類CNN基線 | 結構、輸出與損失設定 |
| 訓練 | 只用訓練集學權重、合理增強 | 權重、種子、訓練曲線 |
| 驗證與定案 | 比較設定、查錯誤，鎖定後測試 | 驗證報告、完整推論契約 |

MD01採中值後Gamma，再除255，像素尺度與Grad-CAM頁一致。其他圖片也使用同一個鎖定的轉換，不能只有測試時才臨時修圖。

### 評估時看哪些錯誤

指引列出準確率、Top-5錯誤率與混淆矩陣。混淆矩陣呈現真實類別與預測類別的交叉計數，可用來看哪兩類最常混淆。

:::supplement[來源：共用例子L21102-D-vision.json；scikit-learn交叉驗證文件]
本例只有二類，Top-5無法提供有用區別。先看準確率與各類召回率，再用混淆矩陣分辨正常誤報與異常漏報；這麼小的教學資料只能檢查流程，不能作為上線品質的證明。
:::

## 程式

### 清理計數與張量形狀（補充）

先把環境變數`IPAS_REPO_ROOT`設為目前repo的絕對路徑。程式讀共用快照，僅核對標籤、索引和張量形狀，不訓練分類器。

```python
import json, os, numpy as np
from pathlib import Path
np.random.seed(21102)
d = json.loads((Path(os.environ["IPAS_REPO_ROOT"]) / "content/examples/L21102-D-vision.json").read_text(encoding="utf-8"))
rows = d["domains"]["manufacturing"]["images"]
print("原始類別數:", np.bincount([r["class_label"] for r in rows]).tolist())
clean = [r for r in rows if r["split"] != "excluded"]
print("清理後類別數:", np.bincount([r["reviewed_label"] for r in clean]).tolist())
for split, ids in d["split_indices"].items():
    chosen = [rows[i] for i in ids]
    x = np.array([r["pixel_array"] for r in chosen], dtype=np.float32)[:, None] / 255
    print(split, np.bincount([r["reviewed_label"] for r in chosen]).tolist(), x.shape)
```
```text
原始類別數: [9, 3]
清理後類別數: [6, 4]
train [4, 2] (6, 1, 4, 4)
validation [1, 1] (2, 1, 4, 4)
test [1, 1] (2, 1, 4, 4)
```

:::tip[讀碼重點]
`class_label`保留原始標記，`reviewed_label`是審查後的監督資料。`[:, None]`在批次後插入通道軸；這段只檢查解碼、排軸與縮放，完整MD01畫質轉換見前頁。
:::

## 怎麼用、怎麼判讀

資料不平衡時，要檢查每個集合的類別數；圖片模糊、重複、標錯時，要先清理。若任務是整圖分類，輸出是類別；需要位置或像素範圍，則要改用相應視覺任務。

### 換個場景

| 場景 | 準備重點 | 驗證重點 |
|---|---|---|
| 不平衡影像分類 | 清洗、分層檢查、適當編碼 | 別讓少數類在切分後消失 |
| 物件或場景整圖分類 | 每張圖片的類別標籤 | 模型輸出與標籤定義一致 |
| 零售包裝（補充） | 保存同商品、同拍攝來源 | 新商品或新批次的表現 |
| 製造表面（補充） | 保存產線與批次、瑕疵準則 | 新批次及低光源錯誤 |
| 醫療分類（補充） | 同病人的圖片整組處理 | 不以同病人不同張冒充獨立 |

## 常見誤解

- **分層後每類數量一定相同。** 分層通常維持比例，並非重取樣平衡類別。（補充）
- **轉成張量就有語意嵌入。** 張量是資料容器，語意表示要看編碼器怎麼產生。（補充）
- **標錯只能刪圖。** 指引列的是去除標錯圖；能確認正確類別時，修正衍生標籤並保留追溯紀錄，是補充做法。
- **驗證準確率最高就能上線。** 還要看錯誤分布、獨立測試、部署條件與任務成本。（補充）

## 進階

### 由資料檢查接到熱區檢查（補充）

固定前處理與模型版本後，可以用Grad-CAM檢查某次分數主要對應哪些區域。若熱區落在亮點或背景，回頭查來源與轉換；不能用一張合理的熱圖取代整體驗證。

## 小結

- 清洗、分層與編碼分別檢查品質、分布與輸入。
- 分類依序完成收集標註、前處理、選模型、訓練與驗證。
- 分層不保證各類均等，像素張量也不等於語意嵌入。（補充）
- 留下每步版本與來源，才能回頭解釋錯誤。（補充）
