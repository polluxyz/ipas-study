## 為什麼需要

如果招聘訓練資料大多來自同一群體，模型會較少看見另一群的履歷變化。前處理去偏（Pre-processing）在訓練前處理這種代表性問題。

它也檢查敏感欄位與相關特徵。只移除性別或族群，仍可能留下能推知群體的資訊。

## 直覺

訓練資料像練習題庫。某一類只有4題，重複練到16次可增加它的影響，但不會把4種經驗變成16種新經驗。

因此要分開問兩件事：模型看到各群多少次，以及資料是否真的涵蓋各群的不同情況。

## 定義與公式

| 方法 | 改動內容 | 主要限制（補充） |
|---|---|---|
| 過採樣 | 增加少數群訓練樣本的出現次數 | 重複樣本不等於新資訊 |
| 欠採樣 | 減少過多群體的訓練樣本 | 可能丟掉有用變化 |
| 特徵去偏 | 移除或調整敏感與相關特徵 | 代理資訊可能仍存在 |
| 資料匿名化與泛化 | 例如把年齡改為年齡區間 | 隱私處理不保證群體公平 |
| 固定重加權（補充） | 改每筆資料在訓練中的影響 | 需確認學習器採用權重 |

指引也把資料匿名化與泛化列為前處理；年齡區間的作法可接著讀隱私泛化與分桶。

:::supplement[來源：Google Machine Learning Crash Course，Mitigating bias；AIF360，Reweighing]
資料增強可加入合理變化，但須確認轉換後標籤仍成立。群體少不等於正類少，不能只平衡正負例就宣稱群體代表性已改善。
:::

## 走一次流程

### 先看群體乘標籤（補充）

共用招聘與信貸檔各有獨立訓練40筆，與固定稽核集的ID不重疊。保留A群，將B群的正、負例分別有放回抽到16筆，種子固定23402。

| 群體×真值 | 原訓練筆數 | 重抽樣筆數 | 仍有多少原始個案 |
|---|---|---|---|
| A×正 | 16 | 16 | 16 |
| A×負 | 16 | 16 | 16 |
| B×正 | 4 | 16 | 至多4 |
| B×負 | 4 | 16 | 至多4 |

總訓練筆數從40變成64。固定稽核集仍是40筆，每群20筆；它的標籤、分數與索引都不跟著重抽樣。

### 分辨敏感、代理與必要特徵

| 欄位角色 | 招聘例子 | 信貸例子 | 檢查方式 |
|---|---|---|---|
| 敏感特徵 | 群體欄 | 群體欄 | 決策用途與稽核權限分開管理 |
| 代理特徵 | 居住區域 | 居住區域 | 看能否推知群體及影響結果 |
| 任務必要特徵（補充） | 職務測驗 | 還款能力資料 | 查與任務的關聯及測量品質 |

:::supplement[來源：Fairlearn，Preprocessing；Google Machine Learning Crash Course，Mitigating bias]
合成資料的區域欄能猜對36/40人的群體。另用「只讓區域甲通過」作反例：不讀性別或族群欄，A選取18/20＝90%，B僅2/20＝10%，仍差80個百分點。

這是另一條示意規則，不是原模型的預測。必要特徵也要檢查測量品質；它與任務相關，不代表對各群都量得準。

線性去相關把特徵中能由群體線性預測的部分扣掉。它只處理指定的線性關係，不能保證非線性代理資訊也消失；修改後仍需分群復評。
:::

### 改善幅度怎麼報（補充）

下面是共用檔的**假想重訓輸出**，不是重抽樣程式實測的預測。它示範報告方式；真實改善必須重訓後另行驗證。

| 固定稽核集指標 | 修改前 | 假想修改後 | 差異 |
|---|---|---|---|
| A／B的FPR | 20%／60% | 20%／40% | 差距縮小20個百分點 |
| A／B的TPR | 80%／80% | 80%／80% | 不變 |
| 整體準確率 | 28/40＝70% | 30/40＝75% | 增加5個百分點 |

若FPR差縮小但少數群的TPR下降，也要一併報告。不能只展示變好的指標，或由訓練數量直接推測測試效能。

## 程式（補充）

依共用檔規則重建獨立訓練資料；正負例各自重抽樣。輸出的是資料筆數，沒有訓練模型或宣稱公平達標。

```python
import random
from collections import Counter
rng = random.Random(23402)
train = [(g, y, i) for g, n in [("A", 16), ("B", 4)]
         for y in [1, 0] for i in range(n)]
resampled = []
for g in "AB":
    for y in [1, 0]:
        cell = [r for r in train if r[:2] == (g, y)]
        resampled += cell if g == "A" else rng.choices(cell, k=16)
for label, data in [("抽樣前", train), ("抽樣後", resampled)]:
    counts = Counter((g, y) for g, y, i in data)
    print(label, [counts[(g, y)] for g in "AB" for y in [1, 0]])
print("固定稽核筆數:", 40)
```
```text
抽樣前 [16, 16, 4, 4]
抽樣後 [16, 16, 16, 16]
固定稽核筆數: 40
```

:::tip[讀碼重點]
`choices` 是有放回抽樣；種子固定讓抽樣索引可重現。不能把它套在測試集，或把相同個案分散到訓練與測試兩邊。
:::

## 怎麼用、怎麼判讀

指引用招聘履歷數量平衡，以及銀行移除族群與相關特徵說明前處理。適合先查資料代表性不足、或特徵可能帶入群體偏見的情況。

### 換個場景

| 場景／資料條件 | 判讀重點 |
|---|---|
| 招聘群體數量懸殊 | 群體與資格交叉表，不能只看總人數 |
| 銀行敏感與高度相關欄位 | 刪除直接欄後仍需檢查代理資訊 |
| 醫療設備資料（補充） | 補足少見設備與群體組合的覆蓋 |
| 多語客服（補充） | 新增真實語句變化，避免只複製同一句 |

:::supplement[來源：Fairlearn，Preprocessing]
前處理改的是下一次訓練的輸入。沒有重訓，已部署模型不會因資料筆數改變而自動更新。
:::

## 常見誤解

- 刪除敏感特徵不會自動清除所有相關資訊。
- 複製少數群資料可增加影響，但不等於增加新的樣本來源。
- 匿名化主要處理隱私，不能由此保證群體公平。（補充）
- 分群復評仍需群體資訊，應與一般推論輸入分開管理。（補充）

## 進階

### 重加權與重抽樣（補充）

重抽樣改出現次數；重加權改每次出現的影響。AIF360的Reweighing以群體與標籤交叉組合設計權重，不是只增加少數正類的權重。

## 小結

- 先看群體與標籤交叉分布，再選抽樣或特徵調整。
- 原測試分布保留，重訓之後才量改善。（補充）
- 直接欄位消失，代理資訊仍可能存在。
- 資料數量平衡只是起點，仍須檢查分群結果。
