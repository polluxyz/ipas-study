## 為什麼需要

資料少、樣式單一時，模型可能記住拍攝方式、字詞或背景聲。資料增強（Data Augmentation）從已有資料產生合理變化，增加訓練多樣性，減少過擬合。

指引列出影像、文字與音訊的多種方法，也提醒不當變換會改變原本語意或標註。先確定要預測什麼，才能判斷哪種變換安全。

利用既有資料產生變體，可以節省額外採集實際資料的費用。

:::supplement[來源：TensorFlow資料增強教學]
增加輸入次數不等於增加獨立來源，也不能取代新族群或新設備的真實資料。
:::

## 直覺

增強是在問模型：「同一件事換一種外觀或表達，你還認得嗎？」如果換完已經不是同一件事，就不能繼續沿用原答案。

### 來源數與輸入次數（補充）

本組製造、零售各16張原圖，每域12張訓練。24張訓練圖各加一個版本，會形成48次輸入；原始來源仍只有24個。

本合成快照僅用來核對變換與計數，部分不同ID的像素完全相同，且跨集合重複。不可據此估計獨立泛化表現；不同ID本身不保證資料獨立。

## 定義與公式

資料增強對既有資料做變換，以增加可學習的樣式。它可以配合訓練即時產生，不必預先存出所有版本；變體數量越多，處理與儲存成本也可能增加。

### 三模態怎麼選

| 資料 | 指引列出的方法 | 指引列出的場景 |
|---|---|---|
| 影像 | 旋轉、平移、翻轉、縮放、裁切、亮度、色彩變換與雜訊 | 人臉辨識、醫學影像分析 |
| 文字 | 同義字替換、隨機插入、刪詞、打亂詞或句順序 | 情感分析、主題分類、對話模型 |
| 音訊 | 語速、音量、背景音、局部靜音 | 指引未為音訊方法另列領域例子 |

指引5-9另列時序資料擾動；5-10把SMOTE放在表格式資料增強，5-48則將它列為重取樣中的過採樣。兩處都在說明合成少數類別樣本，以處理類別不平衡。

本頁聚焦影像、文字與音訊的語意保留；時序擾動和SMOTE的適用條件另見專頁，不能直接套用影像翻轉。

### 三種標籤處置（補充）

有些變換可保留分類標籤；有些必須同步改標註，例如幾何改變後的框、遮罩與方向。若變體沒有可信的合法標籤，就拒絕該次變換，而不是讓模型猜。

影像增強與標籤語意頁集中說明幾何與色彩細節。以下只檢查跨模態共通的「變完還代表原本意思嗎」。

## 走一次流程

### 從原始來源到可評估的資料流（補充）

1. **先定標籤：** M01判斷有無刮痕，R01判斷F字形，R09還要判斷箭頭方向；三者的允許變換不同。
2. **按來源切分：** 每域索引0–11訓練、12–13驗證、14–15測試。原圖與任何變體都繼承來源集合，不重新洗牌。
3. **只增強訓練：** 訓練使用合理隨機變換，再套模型要求的固定尺寸與像素轉換。驗證與測試只套相同契約的固定轉換。
4. **抽查標籤：** M01左右翻轉仍有刮痕，框由`[1,2,3,6]`改為`[5,2,7,6]`，遮罩也翻；F鏡像不沿用F，右箭頭翻後須重判方向。
5. **用固定驗證集比較：** 測試集留到設定鎖定後；若另測擾動耐受度，獨立報告，不用最好一次成績取代主評估。

M01裁成只有右半張時，8格刮痕全不見了。這不是「更難的正例」，而是物件存在性已改變；應拒絕裁切或依任務規則重標。

### 換成文字與聲音（補充）

共用評論「商品不容易故障」的標籤為正面。改成「商品不容易損壞」仍保留原意；刪掉「不」成為「商品容易故障」，情感卻轉為負面，不能沿用標籤。

口令內容辨識可嘗試調低音量，但要仍聽得出原口令。共用波形`[0,0.4,−0.4,0]`乘0.5成`[0,0.2,−0.2,0]`；若任務是判斷「原音量是否過低」，這個變換就可能改變標籤。

## 程式

### 讀出兩條transform流程（補充）

以下刻意使用「方向無關的刮痕有無」任務；不直接套到F字形。固定種子讓第一次訓練翻轉可重現，驗證與測試則不抽亂數。

```python
import numpy as np
rng = np.random.default_rng(23301)
def transform(a, split):
    flip = split == "train" and rng.random() < 0.5
    out = np.flip(a, axis=1) if flip else a.copy()
    return out.astype(float) / 255, bool(flip)
x = np.full((8, 8, 3), 32, dtype=np.uint8)
x[2:6, 1:3] = [255, 0, 0]
x[:2, :2] = np.repeat([0, 85, 170, 255], 3).reshape(2, 2, 3)
for split in ["train", "validation", "test"]:
    z, flipped = transform(x, split)
    print(split, flipped, f"left={z[2, 1, 0]:.3f}, right={z[2, 6, 0]:.3f}")
```
```text
train True left=0.125, right=1.000
validation False left=1.000, right=0.125
test False left=1.000, right=0.125
```

:::tip[讀碼重點]
短路條件讓驗證與測試不抽翻轉亂數，但三個集合都會除255。若把隨機操作放到`if`外，或三個集合都傳`train`，就失去這條界線。
:::

## 怎麼用、怎麼判讀

指引把資料量不足、類別分布不均與多變環境列為考量，也列出人臉、醫療、情感、主題與對話模型場景。增強可能提高泛化，但不保證每種變換都有幫助。

:::supplement[來源：TensorFlow資料增強教學；EDA論文；Torchaudio資料增強教學]
先列出不能改變的語意，再選最小合理擾動。影像中的鏡像F、文字中的否定詞、音訊中的關鍵口令，都是應先保住的訊號；只有檔案長度或陣列形狀合法還不夠。
:::

### 換個場景

| 場景 | 使用方向 |
|---|---|
| 人臉與醫學影像 | 指引列出影像變換 |
| 情感、主題、對話 | 指引列出文字變換 |
| 設備故障、股市趨勢 | 指引列出時序擾動 |
| 製造瑕疵（補充） | 模擬光照與位置差異，不能抹掉缺陷 |
| 零售OCR（補充） | 微調拍攝外觀，鏡像字不沿用原標籤 |

:::supplement[來源：Torchaudio資料增強教學]
音訊可換成口令辨識：用適量背景音模擬環境，但保留可聽辨的口令。反之，音量過低檢測不適合任意調音量；聲音來源辨識也不能把辨識目標當作背景刪掉。
:::

## 常見誤解

- **增強越多，模型一定越好。** 指引提醒變換可能破壞標註，也可能增加成本。
- **刪字只是表達方式變了。** 刪掉否定詞可能讓評論情感反轉。（補充）
- **先做變體再隨機切分就公平。** 同源副本可能跨集合，評估會變得過度樂觀。（補充）
- **影像只做固定縮放就算有多樣性。** 固定前處理是在統一輸入，不會自動產生不同觀測版本。（補充）

## 進階

### 主評估與壓力測試分開（補充）

固定驗證流程用來公平比較設定。若想測部署端的噪音或模糊耐受度，可以預先定義擾動條件另外測試；不能反覆擾動測試集，再挑最高分當成獨立成績。

## 小結

- 增強增加訓練樣式，仍要保留任務的語意與標註。
- 影像、文字與音訊各有方法，不能只照名稱套用。
- 同源變體留在同一集合，訓練隨機、主評估固定。（補充）
- 變體不能取代未收集的新族群或真實部署驗證。（補充）
