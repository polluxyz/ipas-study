## 為什麼需要

影像含有顏色，但任務未必需要所有顏色訊號。只看輪廓的辨識可以考慮簡化輸入；依顏色分類的任務，則需要保留區別顏色的資訊。

指引列出紅綠藍（RGB）、灰階（Grayscale）與HSV之間的轉換，強調依任務調整通道結構。灰階常用於簡化輸入，不能因此推論它對每種任務都合適。

## 直覺

### 換表示，還是丟資訊

RGB用紅、綠、藍三個分量描述每格顏色。HSV改用色相（Hue）、飽和度（Saturation）、明度（Value）三個分量；灰階則把三個分量壓成一個數。

同一R01的F字可以換成以下表示。HSV的三通道在圖上各自畫成灰深淺，方便觀察數值；它們不是三張自然灰階照片。

![同一F字的RGB、灰階與HSV通道對照，注意灰階可能使紅字和綠字變成同一數值。](figure:l23301-color-space-conversion-channels)

## 定義與公式

### 三種表示的差異

| 表示 | 通道 | 保留與限制 |
|---|---|---|
| RGB | 紅、綠、藍 | 保留三個色彩分量，亮度與色彩混在分量內 |
| 灰階 | 一個加權值 | 簡化輸入，通常不能還原原色 |
| HSV | 色相、飽和度、明度 | 分開描述顏色屬性，不保證光照不變性 |

:::supplement[來源：OpenCV Color conversions]
採OpenCV列出的RGB轉灰階加權式：

$$
Y=0.299R+0.587G+0.114B
$$

$R,G,B$是同一像素的紅、綠、藍分量，$Y$是加權灰階值；本例分量皆為0到255。存成8位元時需要量化，這裡四捨五入為整數。

HSV的色相常用角度表示，飽和度描述濃淡，明度是RGB縮放分量的最大值。無彩色區飽和度為0，色相不具區分意義；函式可能依約定回傳0。
:::

## 算一次

### 兩個不同顏色為何撞在一起（補充）

共用資料R01的F字是紅色`[255,0,0]`，R02同字形為綠色`[0,130,0]`。兩張的背景相同，可單獨比較字體顏色。

1. 紅字：0.299×255＝76.245，量化後為76。
2. 綠字：0.587×130＝76.31，量化後也為76。
3. 灰階圖的字形仍存在，但已無法憑這個值區分紅字與綠字。

RGB分量除255再轉成HSV：紅字為`(0°,1,1)`，綠字為`(120°,1,0.510)`，依序是色相、飽和度與明度。兩者仍可區分；只留一個通道則可能丟失資訊。

製造M01紅色刮痕也用同一轉換。如果要判斷的是「有無刮痕」，灰階可能足夠；若要區分靠色差辨識的瑕疵種類，就得另外驗證。

## 程式

### 核對通道數、量化與HSV範圍（補充）

```python
import colorsys
import numpy as np
rgb = np.array([[255, 0, 0], [0, 130, 0]], dtype=float)
gray = rgb @ np.array([0.299, 0.587, 0.114])
print(np.round(gray, 3).tolist())
print(np.rint(gray).astype(int).tolist())
for p in rgb / 255:
    h, s, v = colorsys.rgb_to_hsv(*p)
    print(f"H={360*h:.1f}, S={s:.3f}, V={v:.3f}")
```
```text
[76.245, 76.31]
[76, 76]
H=0.0, S=1.000, V=1.000
H=120.0, S=1.000, V=0.510
```

:::tip[讀碼重點]
`colorsys`的H回傳0到1，本例乘360顯示角度。OpenCV一般8位元HSV以H的整數0至179、S與V的整數0至255編碼；不能跨函式庫直接照搬閾值。
:::

## 怎麼用、怎麼判讀

先確認任務需要的是輪廓、紋理或色彩。指引的灰階簡化用途，適合當作選項評估，而不是一律刪掉顏色的規定。

:::supplement[來源：OpenCV Color conversions；Pillow教學]
若商品色別或病灶顏色是判斷依據，灰階可能移除訊號；若只辨認字形，可以比較灰階與RGB的驗證結果。測HSV方案時也要含亮度變化、陰影與低飽和度區域，不能只看單張漂亮示範圖。
:::

### 換個場景

| 場景 | 表示選擇 | 需要確認 |
|---|---|---|
| 簡化模型輸入 | 指引列出灰階用途 | 關鍵資訊是否還在 |
| 零售商品色別（補充） | RGB或HSV | 色別訊號不能被壓掉 |
| 製造刮痕輪廓（補充） | 可比較灰階 | 紋理與前景對比是否足夠 |
| 醫療病灶顏色（補充） | 先保留色彩 | 灰階是否抹去病灶色差 |

## 常見誤解

### 表示改變不等於資訊增加（補充）

- **灰階複製成三通道就還原RGB。** 三個通道只是在複製相同值，原色無法唯一推回。
- **HSV可以完全去除光照影響。** 陰影、曝光與低飽和度仍會改變可辨識性。
- **通道順序只影響畫面顏色。** 把BGR當RGB會連灰階加權與模型輸入都算錯。

## 進階

### 表示轉換與色彩擾動（補充）

轉成HSV是換表示；刻意改色相或飽和度則是改變影像內容。後者用作資料增強時，需要另外確認是否仍保留標籤，不能把「換色彩空間」當成任意換商品顏色的許可。
