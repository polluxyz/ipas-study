## 為什麼需要

「預測房價多少」與「判斷是否高價屋」使用相同特徵，卻是不同任務。決策樹（Decision Tree）用共同的條件分支結構，處理分類或迴歸。

這頁先辨認任務與解釋方式，再依需要閱讀：

- 想看分類樹的建模與讀碼：分類決策樹。
- 想比較分類的切分品質：樹節點不純度與資訊增益。
- 想算連續目標的葉值與切分：迴歸決策樹。

## 直覺

每個內部節點是一個問題，答案決定下一條分支。葉節點才給預測：分類給類別，迴歸給數值。

同一條「面積是否超過35坪」路徑，可以在房價任務輸出110，也能在高價屋分類任務輸出「高價」。不能光看輸入欄位就判定是哪一種任務。

![先沿條件走到單棵樹的葉；多棵樹可再合併，本圖示範分類硬投票2比1得到高價。](figure:l23202-decision-tree-branch-vote)

## 定義與公式

決策樹反覆用特徵條件分區，讓同區域的目標更相近。分類與迴歸的輸出及訓練準則不同，本頁不重複各專頁公式。

| 項目 | 分類樹 | 平方誤差迴歸樹 |
|---|---|---|
| 目標 | 離散標籤 | 連續數值 |
| 葉輸出 | 類別，亦可估計類別比例 | 訓練目標平均 |
| 常見切分比較（補充） | 吉尼不純度或熵 | 平方誤差下降 |
| 用途 | 判斷高價或一般 | 預測價格多少 |

樹不強制全域線性關係，較能表達非線性與條件交互作用。相較之下，未擴增特徵的線性迴歸以全域係數說明固定其他條件時的變化。

![同六筆房屋只用面積比較：線性迴歸沿固定斜率變化，迴歸樹在35坪切換預測。](figure:l23202-linear-regression-line-step)

## 走一次流程

:::supplement[來源：scikit-learn Decision Trees]
沿用共用六筆房屋，面積10、20、30、40、50、60，價格40、50、60、100、110、120。用「價格至少80」建立教學分類標籤；它由目標衍生，不拿來當預測輸入。
:::

### 同一分支，兩種葉輸出（補充）

1. 訓練前先定義目標：原始價格或高價類別。
2. 示範固定一個35坪分支，前三筆到左葉，後三筆到右葉。
3. 價格任務：兩葉平均分別50與110。
4. 分類任務：左葉全一般、右葉全高價；新房屋38坪走右葉。

這是共用路徑的展示，實際訓練會根據各自目標與準則找切分。此例兩種任務恰好可以使用同一閾值，不代表任何資料都會長出相同樹。

能源資料沿用相同索引，目標220、250、280、400、430、460，兩葉平均250與430。以耗電至少340建立標籤時，分類輸出則為「一般／高耗電」。

### 單樹與森林

單樹只需追一條路徑，容易說明「為何進這個葉」。多棵不同的樹再集成，可以降低單樹因資料小幅改變而產生的波動，但整體規則較難一次說清楚。

:::supplement[來源：scikit-learn Decision Trees；Google Decision Trees課程]
圖示三棵樹對同一房屋給高價、高價、一般，硬投票為2比1，得到高價。若改為價格任務，三棵樹預測100、110、120，平均為110；類別投票和連續數值平均不能混用。
:::

## 程式（補充）

以共用六筆資料分別訓練分類與迴歸；固定相同深度、葉樣本數與種子。

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor

X = np.array([10,20,30,40,50,60]).reshape(-1,1)
y = np.array([40,50,60,100,110,120])
settings = dict(max_depth=1, min_samples_leaf=2, random_state=23202)
r = DecisionTreeRegressor(**settings).fit(X, y)
c = DecisionTreeClassifier(**settings).fit(X, y >= 80)
print("38坪價格", r.predict([[38]]).tolist())
print("38坪為高價", c.predict([[38]]).tolist())
print("三樹價格平均", np.mean([100,110,120]))
print("高價硬票", sum([True,True,False]), "比", 1)
```
```text
38坪價格 [110.0]
38坪為高價 [True]
三樹價格平均 110.0
高價硬票 2 比 1
```

:::tip[讀碼重點]
只改目標與估計器，就可看出任務差別。最後兩行是明列的教學集成輸出，不宣稱已訓練三棵森林中的樹。
:::

## 怎麼用、怎麼判讀

| 比較面向 | 單棵樹 | 隨機森林 |
|---|---|---|
| 解釋 | 可追單一路徑 | 整體需綜合多棵樹 |
| 穩定度 | 深樹易受資料變動影響 | 結合多樣樹可降低波動 |
| 過擬合 | 深度過大風險高 | 通常較能降低單樹風險 |
| 複雜資料 | 表達能力可能不足 | 適合比較高維與複雜結構 |

指引以分類投票說明森林，迴歸則平均多棵樹預測。樹變深後，路徑變長，也不容易解釋。森林也不保證在所有資料都優於淺樹，仍須用相同驗證資料比較。

:::supplement[來源：scikit-learn Decision Trees；Google Decision Trees課程]
本頁圖示是硬類別投票的教學版本；不同實作也可先平均類別機率再取最大類別。詳細集成機制見隨機森林與投票與機率整合。
:::

### 換個場景

| 場景／資料條件 | 比較方式 | 判讀重點 |
|---|---|---|
| 銷售量、房價 | 線性迴歸與樹迴歸 | 連續數值，觀察分段與外推 |
| 非線性、混合特徵分類 | 單棵分類樹 | 邏輯分支與過擬合取捨 |
| 高維、複雜結構分類 | 比較森林 | 穩定度與整體解釋性取捨 |
| 工廠能源（補充） | 耗電數值或高耗電標籤 | 先定義輸出再選任務 |
| 醫療分流（補充） | 診斷類別或住院天數 | 類別與連續輸出分開驗證 |

## 常見誤解

- **決策樹只做分類。** 改用連續目標與迴歸準則，也能預測數值。
- **森林只是把同一棵樹複製多次。** 需要有差異的樹才能發揮集成價值。（補充）
- **有分支就一定可解釋。** 樹太深或樹太多時，整體規則仍會複雜。

## 小結

- 同一種分支結構可做分類或迴歸，先看目標與葉輸出。
- 線性模型解釋全域係數；樹解釋條件路徑與葉值。
- 單樹較易追蹤，森林以較複雜的整合換取穩定度。
- 分類投票與迴歸平均不同，兩者都需驗證泛化表現。
