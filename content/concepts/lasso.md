## 為什麼需要

房價表可能同時記錄面積與另一份面積欄。直接擬合線性迴歸，可能出現多組係數都能產生相似預測，個別係數卻不好解釋。

Lasso 迴歸（Least Absolute Shrinkage and Selection Operator）懲罰係數絕對值和，讓部分係數歸零，同時預測與選特徵。

## 直覺

每保留一個非零係數，都得付出額外代價。某欄帶來的誤差改善不夠時，Lasso可能直接不使用它；懲罰太大，連有用訊號也會被壓掉。

係數路徑圖把多種懲罰強度排在同一橫軸，讓你看到哪些欄位先歸零。下圖使用共用房屋60筆訓練資料，先以訓練平均與標準差縮放。
:::

## 定義與公式

沿用指引的總平方誤差記法，尋找讓下式最小的截距與係數：

$$
L=\sum_{i=1}^{n}(y_i-\widehat y_i)^2+\lambda\sum_{j=1}^{p}|\beta_j|,
\qquad \widehat y_i=\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}
$$

| 記號 | 意義 |
|---|---|
| $n,p$ | 訓練筆數、特徵數 |
| $y_i,\widehat y_i$ | 目標、預測 |
| $x_{ij}$ | 第$i$筆第$j$個特徵值 |
| $\beta_0,\beta_j$ | 截距、特徵係數 |
| $\lambda\ge0$ | 懲罰強度 |

λ增加會提高大係數的代價，常促使更多係數歸零；太強則可能欠擬合。一般L1懲罰原理另見L1 正則化與 Lasso，本頁著重實際迴歸與篩選。

:::supplement[來源：scikit-learn Lasso API；Linear Models 1.1.3]
截距不列入這裡的係數懲罰。

scikit-learn的`Lasso(alpha=α)`使用SSE除以2n再加α倍絕對值和。因此要對應指引的λ，需用`alpha=λ/(2*n)`；不是把同一數字直接填進去。

L1懲罰會受欄位單位影響。先做特徵縮放與標準化，再比較係數或懲罰路徑；縮放器只能fit訓練資料，交叉驗證時也要在每摺內fit。
:::

## 算一次（補充）

先用同一批六筆房屋的候選式 $\widehat y=20+2a-z$。實際為40、50、60、100、110、120，預測35、50、75、90、115、130。

殘差為5、0、−15、10、−5、−10，平方和475。取λ=10，係數絕對值和為3，目標值為 $475+10\times3=505$。

這只是在算一組候選係數的代價，不是宣稱它已最適。下面改用完整60筆訓練資料，對四個標準化欄位真正擬合；每次用相同索引。

| λ | 面積係數 | 屋齡係數 | 無關欄係數 |
|---:|---:|---:|---:|
| 12 | 36.9710 | −5.6970 | −1.2048 |
| 120 | 36.2218 | −4.9705 | −0.3637 |
| 600 | 32.8225 | −1.5808 | 0 |
| 1200 | 28.0977 | 0 | 0 |
| 6000 | 0 | 0 | 0 |

面積副本在以上設定都約為0；表格把小於 $10^{-8}$ 的數值顯示成0。λ=600時無關欄先被排除，λ=6000時模型只剩截距。

### 相關特徵的選中名單（補充）

完全相同的面積與副本是共線性的極端例。λ=120時，原順序係數為「面積36.2218、副本0」；只交換兩欄順序再對回欄名，變為「面積0、副本36.2218」。

兩欄可以互相替代，預測不變，但選中名單改變。高度相關而非完全相同時，也應用重抽樣檢查穩定度，不能把單次被選到當成唯一重要變數。

能源資料也有產量及完全相同的副本。若目標放大3倍並加100，要得到對應的Lasso係數路徑，SSE版λ也需放大3倍；不能跨目標單位直接沿用相同強度。

## 程式（補充）

先重建與其他模型相同的80筆資料，再只以60筆訓練列估計標準化。資料以算術產生，不使用隨機抽樣。

```python
import numpy as np
from sklearn.linear_model import Lasso
from sklearn.preprocessing import StandardScaler

i = np.arange(80)
a, z, v = (10+7*i%51).astype(float), (5+3*i%21).astype(float), 11*i%17-8
y = 20+2*a-z+20*(a>35)+(13*i%9-4)
h = [0,4,8,12,16,20]
a[h], z[h], y[h] = [10,20,30,40,50,60], [5,10,5,10,5,10], [40,50,60,100,110,120]
X = np.column_stack([a,a,z,v]); tr = i[i%4!=3]
Z = StandardScaler().fit_transform(X[tr])
print("訓練形狀", Z.shape)
```
```text
訓練形狀 (60, 4)
```

```python
for order in [[0,1,2,3], [1,0,2,3]]:
    m = Lasso(alpha=1, max_iter=100000, tol=1e-10).fit(Z[:,order], y[tr])
    back = np.zeros(4)
    back[order] = m.coef_
    back[np.abs(back)<1e-8] = 0
    print(back.round(4).tolist())
```
```text
[36.2218, 0.0, -4.9705, -0.3637]
[0.0, 36.2218, -4.9705, -0.3637]
```

:::tip[讀碼重點]
60筆時alpha=1對應λ=120。第二次先交換輸入順序，再把係數放回原欄名順序；這樣比較的是「哪一欄被選中」。這裡固定循序求解，不涉及亂數種子。
:::

## 怎麼用、怎麼判讀

Lasso適用於共線、高維、希望限制過擬合或同時篩選特徵的情境。λ應以訓練內的交叉驗證或驗證集選擇，不以測試集挑到最好看的一個數字。

指引4-16沿用線性迴歸的模型假設；只用原始特徵時，Lasso仍是線性模型，不能自行學出彎曲關係。

:::supplement[來源：scikit-learn Lasso API；Linear Models 1.1.3]
求解與統計推論的前提需分開理解，詳見線性迴歸的模型假設。Lasso可處理共線欄位，但不保證每個係數都有穩定、獨立的解釋。
:::

| 想達到的目的 | 怎麼看 | 限制 |
|---|---|---|
| 簡化使用欄位 | 看非零係數名單 | 不是因果篩選 |
| 防止過擬合 | 比較驗證誤差 | 過強會欠擬合 |
| 處理相關欄位 | 檢查選中名單穩定度 | 可能只留其中一欄 |
| 關係明顯非線性 | 比較特徵轉換或其他模型 | 原始特徵的加權和有形狀限制 |
| 保留相關訊號（補充） | 另比較嶺迴歸或Elastic Net | 需重新驗證模型 |

### 換個場景

| 場景／資料條件 | Lasso用途 | 判讀重點 |
|---|---|---|
| 高維、特徵多於樣本 | 同時擬合與挑欄 | 可解仍不等於選得穩 |
| 多重共線、希望減少過擬合 | 懲罰大係數 | 可能僅保留相關組的一欄 |
| 預測優先並需要特徵選擇 | 比較稀疏模型的驗證表現 | 強度不宜只靠手猜 |
| 房價欄位精簡（補充） | 減少後續資料蒐集欄位 | 面積副本不能視為獨立訊號 |
| 工廠能源感測（補充） | 篩選用量預測的感測欄 | 同步變動的感測器可能輪流被選 |

## 常見誤解

- **係數為0就表示完全無關。** 只是該資料與懲罰下沒有使用它，相關欄可能已代替它。（補充）
- **Lasso自然會保留整組相關特徵。** 它可能擇一，不能保證單次名單穩定。
- **懲罰越強越好。** 過強會壓掉有用訊號，造成欠擬合。
- **縮放與正則化是同一件事。** 前者改尺度，後者在訓練目標加代價，兩者需分開理解。（補充）

## 進階

### 相關性與可解釋性的界線（補充）

篩選的目的可以是減少部署欄位，不必聲稱找到唯一真因。若選中名單是決策依據，應另外檢查不同重抽樣下的保留頻率，並交由領域知識判讀。

## 小結

- Lasso以L1懲罰促進係數歸零，可同時預測與篩選特徵。
- λ增加不保證泛化更好，太強可能欠擬合。
- 共線特徵可能擇一，選中名單未必穩定。
- 先以訓練資料縮放；不同API的懲罰強度需核對目標式。（補充）
