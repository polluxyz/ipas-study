## 為什麼需要

誤差指標告訴我們差了多少，卻沒有說模型比簡單基準好多少。決定係數（Coefficient of Determination，R²）用「全部預測該批實際值的平均數」作比較基準。

它衡量的是相對於這個基準，模型減少多少平方誤差。指引以「解釋目標變數變異的比例」說明，但不能讀成分類準確率。

## 直覺

若完全不使用特徵，每筆都猜同一個平均數，仍然能形成一個基準。模型需要比這個基準更接近實際值，R² 才會大於 0。

:::supplement[來源：本站 L23303 網店出貨量教學模擬資料]
八筆出貨量平均為 47.5 箱。永遠猜 47.5 箱的平方誤差和為 5950，既有模型的平方誤差和只有 407。

RSS/TSS＝6.84%，是相對平均值基準剩下的平方誤差比例，因此 R² 約 0.932。這個比例仍容許某一天少估 20 箱，不能用高分保證每筆都準。
:::

## 定義與公式

先算平均值基準、模型殘差平方和與總變異平方和：

$$
\begin{aligned}
\bar y&=\frac{1}{n}\sum_{i=1}^{n}y_i \\
\mathrm{RSS}&=\sum_{i=1}^{n}(y_i-\hat y_i)^2 \\
\mathrm{TSS}&=\sum_{i=1}^{n}(y_i-\bar y)^2 \\
R^2&=1-\frac{\mathrm{RSS}}{\mathrm{TSS}}
\end{aligned}
$$

- $n$ 是樣本數，$i$ 是樣本索引；$y_i$、$\hat y_i$ 是同一筆實際值與預測值。
- $\bar y$ 是這批實際值的平均數。
- RSS（Residual Sum of Squares）是模型殘差平方和。
- TSS（Total Sum of Squares）是全部猜 $\bar y$ 時的平方誤差和。

:::supplement[來源：scikit-learn r2_score API；本站 L23303 網店出貨量教學模擬資料]
本頁用單一目標、等權重版本。資料須逐筆配對、數值有限，至少兩筆且實際值不全相同，才能使用一般的 R² 判讀。

出貨資料的 $\bar y=47.5$、RSS＝407、TSS＝5950，故 $R^2=1-407/5950\approx0.931597$。平方和的單位相同，相除後無單位。
:::

### 重要邊界：常數目標（補充）

當所有實際值相同，TSS＝0，公式不能用一般除法計算。完全預測正確形成 0/0，否則是用正誤差除以 0；都沒有通常「解釋幾成變異」的意義。

`r2_score` 預設 `force_finite=True`，對常數目標的完美與非完美預測分別回傳 1 與 0。這是 scikit-learn 的替代規則，並非原公式的除法結果。

## 算一次

:::supplement[來源：本站 L23303 網店出貨量教學模擬資料]
共用資料實際出貨量為 10、20、30、40、50、60、70、100 箱；預測值為 11、19、31、39、51、59、71、80 箱。

1. 平均值：$(10+20+30+40+50+60+70+100)/8=380/8=47.5$。
2. 模型 RSS：$1+1+1+1+1+1+1+400=407$。
3. 基準 TSS：把每筆實際值與 47.5 相減後平方，逐項如下。

| 樣本 | 實際值減平均（箱） | 平方（箱平方） |
|---|---|---|
| 1、2 | −37.5；−27.5 | 1406.25；756.25 |
| 3、4 | −17.5；−7.5 | 306.25；56.25 |
| 5、6 | 2.5；12.5 | 6.25；156.25 |
| 7、8 | 22.5；52.5 | 506.25；2756.25 |

加總為 $1406.25+756.25+306.25+56.25+6.25+156.25+506.25+2756.25=5950$。

最後 $R^2=1-407/5950\approx0.932$，表示相對平均值基準，平方誤差減少約 93.16%。

RSS/TSS＝6.84%，是相對平均值基準剩下的平方誤差比例，不是 6.84% 的樣本出錯。

此處的 47.5 是評估資料的描述性基準。真正部署的常數預測只能從當時可取得的訓練資料估計，不能偷看未來實際值。
:::

## 程式

:::supplement[來源：scikit-learn r2_score API]
先用 NumPy 展開兩個平方和，再與套件核對：

```python
import numpy as np
from sklearn.metrics import r2_score
y_true = np.array([10, 20, 30, 40, 50, 60, 70, 100])
y_pred = np.array([11, 19, 31, 39, 51, 59, 71, 80])
rss = np.sum((y_true - y_pred) ** 2)
tss = np.sum((y_true - y_true.mean()) ** 2)
print(f"平均: {y_true.mean():.1f}; RSS: {rss}; TSS: {tss:.0f}")
print(f"手算 R²: {1 - rss / tss:.6f}")
print(f"套件 R²: {r2_score(y_true, y_pred):.6f}")
print(f"改成十箱單位: {r2_score(y_true / 10, y_pred / 10):.6f}")
```
```text
平均: 47.5; RSS: 407; TSS: 5950
手算 R²: 0.931597
套件 R²: 0.931597
改成十箱單位: 0.931597
```
:::

:::tip[讀碼重點]
TSS 使用實際值的平均，不是預測值的平均。最後一行同時換算實際與預測的單位，R² 因分子分母同比縮放而不變。
:::

## 怎麼用、怎麼判讀

以下判讀以 TSS＞0 為前提：

| R² | 平方誤差比較 | 意義 |
|---|---|---|
| 1 | RSS＝0 | 每筆預測正確 |
| 0 | RSS＝TSS | 與全部猜這批平均值的平方誤差相同 |
| 小於 0 | RSS＞TSS | 比這個平均值基準更差 |

跨資料集時，TSS 會改變。不同任務的 R² 不宜直接排名，應在共同評估資料上進行模型比較，並搭配 MAE、RMSE。

### 換個場景

| 場景 | 判讀重點 |
|---|---|
| 線性迴歸的預測能力評估 | 指引列出的用途；比較模型與平均值基準 |
| 房價估算（補充） | 跨地區房價變異不同，不能只憑兩地 R² 排名模型 |
| 電力負載（補充） | 負載幾乎固定時，少量誤差也可能導致負 R² |
| 交通流量（補充） | 尖峰與離峰的變異不同，分群後要同時看樣本數和原單位誤差 |

### 電力負載：為什麼可以是負值（補充）

`L23303-B-electricity.json` 的實際值為 100、102、98、100 MW，平均 100 MW，TSS＝$0^2+2^2+(-2)^2+0^2=8$ MW 平方。

模型甲的殘差為 0、0、0、8 MW，RSS＝64，R²＝$1-64/8=-7$。模型乙每筆少估 3 MW，RSS＝36，R²＝$1-36/8=-3.5$。

乙的 RMSE 僅 3 MW，R² 仍為負，因為平均值基準在這批穩定負載上很強。負值表示比基準差，不表示「負的準確率」，更不能只憑負值斷言過擬合。

### 指引限制的澄清（補充）

指引 4-13 將範圍寫成 0～1，但 5-24 已說明負值。依公式，只要 RSS＞TSS 就為負，因此一般範圍是上限 1、沒有有限下限。

指引 5-24 對「非線性、未標準化資料」的限制也過強。對非線性模型仍可用相同的實際值與預測值計算 R²；但線性模型的平方和分解與推論條件不能直接移植。

對實際值和預測值同做非零倍數換算及平移，兩個平方和同比變化，R² 不變。未標準化不會自動使它失效；真正要固定的是資料基準，而非強制標準化。

## 常見誤解

- **「R²＝0.85 是準確率 85%。」** 它描述相對平均值基準的變異比例，不計分類對錯。
- **「R²＝0 一定代表每筆都猜平均。」** 只表示平方誤差和相等，不要求預測值逐筆相同。
- **「R² 低於 0 是程式錯誤。」** 模型比平均值基準差時就可能出現，應查資料與預測。
- **「R² 高就能省略殘差分析。」** 高分仍可能伴隨彎曲、離群值或變異不齊，需檢查誤差型態。（補充）

## 進階

### 訓練集高分與模型複雜度（補充）

普通最小平方法在含截距、目標非定值、同一訓練資料上重新擬合時，加入特徵且保留舊特徵，不會降低訓練 R²。這個性質不能直接套到正則化或其他訓練目標。

因此增加特徵後的訓練高分不等於泛化改善。調整後 R² 會考慮特徵數量，而實務模型比較仍應觀察驗證集表現。

## 小結

- R²＝1−RSS/TSS，以這批實際值的平均數作平方誤差基準。
- 出貨例子平均 47.5、RSS＝407、TSS＝5950，R² 約 0.932。
- R² 可為負；實際值全相同時 TSS＝0，不能照通常方式判讀。
- 它沒有單位，仍不能直接跨資料集排名，也不能取代原單位誤差與殘差分析。
