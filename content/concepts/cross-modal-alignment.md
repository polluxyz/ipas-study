## 為什麼需要

照片是像素，商品描述是文字，不能直接把兩者逐項相減來判斷是否相符。跨模態語意對齊（Cross-Modal Alignment）讓兩種資料的表示具有可比較的意思。

共同空間的重點是學會「哪張圖對應哪段話」，不是把檔案擺在同一個位置。

## 直覺

想像兩套不同單位的地圖先校準到同一座標系。圖片編碼器與文字編碼器各自產生向量，再藉配對學習讓相關表示靠近。

![這是三維教學向量前兩維的投影；圖文符號不同，同編號表示已知正配對，投影本身不能代表完整距離。](figure:l21104-cross-modal-alignment-space)

指引以 CLIP 說明圖文對比學習：配對相符者相對靠近，不相符者作為對照。圖中數字與下一節算例來自同一份合成資料。

## 定義與公式

共享語意空間讓不同模態的輸入產生可比較的向量。訓練需要學出跨來源的語意對應。

### 用餘弦相似度比較（補充）

依 CLIP 原論文的正規化表示，對非零向量使用：

$$
s(\mathbf{x},\mathbf{t})=\frac{\mathbf{x}^{\mathsf T}\mathbf{t}}{\|\mathbf{x}\|_2\|\mathbf{t}\|_2}
$$

$\mathbf{x}$、$\mathbf{t}$ 分別是圖片與文字向量；$\mathsf T$ 表轉置，分子是各維乘積之和，$\|\cdot\|_2$ 是長度。零向量無法計算。

R01 的圖 $(1,0,0)$ 對文 $(0.8,0.6,0)$，兩者長度皆為 1，內積為 $1\times0.8=0.8$，除以兩者長度仍得 0.8。分數越高代表方向越接近。

## 算一次

:::supplement[來源：CLIP 原論文第 2.2 節與 Figure 3]

使用零售前 3 對，以圖片為列、文字為欄；所有向量已是單位長度。下面直接以共用例子計算，並沿用 CLIP 原論文的候選比較方式。

| 圖片＼文字 | R01 紅杯 | R02 背包 | R03 雨傘 |
|---|---|---|---|
| R01 紅杯 | 0.8 | 0 | 0.6 |
| R02 背包 | 0.6 | 0.8 | 0 |
| R03 雨傘 | 0 | 0.6 | 0.8 |

對角線三格是已知正配對，非對角線六格是這批的負配對。固定 R01 圖片，0.8 大於 0.6 與 0，優先取紅杯文字；固定 R01 文字，則要沿第一欄比較。

製造 M01～M03 分別換成裂痕齒輪、磨損軸承與完整螺栓；此處換景只換標籤，沿用相同教學向量與矩陣。這只驗證比較規則，不代表兩領域的真實模型成效相等。
:::

## 程式（補充）

程式直接讀共用 JSON，正規化後計算整組矩陣。這是向量核算，沒有下載或訓練模型；讀法參考 CLIP 官方範例。

```python
import json, os
from pathlib import Path
import numpy as np
root = Path(os.environ.get("IPAS_REPO_ROOT", "."))
d = json.loads((root / "content/examples/L21104-A-pairs.json").read_text(encoding="utf-8"))
pairs = d["domains"][0]["pairs"][:3]
x = np.array([p["image_vector"] for p in pairs], dtype=float)
t = np.array([p["text_vector"] for p in pairs], dtype=float)
x /= np.linalg.norm(x, axis=1, keepdims=True)
t /= np.linalg.norm(t, axis=1, keepdims=True)
s = x @ t.T
print("相似度:", s.round(3).tolist())
print("最佳文字索引:", s.argmax(axis=1).tolist())
```
```text
相似度: [[0.8, 0.0, 0.6], [0.6, 0.8, 0.0], [0.0, 0.6, 0.8]]
最佳文字索引: [0, 1, 2]
```

:::tip[讀碼重點]
矩陣乘法的文字端要轉置，才會得到「圖片數 × 文字數」。取每列最大值是在找圖對文；每欄最大值則是文對圖。
:::

## 怎麼用、怎麼判讀

指引把共享表示用於圖文比較、檢索與跨模態關聯。先確認任務在找語意關係，再決定如何建立正負配對。

指引 3-74 也提到模態間的轉換：共同表示可作為圖片轉描述等任務的前置表示。實際生成文字仍要接生成模組，不能把相似度比較視為已完成翻譯。

:::supplement[來源：CMU 多模態教學的 Alignment；CLIP 原論文第 2.2 節與 Figure 3]
時間同步回答「哪個時點互相對應」，語意對齊回答「哪段描述與哪個內容相符」。兩邊維度相同、時間相同或共用資料夾，都不能證明學到了語意對齊。

批內負配對可能也合理，例如另一段也描述紅杯。把這些資料一律當錯配會引入錯誤訓練訊號，需依資料規則檢查。
:::

### 換個場景

| 場景 | 查詢與候選 | 注意什麼 |
|---|---|---|
| 圖文對應 | 圖片與描述 | 配對者的語意應相符 |
| 圖文檢索 | 文字找圖片、圖片找文字 | 列與欄方向別弄反 |
| 零售（補充） | 描述找商品照 | 類似款式可能都合理 |
| 製造（補充） | 巡檢敘述找缺陷照 | 細節需另核對原圖 |

## 常見誤解

- 共同儲存就是對齊：共同空間還需要可用的語意關係。
- 高相似度證明敘述為真：它只表示模型認為較匹配，不能驗證事實或因果。（補充）
- 圖片與文字必須完全相同向量：對比學習追求相對可區分，不要求逐維相等。（補充）

## 小結

- 語意對齊學的是跨模態的對應。
- 正負配對是學習訊號，共同儲存只是管理方式。
- 讀相似度矩陣時，先固定查詢方向再比較候選。
