## 為什麼需要

如果簡單模型一直漏掉相同規律，只平均許多相似模型可能還是不夠。Boosting策略（提升法）讓下一個模型針對已有組合的不足學習，逐步加強預測。

## 直覺

想像房價先估一個起點，再檢查哪些房屋低估、哪些高估。下一棵樹負責提供修正方向，原有預測仍留在組合裡。

![下一輪必須接收既有預測與錯誤資訊；最後使用全部修正後的組合，不只取最後一棵樹。](figure:l23202-boosting-sequential)

## 定義與公式

Boosting是一類逐輪建立模型的策略。不同演算法定義「不足」的方式不同，不能把所有Boosting都說成只學原始殘差。

本頁不以單一公式概括所有提升策略；梯度提升的加法更新式見梯度提升與XGBoost頁。

:::supplement[來源：INRIA AdaBoost及Gradient-boosting decision tree課程]
AdaBoost會調整樣本權重；梯度提升則用損失函數的負梯度指引修正。本頁用平方損失的梯度提升示範，此時修正目標可寫成實際值減預測值。
:::

| 比較面向 | Bagging策略 | Boosting策略 |
|---|---|---|
| 建模資料 | 重抽多份訓練樣本 | 依已有組合決定本輪學習 |
| 輪次相依 | 可分別擬合 | 新輪依賴前輪組合 |
| 最後整合 | 平均或投票 | 依策略加權組合 |
| 指引的理解起點 | 降低變異 | 降低偏差 |

偏差降低、變異降低是理解傾向。模型容量、雜訊與調參方式都會改變結果，不能宣稱Boosting只影響偏差。

## 走一次流程

### 兩輪修正房價（補充）

這個四筆微型例另存在共用例子檔，不是100筆資料的子集。面積20、25、40、45，房價100、120、180、200；起點取平均150。

1. 實際值減150，得到−50、−30、30、50。
2. 第一棵深度1的樹把兩小屋分一組、兩大屋分一組，修正值為−40、−40、40、40。
3. 學習率0.5，只加入半個修正，得到130、130、170、170。
4. 重新計算殘差−30、−10、10、30，第二棵樹輸出−20、−20、20、20；再加一半，得到120、120、180、180。

這裡展示訓練內修正，不是泛化證據。第二輪學的是整體預測留下的殘差，而不是只看上一棵樹的輸出。

## 程式（補充）

```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor
X = np.array([20, 25, 40, 45]).reshape(-1, 1)
y = np.array([100, 120, 180, 200], dtype=float)
pred = np.full(4, y.mean())
for t in range(2):
    residual = y-pred
    tree = DecisionTreeRegressor(max_depth=1, random_state=23202)
    tree.fit(X, residual)
    pred += .5*tree.predict(X)
    print("輪", t+1, "預測", pred.tolist())
```
```text
輪 1 預測 [130.0, 130.0, 170.0, 170.0]
輪 2 預測 [120.0, 120.0, 180.0, 180.0]
```

:::tip[讀碼重點]
`residual`在每一輪重算，`pred`累積保留。若把第二輪樹當成完整房價模型，會把修正量誤當房價。
:::

## 怎麼用、怎麼判讀

指引以Gradient Boosting、XGBoost、LightGBM作為代表。先理解策略的逐輪相依，再到梯度提升與XGBoost頁看平方損失與分類Logloss的差異。

:::supplement[來源：scikit-learn Ensembles §Gradient-boosted trees]
較小學習率通常需要更多輪；樹深、輪數與學習率要一起評估。輪次有相依性，仍可在一輪內並行搜尋候選分裂，不等於完全不能並行計算。
:::

## 常見誤解

- 逐輪提升最後仍使用模型組合，不是只留下最後一棵樹。
- 降低偏差不等於驗證誤差必定下降。
- 不是所有Boosting都採取相同的重加權或殘差演算法。（補充）
- 一輪內的加速不會消除前後輪的訓練相依性。（補充）

## 小結

- 每一輪修正已有組合的不足。
- 與Bagging的主要差異是前後模型的訓練相依性。
- 降低偏差是傾向，不是免於過擬合的保證。
- 修正目標依演算法而異，不能一律當作原始殘差。（補充）
