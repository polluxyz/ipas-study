## 為什麼需要

同樣要產生客服回覆，可以在對話產品中輸入資料，也可以把語言模型接進自己的系統。先分清楚模型與產品，才知道要比較生成能力、操作介面，還是整套服務的限制。

指引把 GPT 系列列為語言模型，把 ChatGPT 列為對話應用。模型系列與產品名稱不能直接當成兩個相同層級的版本比較。

## 直覺

使用者在客服入口提出問題，應用把問題交給模型，再呈現回覆。看到的介面是產品層，產生文字的能力來自模型層。

![沿客服需求往下看：對話產品與生成模型分屬兩層，須分別查核。](figure:l21103-text-generation-platforms-layers)

:::supplement[來源：OpenAI Text generation]
同一模型可透過 API 接進不同應用。應用也可能更換模型，因此記錄「用了哪個產品」後，還要記錄當時使用的模型與功能設定。
:::

## 定義與公式

語言模型（Language Model）依輸入上下文生成文字。對話產品（Conversational Product）則提供讓使用者提出需求、接收回覆的互動方式；本頁不需要公式。

| 比較項目 | GPT 系列 | ChatGPT |
|---|---|---|
| 所在層次 | 語言模型系列 | 對話應用產品 |
| 主要角色 | 提供理解與生成能力 | 讓使用者進行多情境對話 |
| 客服例 | 根據通知生成回覆草稿 | 客服人員輸入通知並查看草稿 |
| 查核重點（補充） | 模型識別、輸入輸出能力 | 帳號方案、可用功能與資料政策 |

指引從 GPT-2 談起，再以 GPT-3、GPT-4 說明生成品質的進展。這些模型可用來對話、撰寫摘要、翻譯與生成程式碼。

### 工具的定位

指引把語言、圖像與工具調用的整合列為 ChatGPT 與 Gemini 的跨模態特性，也強調 Claude 的安全對齊與長上下文處理。這是選工具時要注意的方向，不能解讀成任務品質的保證。

指引另列 LLaMA、Mistral、Command-R 等模型；部署與授權的比較接到「開放權重模型與授權查核」頁學習。

:::supplement[來源：Anthropic Prompting long context；Google Gemini Long context]
長上下文（Long Context）表示一次能處理較多輸入資訊，不代表每條細節都能找回。安全導向也不表示零幻覺；仍要用自己的來源與驗收條件測試。
:::

## 走一次流程

使用 `L21103-C-generation.json` 的客服 CS01：來源說「三日內回覆」。候選是手寫的合成文字，不是任何平台的實測結果。

1. 定任務：整理回覆時限，不能承諾來源未載的退款日期。
2. 分模型與產品：客服可在對話產品中試做；要接進既有系統時，再評估模型介面。（補充）
3. 放入同份來源與相同任務，產出草稿後對照「三日」條件。
4. 人工查核候選 B 的「一日」，發現與來源矛盾；不能因品牌或語氣可信就接受。

### 長文件比較卡（補充）

換成教育 ED01 的上課通知，再假設學校要同時整理12份長講義與掃描課表。先列輸入需求，再記每個候選版本的證據；文字資料的成功不能代表影像也成功。

| 需求 | 查核證據 | 驗收做法 |
|---|---|---|
| 長文件 | 確切模型與產品的輸入限制 | 指定各文件的條件，檢查有無漏失 |
| 掃描課表 | 該版本是否接受及理解影像 | 對照原圖核對日期與方式 |
| 學生資料 | 儲存、使用、存取及刪除規則 | 資料負責人確認允許的輸入範圍 |
| 可重現比較 | 查核日期、設定及來源版本 | 各工具使用相同資料與規準 |

## 怎麼用、怎麼判讀

模型能力、產品功能與任務結果要分別判斷。指引列出的對話、摘要、翻譯和程式生成，都是任務方向；是否適用仍需回到輸入條件與驗收結果。

### 換個場景

| 場景 | 資料條件 | 比較重點 |
|---|---|---|
| 客服與摘要 | 有通知與使用者問題 | 回覆是否保留來源條件 |
| 長文件整理 | 要跨段落保持上下文 | 能否找齊並正確使用重要資訊 |
| 跨模態任務 | 同時含文字與影像 | 工具是否能處理必要輸入 |
| 教育排課（補充） | 講義與掃描課表並存 | 時間、方式及來源能否核對 |
| 製造維修（補充） | 手冊隨機型及版本改變 | 能否依指定版本整理步驟 |

## 常見誤解

- 「模型與對話產品可以互換名稱。」前者提供能力，後者是使用能力的應用。
- 「強調安全就不會產生幻覺。」安全定位無法替代事實查核。（補充）
- 「可放入長文件就代表已正確理解。」容量與任務正確性仍要分別驗收。（補充）

## 小結

- GPT 系列是模型系列，ChatGPT 是對話應用。
- 長文件、安全與輸入模態是不同的比較面向。
- 同份來源、同份任務與相同規準，才能比較工具結果。（補充）
- 產品與模型的版本條件需要各自留下紀錄。（補充）
