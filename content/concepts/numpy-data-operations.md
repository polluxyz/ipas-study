## 為什麼需要

### 資料清理的共同讀碼前置（補充）

資料轉型、標準化與離群值篩選常以NumPy陣列實作。讀碼若先猜數字，容易把「選一欄」、「選一列」與「挑出所有符合條件的元素」混在一起。

本頁用本組共用資料M01–M04的10、20、30、80°C。`numpy_fixture`把四筆排成兩個時段、每段兩次量測；這是教學重排，不代表原始主表只有兩列。

## 直覺

### 先畫位置，再看消去哪個軸（補充）

陣列的形狀（shape）描述每一軸的長度。二維`shape=(2, 2)`有兩列、兩欄；第0軸的索引往下換列，第1軸的索引往右換欄，索引從0起算。

![axis指定被聚合的方向，結果保留另一軸的兩個位置。](figure:l23301-numpy-data-operations-axes)

`axis=0`把兩列壓成一列結果，所以每欄得到一個平均。`axis=1`把兩欄壓成一欄結果，所以每列得到一個平均；不能只背「0就是欄」而不看輸入形狀。

## 定義與公式

### 形狀與運算約定（補充）

| 寫法 | 做什麼 | 本例結果形狀 |
|---|---|---|
| `X[:, 0]` | 每列都取第0欄 | `(2,)` |
| `X[:, :1]` | 每列取第0欄且保留欄軸 | `(2, 1)` |
| `X.mean(axis=0)` | 沿列聚合，每欄一個平均 | `(2,)` |
| `X[X[:, 1] > 50]` | 用第1欄的條件保留整列 | `(1, 2)` |
| `X[X > 25]` | 用同形狀遮罩挑元素 | `(2,)` |

布林遮罩（Boolean Mask）的True表示保留，False表示略過。`X[:, 1] > 50`長度為列數，用來選列；`X > 25`與X同形狀，會按順序取出符合的元素。

逐元素乘法`X * w`逐格相乘，可用廣播把長度2的權重對齊每一列的兩欄。矩陣向量乘法則是：

$$
\mathbf{y}=X\mathbf{w}
$$

$X$為2×2矩陣，$\mathbf{w}$為長度2權重，$\mathbf{y}$為長度2加權和。二維X與一維w可用`X @ w`或`np.dot(X,w)`；一維向量彼此的`dot`輸出內積。

## 算一次

### 逐步核對位置與數字（補充）

把四筆溫度排成`[[10,20],[30,80]]`，`shape=(2,2)`且元素數仍為4。各格都是°C；若欄位單位不同，列平均就可能沒有物理意義。

1. 沿第0軸取平均：第0欄為(10+30)÷2=20，第1欄為(20+80)÷2=50。
2. 沿第1軸取平均：第0列為15，第1列為55。
3. 檢查第1欄大於50：20不符、80符合，遮罩為`[False, True]`，保留整列`[30,80]`。
4. 令權重為`[1,2]`，逐元素結果是`[[10,40],[30,160]]`。
5. 每列加總乘積：10+40=50、30+160=190，因此矩陣向量乘法得到`[50,190]`。

若第二領域改用同索引的零售金額，四個數字都是10倍；遮罩門檻也同比改成500，保留的仍是第二列。固定索引後才能比較清理操作，不能挑不同列來支持結論。

## 程式

### 軸、切片與兩種遮罩（補充）

```python
import numpy as np
X = np.array(["10", "20", "30", "80"]).astype(float).reshape(2, 2)
print(X.shape)
print(X.mean(axis=0).tolist(), X.mean(axis=1).tolist())
print(X[:, 0].shape, X[:, :1].shape)
row_mask = X[:, 1] > 50
print(row_mask.tolist(), X[row_mask].tolist())
print(X[X > 25].tolist())
```
```text
(2, 2)
[20.0, 50.0] [15.0, 55.0]
(2,) (2, 1)
[False, True] [[30.0, 80.0]]
[30.0, 80.0]
```

:::tip[讀碼重點]
`:`表示沿該軸取全部；切片的終點不包含在內。數值字串先轉成浮點型別，才進行數值運算。
:::

### 逐元素、內積與重排（補充）

```python
import numpy as np
X = np.array([[10, 20], [30, 80]])
w = np.array([1, 2])
print((X * w).tolist())
print((X @ w).tolist(), np.dot(X[0], w).item())
print(X.T.tolist())
print(X.reshape(4).tolist())
```
```text
[[10, 40], [30, 160]]
[50, 190] 50
[[10, 30], [20, 80]]
[10, 20, 30, 80]
```

:::tip[讀碼重點]
`T`交換列欄；`reshape`依指定順序改形狀，不等於轉置。這裡`reshape(4)`採預設的C順序，逐列取回10、20、30、80。
:::

## 怎麼用、怎麼判讀

### 四步讀碼法（補充）

先寫輸入shape與型別，再看切片或遮罩選哪些位置，接著看運算消去或新增哪個軸，最後代入數字。每一步保留中間shape，比只看最後輸出更容易定位錯誤。

多個條件要用`(條件一) & (條件二)`或`|`逐元素結合，不能用Python的`and`、`or`直接判斷多元素陣列。`axis=None`通常聚合所有元素，不能誤當作第0軸。

### 換個場景（補充）

指引未列出NumPy陣列操作的專門場景；本頁是數值前處理的共同讀碼前置。

| 場景 | 陣列約定 | 要先確認 |
|---|---|---|
| 製造溫度（補充） | 列是時段、欄是重複量測 | 平均的方向與單位 |
| 零售金額（補充） | 列是訂單、欄是不同特徵 | 列遮罩要與訂單索引對齊 |
| 醫療影像（補充） | 軸可能是批次、高、寬、通道 | 不能把通道軸當成樣本軸 |

## 常見誤解

### 形狀正確仍可能算錯（補充）

- **`*`就是內積。** `*`是逐元素乘法；內積或矩陣乘法還涉及沿共同維度加總。
- **所有遮罩都保留二維。** 同形狀的布林遮罩會把符合元素取成一維；列遮罩則保留欄。
- **`reshape`會自動理解資料意義。** 它只照順序重排形狀，不會辨認欄位、時間或單位。
- **轉成整數只是換表示。** 小數轉整數可能失去小數部分，須先確認是否允許。

## 進階

### 切片與複本（補充）

基本切片回傳共享原陣列記憶體的view，進階索引（含布林索引）取值則回傳複本。要保留原始快照時，明確使用`.copy()`建立待修改陣列，避免清理時意外覆寫來源。

用布林索引直接指定新值，例如`X[mask] = 0`，仍會修改X；「取值回傳複本」不能推成「索引指定不會改原陣列」。

## 小結

### 本頁重點（補充）

- shape先說位置，axis再說沿哪個方向聚合。
- 列遮罩選整筆，同形狀遮罩選元素，輸出維度不同。
- 逐元素乘法與矩陣向量乘法的加總規則不同。
- 每一步核對型別、單位與索引，避免數字合理卻語意錯誤。
