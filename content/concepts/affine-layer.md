## 為什麼需要

特徵全為零時，目標值不一定為零。例如設備即使沒載入工作，也可能有待機耗電；模型需要偏差來表達基準值。

指引在迴歸與神經網路層都使用加權後加偏差的形式。數學上這是仿射運算（Affine Transformation）；把它叫線性層是模型慣用名稱。

## 直覺

先以權重改變方向或尺度，再把全部結果平移同一段距離。偏差不依本批次有幾筆資料而改變，每筆都加同一組偏差。

:::supplement[來源：PyTorch Linear]
下圖固定使用同一縮放矩陣，比較有無平移。加上 $b=(2,1)$ 後，原點也移到 $(2,1)$，因此不再是純線性變換。
:::

![先比較縮放後的形狀，再看加偏差時全部點一起移動，原點不再固定。](figure:l23102-affine-layer-translation)

## 定義與公式

單筆採欄向量慣例，單輸出的預測為：

$$
\hat y=w^\top x+b
$$

$x,w$ 都是 $d$ 維向量，$b$ 是純量偏差，$\hat y$ 是一個輸出。

指引在神經網路使用 $z=Wa+b$：$a$ 是 $d$ 維欄向量，$W$ 為 $k\times d$，每個橫列是一組輸出權重；此處 $z,b$ 都是 $k$ 維向量，須與上式的純量偏差分開理解。

### 批次的排列（補充）

本組固定每個橫列是一筆，公式寫成：

$$
Z=XW+\mathbf1_n b^\top
$$

$X$ 為 $n\times d$，$W$ 為 $d\times k$，$b$ 是 $k$ 維欄向量，$\mathbf1_n$ 為 $n$ 個 1 組成的欄向量，$Z$ 為 $n\times k$。

簡寫 $XW+b$ 時，是指每個橫列都加同一個 $b^\top$，不是只改其中一筆。欄向量與橫列批次的權重儲存方向相反，描述的是同一運算。

## 算一次（補充）

能源第一筆 $x=(1,2,3)$，共用 $W_1=\begin{bmatrix}1&0\\2&1\\-1&2\end{bmatrix}$、$b^\top=(1,-1)$。

第一個輸出為 $1\cdot1+2\cdot2+3\cdot(-1)+1=3$。第二個輸出為 $1\cdot0+2\cdot1+3\cdot2-1=7$，所以結果是 $(3,7)$。

| 樣本 | 輸入 | $XW_1+b$ | $XW_2+b$ |
|---|---|---|---|
| E01 | $(1,2,3)$ | $(3,7)$ | $(6,0)$ |
| E02 | $(2,1,0)$ | $(5,0)$ | $(5,-2)$ |
| E03 | $(0,1,2)$ | $(1,4)$ | $(3,0)$ |
| E04 | $(3,0,1)$ | $(3,1)$ | $(8,-4)$ |

其中 $W_2=\begin{bmatrix}2&-1\\0&1\\1&0\end{bmatrix}$，是第二組固定候選權重。比較兩者時不換樣本或切分，避免把資料差異當成權重效果。

授信第一筆 $x=(1,1,0)$ 用 $W_1$ 與同一偏差，得到 $(4,0)$。同樣算法可以表示兩種額度分數，但不能直接稱為兩個機率。

### 原點與純量輸出（補充）

圖例用 $A=\mathrm{diag}(2,1)$、$b=(2,1)^\top$。輸入 $(1,1)^\top$ 得 $(4,2)^\top$；零輸入則得 $b$。

若只取能源模型第一欄權重，欄向量公式給 $w^\top x+1=2+1=3$，與批次結果第一格相同。這也核對了兩種排列的對應。

## 程式（補充）

```python
import numpy as np
import torch
torch.manual_seed(42)
X = np.array([[1., 2., 3.], [2., 1., 0.], [0., 1., 2.], [3., 0., 1.]])
W = np.array([[1., 0.], [2., 1.], [-1., 2.]])
b = np.array([1., -1.])
Z = X @ W + b
layer = torch.nn.Linear(3, 2, dtype=torch.float64)
with torch.no_grad():
    layer.weight.copy_(torch.tensor(W.T))
    layer.bias.copy_(torch.tensor(b))
print("輸出", Z.tolist())
print("一致", np.allclose(Z, layer(torch.tensor(X)).detach().numpy()))
```
```text
輸出 [[3.0, 7.0], [5.0, 0.0], [1.0, 4.0], [3.0, 1.0]]
一致 True
```

:::tip[讀碼重點]
PyTorch 的 weight 是輸出×輸入，因此複製 W.T。偏差 b 的兩個元素會廣播到每筆資料，並非沿著樣本軸設定四個偏差。
:::

## 怎麼用、怎麼判讀

線性預測適合連續目標的基礎建模。指引以銷售額、房價、醫療成本及行為解釋應用；模型是否夠用仍要看資料與驗證結果。

:::supplement[來源：Dive into Deep Learning 3.1；PyTorch Linear]
指引 3-17 把患病機率列為線性迴歸應用，須補上輸出範圍限制；成本與機率應分開選模型。

純仿射輸出沒有自動限制在 0 到 1，因此不能直接當機率。超出訓練資料範圍的外推，也可能產生不合理的負成本或額度，必須另做驗證與限制。
:::

### 換個場景

| 場景 | 輸出型態 | 判讀重點 |
|---|---|---|
| 銷售與房價 | 銷售額、價格 | 檢查連續值誤差與合理範圍 |
| 醫療成本或風險 | 金額或患病機率 | 成本可連續；機率須有範圍限制 |
| 行為建模 | 隨條件變化的量 | 描述關聯不自動證明因果 |
| 能源用電（補充） | 用電指數 | 留意零輸入的基準耗電 |
| 授信額度（補充） | 額度分數 | 需額外驗證政策與輸出限制 |

## 常見誤解

- 有非零偏差就不符合純線性變換的原點條件。（補充）
- 神經網路仿射層之後可以接非線性激活，整體不必是線性模型。
- 層輸出是分數，尚未自動成為機率。（補充）

## 進階

### 教材勘誤（補充）

指引 3-12 把加偏差的預測稱為線性投影；偏差非零時，映射屬仿射。判斷時要看原點是否被平移，不能只沿用模型名稱。

指引 3-17 的患病機率例子須加限制：純仿射輸出可能超出機率範圍。醫療成本可作連續預測；機率則宜採邏輯迴歸等具有相應輸出限制的模型，再做驗證。

## 小結

- 仿射運算將特徵加權後加上偏差。（補充）
- 每筆資料共用同一組權重與偏差。（補充）
- 選輸出形式時，要先確認目標是連續值還是機率。
