## 為什麼需要

:::supplement[來源：Goodfellow 等，Explaining and Harnessing Adversarial Examples]
產線檢測原本能抓到瑕疵，卻可能被刻意調整的輸入騙過。對抗樣本（Adversarial Example）關心的是：攻擊者保留任務上的原意，卻讓模型給出錯誤答案。

它是推論期的輸入風險。模型正常載入、請求通過登入，仍可能發生；不能只靠網路安全檢查判定模型安全。
:::

## 直覺

:::supplement[來源：PyTorch Adversarial Example Generation；對抗穩健性課程第 1 章]
共用資料的製造 M12 是「有瑕疵」，零售 R12 是「有缺貨」。兩者都以抽象格網表示影像，不是真實照片，也不宣稱人眼看不出差異。

基準模型只盯左上角的微弱線索。攻擊者改這一格，就能讓分類翻轉，中央較穩定的任務訊號卻沒有改變。

![比較同一張 M12：只改左上格就跨過分類門檻，放大差異面板只是為了看清擾動。](figure:l23401-adversarial-examples-perturbation)
:::

## 定義與公式

### 先寫清楚威脅設定（補充）

本例攻擊者知道分類規則，可改送入模型的像素，不能改標籤、權重或登入權限。目的為讓原本判對的圖判錯，不指定一定變成哪個錯誤類別。

| 威脅 | 變化的來源 | 直接影響 |
|---|---|---|
| 對抗輸入 | 有意選擇誤導模型的改動 | 漏檢或誤報 |
| 自然漂移 | 相機、光照、商品改變 | 資料條件與原先不同 |
| 未授權存取 | 盜用帳密或越過權限 | 原圖、模型或服務被非法取得 |

三者可以同時存在。只看準確率下降，尚不能判斷原因；要追查輸入來源、版本及存取紀錄。

### 有限幅度擾動（補充）

$$
x'=x+\delta,\qquad
\|\delta\|_\infty=\max_j|\delta_j|\leq\epsilon
$$

$x$ 是原像素向量，$x'$ 是新輸入，$\delta_j$ 是第 $j$ 格的改動，$\epsilon$ 是幅度上限。本例像素範圍為 0～1，取 $\epsilon=0.02$；加完仍須合法。

模型故意設得很脆弱，使用下式：

$$
z=100(x_{00}-0.5),\qquad
\widehat y=\begin{cases}1&z\geq0\\0&z<0\end{cases}
$$

$x_{00}$ 是左上像素，$z$ 是分數，$\widehat y$ 是預測類別。這是教學自訂模型，不是所有影像模型的公式；其他像素在此模型中沒有權重。

## 算一次

### M12 與 R12 的同一種失敗（補充）

1. 原值 0.51，分數是 100 乘以 0.01，得到 1；正確判為有目標問題。
2. 左上格減 0.02，得到 0.49；其他 15 格不變，最大改動確為 0.02。
3. 新分數為負 1，改判為沒有問題；人工標籤仍是 1。
4. 反向例 M11 的原值 0.49，加 0.02 後也會從 0 翻為 1。

共用測試索引固定為第 11、12 張。每個領域各有 2 張原圖判對，攻擊後各有 2 張判錯，成功比例為 2／2＝100%；兩領域合計為 4／4。

分母是「原先判對且實際受測的圖」，不能把未測資料算進去。這個數字只描述玩具模型，沒有估計真實場域的攻擊成功率。

## 程式（補充）

先將環境變數 `IPAS_REPO_ROOT` 設為 repo 根目錄。以下直接讀共用像素，只攻擊保留的兩張圖，不下載模型。

```python
import json, os
from pathlib import Path
d = json.loads((Path(os.environ["IPAS_REPO_ROOT"]) / "content/examples/L23401-G-vision-review.json").read_text(encoding="utf-8"))
for domain, rows in d["domains"].items():
    pairs = []
    for i in d["split"]["test"]:
        r = rows[i]; p = r["pixels"][0][0]
        q = p + (0.02 if r["label"] == 0 else -0.02)
        pairs.append((r["id"], int(p >= 0.5), int(q >= 0.5)))
    print(domain, pairs)
```
```text
manufacturing [('M11', 0, 1), ('M12', 1, 0)]
retail [('R11', 0, 1), ('R12', 1, 0)]
```

:::tip[讀碼重點]
這段選擇的是已知模型的有害方向，並非隨機加雜訊。使用真實標籤是離線評估設定；外部攻擊者未必知道標籤。

在這個單格模型中，也可先查詢原圖預測，再往降低該類分數的方向改動。因四張原圖都判對，本例會得到相同方向；這不表示未知模型都能用同樣方法攻破。
:::

## 怎麼用、怎麼判讀

:::supplement[來源：對抗穩健性課程第 1 章；PyTorch Adversarial Example Generation]
先問誰能修改哪個輸入，再問修改預算與目標。白箱情境可用模型梯度找方向；只能查詢輸出的黑箱情境，還要計入查詢能力與成本。

攻擊造成的影響可能是有瑕疵卻放行，也可能是正常產品被攔下。兩類錯誤的業務後果不同，應分開記錄，再考慮對抗訓練與防禦邊界。
:::

| 交通標誌 | 數位圖像或實體貼紙 | 實體變形需另測，不能直接套像素結果 |

## 常見誤解（補充）

- **隨機雜訊就是對抗攻擊**：關鍵在刻意選擇誤導方向，隨機雜訊可作比較基準。
- **模型判錯表示系統遭入侵**：合法推論管道也可能接到有害輸入。
- **小擾動測試成功就能攻破所有模型**：模型、前處理及允許幅度改變都要重測。

## 小結（補充）

- 對抗輸入、自然漂移與未授權存取，原因和控制點不同。
- 小擾動須寫清楚尺度、上限與攻擊者能力。
- 攻擊成功率須附模型、樣本與分母，才能解讀。
