## 為什麼需要

損失函數（Loss Function）把模型的預測轉成可用來學習的誤差。選錯損失，模型就可能努力改善一個與需求不同的目標。

同樣是電商資料，「會不會流失」與「下月花多少錢」需要不同的答案。選損失以前，要先說清楚標籤代表什麼。

## 直覺

損失函數決定哪些錯誤受到較重懲罰。均方誤差會放大大誤差的影響；平均絕對誤差對離群值較不敏感；交叉熵損失則比較分類機率與標籤。

懲罰方式會改變參數更新的依據，連帶影響模型往哪裡學、如何收斂。

訓練損失用來引導參數學習，評估指標則依任務檢查模型表現。同一個均方誤差也能用來評估迴歸；分類可另看精確率與召回率。

:::supplement[來源：Dive into Deep Learning 3.1、4.1]
可以把訓練損失想成練習時的回饋，評估則像驗收。即使使用同一個量，仍須說清楚使用的資料與用途。
:::

## 定義與公式

本頁聚焦選擇。均方誤差（Mean Squared Error，MSE）、平均絕對誤差（Mean Absolute Error，MAE）與交叉熵損失的詳細公式見各自概念頁。

| 任務 | 標籤的意思 | 常見訓練損失 | 偏好 |
|---|---|---|---|
| 迴歸 | 金額、需求量等連續值 | 均方誤差 | 大誤差受到較重懲罰 |
| 迴歸 | 同樣的連續值 | 平均絕對誤差 | 相對降低離群值影響 |
| 分類 | 類別與對應的預測機率 | 交叉熵損失 | 鼓勵把機率分給真實類別 |

### 標籤與輸出須對齊（補充）

| 任務 | 輸出與標籤 | PyTorch 範例 |
|---|---|---|
| 二元分類 | 每筆一個 logits 與浮點 0/1 | BCEWithLogitsLoss |
| 三類互斥分類 | 每筆三個 logits 與一個類別索引 | CrossEntropyLoss |
| 數值迴歸 | 預測數值與同形狀數值目標 | MSELoss 或 L1Loss |

Logits 是尚未轉成機率的分數。上述兩種 PyTorch 分類損失直接接受 logits；不要先轉機率再餵入，詳見交叉熵損失。

## 走一次流程

1. 辨識標籤：是類別、機率分佈，還是連續數值。
2. 確認錯誤代價：一般大小差距，還是特別重視大誤差。
3. 分類先考慮交叉熵；迴歸依代價選均方誤差或平均絕對誤差。
4. 確認框架要求的形狀、型別與 logits／機率格式。（補充）
5. 用驗證集比較候選設定，最後以保留的測試集評估。

### 同一資料的兩個需求（補充）

取共用電商資料 E01–E06。資料檔保留二元目標與下月金額目標，兩者是分別設計的教學任務；候選預測也是假設值，不是模型實測成果。

下月金額目標是獨立設計的教學數值，與特徵中的 30 日金額沒有換算關係；不應把兩者的量級差當成顧客成長預測。

迴歸的金額單位為百元。候選甲的六筆誤差是 1、1、1、1、1、6；候選乙都是 2。

| 候選 | MAE | MSE | 在意什麼會選它 |
|---|---:|---:|---|
| 甲 | 1.8333 | 6.8333 | 線性計算每筆差距 |
| 乙 | 2.0000 | 4.0000 | 特別重罰大幅失準 |

若改問是否流失，六筆答案是 0、1、0、1、0、1。甲給正類的機率為 0.1、0.8、0.2、0.7、0.3、0.6；乙分別為 0.4、0.6、0.4、0.6、0.4、0.6。

兩者在閾值 0.5 下都全對，但平均交叉熵為 0.2960 與 0.5108。交叉熵能區分這批預測的信心，準確率看不到這個差別。

## 程式（補充）

下面抽出相同六筆的誤差、標籤與機率，核對比較數字。沒有訓練或隨機步驟。

```python
import numpy as np
from sklearn.metrics import log_loss
y = np.array([0, 1, 0, 1, 0, 1])
for name, error, p in [
    ("甲", [1, 1, 1, 1, 1, 6], [.1, .8, .2, .7, .3, .6]),
    ("乙", [2, 2, 2, 2, 2, 2], [.4, .6, .4, .6, .4, .6])]:
    e = np.array(error)
    accuracy = ((np.array(p) >= .5) == y).mean()
    print(f"{name} MAE={abs(e).mean():.4f} MSE={(e**2).mean():.4f}")
    print(f"交叉熵={log_loss(y, p):.4f} 準確率={accuracy:.1f}")
```
```text
甲 MAE=1.8333 MSE=6.8333
交叉熵=0.2960 準確率=1.0
乙 MAE=2.0000 MSE=4.0000
交叉熵=0.5108 準確率=1.0
```

:::tip[讀碼重點]
這裡的 `log_loss(y, p)` 接收正類機率，不是閾值後的 0／1 預測。兩組分類決策都答對，仍可因機率不同而得到不同的交叉熵。
:::

## 怎麼用、怎麼判讀

不要因為類別編成 0、1、2，就當成連續量。若它們代表三種設備類型，類別編號之間沒有固定的大小距離。

MSE 可同時作為迴歸的訓練損失與評估指標。分類訓練可用交叉熵，決策評估則另看精確率、召回率等指標。

:::supplement[來源：Dive into Deep Learning 3.1、4.1；PyTorch CrossEntropyLoss]
把三種設備類別的編號套入 MSE，會任意假設「類型 0 到類型 2」比「類型 0 到類型 1」錯得更遠。這是標籤語意與損失的錯配。

決策還要查核漏報、誤報的業務成本。不能以某個損失變小，取代所有業務查核。
:::

### 換個場景

指引 4-4 的適用條件是分類機率與連續數值的區別，以及大誤差、離群值的影響；沒有替損失選擇指定產業。

| 場景 | 需求 | 選擇與查核 |
|---|---|---|
| 電商（補充） | 下月金額或是否流失 | 前者用迴歸損失；後者用分類損失 |
| 製造（補充） | 剩餘壽命或是否故障 | 先辨識數值與類別，再看漏報代價 |
| 交通（補充） | 預測行車時間 | MSE 重視大延誤；MAE 看平均時間差距 |

## 常見誤解

- 有數字標籤就一定是迴歸：還要看數字的語意。（補充）
- MAE 完全不受離群值影響：它只是比 MSE 較不敏感。
- 不同任務的損失可以直接比大小：量尺、單位與目標可能不同。（補充）

## 小結

- 先確認標籤語意，再配對損失。
- MSE 重罰大誤差；MAE 相對降低離群值影響；交叉熵比較分類分佈。
- 依任務選評估指標；同一個 MSE 也能用於迴歸評估。
- 損失改善後，仍須查核實際決策效果。（補充）
