## 為什麼需要（補充）

能源超載或客服長等待可能受許多隨機因素影響。若要逐一列出全部組合很困難，可以先指定機率模型，反覆產生情境，再統計結果。

蒙地卡羅方法（Monte Carlo method）把「難以直接加總」改成「大量抽樣後彙整」。本頁超出指引原有教學深度，屬抽樣估計的補充。

## 直覺（補充）

抽樣一次，就算一次是否超載；抽很多次，再看超載占幾成。也可以把每次情境換成損失，最後看平均或尾部。

本例從共用48期資料等機率、有放回重抽，保留同列能源與客服值。這是在指定的經驗分佈下模擬，不是宣稱未來只會發生這48種情境。

## 定義與公式（補充）

### 事件頻率與平均損失

$$
\widehat p_A=\frac1N\sum_{i=1}^{N}\mathbf1(A_i),\qquad
\widehat\mu_L=\frac1N\sum_{i=1}^{N}L_i
$$

$N$ 是模擬次數，$A_i$ 表示第 $i$ 次是否發生事件；指示函數 $\mathbf1$ 在事件成立時為1，否則為0。$L_i$ 是該次損失，$\widehat\mu_L$ 是平均損失估計。

本例令超過120 kWh的部分每kWh損失2元，即 $L_i=2\max(E_i-120,0)$。$E_i$ 是該次能源用量；平均損失需要對所有模擬次數平均，包括零損失。

### 條件機率

$$
\widehat p_{A\mid B}=
\frac{\sum_{i=1}^{N}\mathbf1(A_i\cap B_i)}
{\sum_{i=1}^{N}\mathbf1(B_i)}
$$

$B_i$ 是第 $i$ 次的條件事件，分子計同時成立，分母只計條件成立。分母必須大於0；用總次數 $N$ 代替，算到的是聯合頻率。

若真實 $P(B)=0$，條件機率本身沒有這個比值定義。若 $P(B)>0$ 但模擬剛好沒抽到，只能說這批樣本無法估計，不能回報0。

### 抽樣誤差

在獨立、同分佈的事件抽樣下，可用下式粗估頻率的標準誤：

$$
\widehat{\mathrm{SE}}(\widehat p)=
\sqrt{\frac{\widehat p(1-\widehat p)}{N}}
$$

$\widehat p$ 是事件頻率，SE是估計值的抽樣波動尺度，不是原始資料的標準差。事件極少、估計恰為0或1時，這個代入式會失真，不能解讀成沒有不確定性。

## 算一次（補充）

### 能源事件與損失

1. **指定模型**：48列各有 $1/48$ 的抽取機率，每次放回；事件是用量嚴格大於120 kWh。
2. **固定抽樣**：種子231013，抽10000列索引；比較樣本數時沿用同一序列前綴。
3. **逐次計算**：把事件轉成0或1，同時計算超額用電的損失。
4. **彙整核對**：622次超標，頻率 $622/10000=0.0622$；平均損失為4.1292元。

這個小模型可直接列舉作核對：48列有3列超標，所以精確基準為 $3/48=0.0625$。平均損失的模型基準為4元；模擬並不會恰等於基準。

把 $\widehat p=0.0622$、$N=10000$ 代入標準誤公式，得到約0.00242。次數增加4倍時，典型波動尺度約減半，不是每一個估計都必然變準。

### 條件遮罩：骰子例

公平骰子令事件 $A$ 為偶數，條件 $B$ 為大於3。條件內只有4、5、6，其中4、6為偶數，解析機率是 $2/3$。

另建同種子產生器抽10000次：條件成立4982次，交集3377次。條件率 $3377/4982\approx0.67784$，聯合頻率 $3377/10000=0.3377$。

## 程式（補充）

第一段照JSON規則重建能源欄並模擬。`integers(0, 48)` 抽索引0到47，符合48期等機率、有放回抽樣。

```python
import numpy as np
t = np.tile(np.arange(12)-5.5, 4) + 20
energy = 100 + 4*(t-20) + np.repeat([-2, 0, 2, 0], 12)
energy[-1] = 210
rng = np.random.default_rng(231013)
idx = rng.integers(0, 48, size=10000)
high = energy[idx] > 120
loss = np.maximum(energy[idx]-120, 0)*2
for n in (10, 100, 1000, 10000):
    print(n, f"{high[:n].mean():.4f}")
print("事件次數:", int(high.sum()))
print(f"平均損失={loss.mean():.4f}元")
```
```text
10 0.0000
100 0.0200
1000 0.0530
10000 0.0622
事件次數: 622
平均損失=4.1292元
```

:::tip[讀碼重點]
`high.mean()` 把布林值當0或1平均。`high[:n]` 使用同一序列前綴；固定種子用來重現路徑，不能消除抽樣誤差。
:::

第二段獨立重建骰子產生器，不接續能源抽樣的亂數狀態。NumPy上界不含7，因此得到公平六面骰的1到6。

```python
rng = np.random.default_rng(231013)
die = rng.integers(1, 7, size=10000)
condition = die > 3
joint = condition & (die % 2 == 0)
den = int(condition.sum())
estimate = float(joint.sum()/den) if den > 0 else None
print("條件與交集:", den, int(joint.sum()))
print("這批樣本無法估計" if estimate is None else f"條件估計={estimate:.6f} 解析值={2/3:.6f}")
empty = die > 6
empty_estimate = float((empty & (die % 2 == 0)).sum()/empty.sum()) if empty.any() else None
print("零條件樣本:", empty_estimate)
```
```text
條件與交集: 4982 3377
條件估計=0.677840 解析值=0.666667
零條件樣本: None
```

:::tip[讀碼重點]
陣列交集用 `&`，每個比較條件加括號；Python的 `and` 不能代替逐元素交集。分母先檢查，再做除法；`None` 表示沒有估計值，輸出時也須先分支，不能套用浮點格式。
:::

## 怎麼用、怎麼判讀（補充）

先查模型是否回答業務問題，再查抽樣是否正確，最後才增加模擬次數。小例可先用解析答案核對程式；複雜情境再靠模擬估計。

本例等待超過10分鐘的模型基準是 $8/48\approx0.1667$，同批重抽索引得到1684次，估計0.1684。條件問題則須另篩選條件，不能直接沿用全部次數當分母。

### 兩種誤差要分開

| 問題 | 增加抽樣次數有何幫助 | 還要做什麼 |
|---|---|---|
| 抽樣波動 | 通常降低估計波動 | 報樣本數與誤差尺度 |
| 模型假設錯誤 | 無法靠重抽修正 | 對照資料與假設 |
| 稀少條件沒被抽到 | 可能取得更多有效樣本 | 先檢查模型是否可能發生 |
| 48期沒見過的新極端 | 重抽不會創造新支持範圍 | 另設合理壓力情境 |

### 換個場景（補充）

指引沒有為本方法列出專屬場景。下列為把抽樣流程換到其他領域的補充；都須先交代情境分佈與損失規則。

| 場景 | 抽什麼 | 彙整什麼 |
|---|---|---|
| 能源容量 | 日用量或負載情境 | 超載率、超額損失 |
| 客服人力 | 到達、服務與等待情境 | 長等待率、尾部分位數 |
| 交通排隊 | 車流與通行時間 | 壅塞率、延誤成本 |

## 常見誤解（補充）

- 模擬10000次不等於取得10000筆新的真實觀測，原資料資訊沒有自動增加。
- 固定種子代表容易重現同一過程，不代表估計沒有誤差。
- 樣本更多可讓錯誤模型算得更穩定，卻不會自動變成正確模型。
- 條件機率要除以條件次數；條件樣本為0時，不能把0除以0寫成0。

## 小結（補充）

- 先指定模型，再抽樣、逐次計算、彙整頻率或損失。
- 條件估計以交集次數除以條件次數，分母要大於0。
- 固定種子有助重現，足夠樣本有助降低抽樣波動。
- 更多模擬無法修正錯誤模型，也無法補回原資料缺少的極端情境。
