## 為什麼需要

若要把評論交給傳統分類器，最直接的做法是數詞。詞袋模型（Bag of Words，BoW）把每篇文件整理成相同欄位，讓長短不同的文字都能比較。

它便於檢查：某欄很高，可以回頭看到是哪個詞。但這個方便來自省略順序；「誰到哪裡」不能只看詞出現幾次。

## 直覺

先固定詞彙表，再讓每篇文件填一列。每個欄位永遠指向同一個詞，值是該詞在文件中出現的次數。

![R01 與 R02 的「不」欄不同；T03 的訂位相關詞落在相同固定欄位，未顯示的詞仍在完整矩陣中。](figure:l21101-bag-of-words-matrix)

圖只顯示完整詞表中的六欄。完整語料共有 53 個不同詞，每篇文件都用 53 維表示，未出現的詞填零。

## 定義與公式

詞袋的表示單位是文件。固定詞序後逐詞計數，文件排成橫列、詞排成直欄，得到文件詞矩陣（Document-term Matrix）。

「詞序」在此是詞表欄位順序，不是原句中各詞的位置。詞表順序可以自訂，但訓練、驗證與之後的輸入必須用同一份對應。

:::supplement[來源：scikit-learn Feature extraction 8.2.3.1 The Bag of Words representation]
二元詞袋只記出現與否；本頁使用計數版，重複出現會累加。實作可用稀疏矩陣只存非零值，省下大量零值的儲存成本。
:::

## 算一次

共用例子 `L21101-B-vectors.json` 保留 24 句原始斷詞，不刪停用詞、不改英文大小寫。先用其中三篇查看計數，不把欄位切片誤當成完整表示。

1. 固定顯示詞序「我、不、喜歡、書、訂、票」。
2. R01「我／喜歡／這／本／書」在這六欄是 `(1,0,1,1,0,0)`。
3. R02 多了「不」，所以是 `(1,1,1,1,0,0)`；R01 與 R02 的否定差異仍可見。
4. T03「我／要／查／台北／到／台南／的／票」是 `(1,0,0,0,0,1)`。其他詞的計數留在未顯示的欄位。

再看同詞不同語序：固定「台北、到、台南」，「台北／到／台南」與「台南／到／台北」都是 `(1,1,1)`。這就是詞袋無法還原方向的反例。

## 程式（補充）

下例讀取共用 JSON。一般從 repo 根目錄執行即可；教材實測器在暫存目錄執行時，用 `IPAS_REPO_ROOT` 指向 repo。

```python
import json, os
from pathlib import Path
from collections import Counter
root = Path(os.environ.get("IPAS_REPO_ROOT", "."))
data = json.loads((root / "content/examples/L21101-B-vectors.json").read_text(encoding="utf-8"))
vocab = data["bow_display_vocabulary"]
for doc in data["documents"]:
    if doc["id"] in ["R01", "R02", "T03"]:
        counts = Counter(doc["tokens"])
        print(doc["id"], [counts[t] for t in vocab])
print("完整詞表", len(data["vocabulary"]))
```
```text
R01 [1, 0, 1, 1, 0, 0]
R02 [1, 1, 1, 1, 0, 0]
T03 [1, 0, 0, 0, 0, 1]
完整詞表 53
```

:::tip[讀碼重點]
Counter 計入重複次數；讀取不存在的詞時得到零。vocab 固定顯示欄序，不能每篇各自重排。
:::

## 怎麼用、怎麼判讀

詞袋適合先建立文本分類與主題建模的簡單表示。重要詞直接占一欄，能清楚追查模型接收哪些訊號。

遇到大詞表時，維度會增加且多數位置為零。需要短範圍詞序可考慮 N-gram；要降低常見詞的相對影響，可接 TF-IDF。它們都不會自動補齊同義詞與多義詞的理解。

### 換個場景

| 場景 | 使用方式 | 判讀重點 |
|---|---|---|
| 文本分類、主題建模 | 用詞頻找類別或主題的訊號 | 指引列出的用途；不保證詞序正確 |
| 詞表很大的語料 | 每詞仍占固定欄位 | 高維與稀疏是成本來源 |
| 製造故障分類（補充） | 計數錯誤碼與零件名稱 | 同義零件名可能分散成不同欄 |
| 法律文件整理（補充） | 以用詞模式輔助歸類 | 不能僅靠詞袋判讀否定範圍 |

## 常見誤解

- 「固定向量長度代表每句一樣長」：固定的是詞表欄數，原句詞數可以不同。
- 「詞袋完全看不到否定」：保留「不」就看得到其計數，但仍不知道它修飾哪個詞。（補充）
- 「兩篇詞袋相同就意思相同」：詞序反例已說明，計數相同仍可能意義不同。

## 進階

### 詞表外的詞（補充）

固定詞表之後，未登錄詞不會自動多出新欄。套件可能忽略它們；若整篇都在詞表外，可能得到全零向量，須另訂處理方式。

本頁 53 詞的全語料詞表只用來教表示；實際評估要先切分，再從訓練資料建立詞表，避免資料洩漏。

## 小結

- 每篇一列、每詞一欄，詞表順序要固定。
- 計數保留頻率，省略原句的詞序與語法結構。
- 高維不等於每篇資訊多，很多位置可能是零。
- 需要加權可接 TF-IDF，需要短詞序可比較 N-gram。
