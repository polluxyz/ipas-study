## 為什麼需要

指引5-19並列輸入資料分布、模型預測分布及錯誤率等監控項目。這些訊號回答不同問題，發出警報後要先分流，才知道還缺什麼證據。

本頁負責分流對照。各現象的完整定義見資料漂移、概念漂移及模型效能衰退與漂移用語；統計量計算另見KL、PSI 與 KS 漂移偵測。

## 直覺

先查進來的資料，再查相同條件的真值關係，最後查實際成績。輸出占比則告訴我們系統做了哪些決策，不能拿來代替真值。

![輸入、條件關係與效能需要不同證據；預測分布及版本則是另外要核對的線索。](figure:l21203-drift-detection-layers)

這張圖是調查地圖，並不表示必須三層都變。輸入可以改變而準確率不變，關係也能在輸入比例相同時改變。

## 定義與公式

指引已提出輸入、預測分布及效能監控。完整分流時，再加入輸入與真值的關係比較：

| 觀察對象 | 核對的證據 | 可支持什麼 |
|---|---|---|
| 輸入分布 | 新舊特徵與異常比例 | 資料是否變得不同 |
| 條件關係（補充） | 同輸入條件下的真值 | 關係是否改變 |
| 預測分布 | 分數及預測類別占比 | 系統行為是否變動 |
| 實測效能 | 預測配對真值後算分 | 實際成績是否下降 |

:::supplement[來源：CMU SEI〈Expecting the Unexpected〉What Is Drift?]
符號上，輸入看$P(X)$，關係看$P(Y\mid X)$；$X$是輸入、$Y$是真值。預測值可寫成$\hat Y$，它的分布不是實際$Y$的分布。

沒有真值仍可監控輸入及預測；要直接評估條件關係與實際準確率，則需要可用且配對正確的真值。
:::

## 走一次流程

指引建議設定門檻並追查資料與環境。下面的具體分流步驟是補充，使用本組相同資料，避免各頁換掉比較基準。

### 四期摘要怎麼分流（補充）

固定v1、0.5閾值，以P0為共同參考；不是每期都改和前一期比較。

此處真值正類是違約；預測陽性率是模型預測為正類的比例，分母為當期全部100人。

| 期別 | 輸入低／高組 | 組內違約率 | 準確率／預測陽性率 |
|---|---|---|---|
| P0 | 50／50 | 10%／90% | 90%／50% |
| P1 | 20／80 | 10%／90% | 90%／80% |
| P2 | 50／50 | 40%／60% | 60%／50% |
| P3 | 20／80 | 40%／60% | 60%／80% |

1. 固定參考與切點，先比輸入：P1、P3低／高組為20／80，與P0的50／50不同。
2. 再比同組真值：P2、P3違約率為40%／60%，與P0的10%／90%不同；P1則維持原關係。
3. 配對預測與真值後評分：P2、P3準確率降到60%；P1仍是90%。
4. 另外比預測陽性率：P1、P3由50%變80%，只證明決策占比變動，不能代替真值評分。

因此P1分到輸入變動，P2分到關係與效能變動，P3兼有輸入、關係及效能變動。各結論都有對應證據。

### AUC相同的反例（補充）

另外對同一批P0做輸出後處理比較，不把它當成上述固定模型的第五期。原分數0.2／0.8改為0.6／0.9，兩組仍維持相同排序。

原本低組判陰性、高組判陽性，正確45＋45＝90人。新分數在0.5閾值下全判陽性，真陽性共5＋45＝50人，準確率降為50%。

ROC曲線維持不變，AUC仍為0.90，預測陽性率卻由50%變100%。因此AUC不變只能說這次排序摘要相同，不能保證決策行為或固定閾值成績相同。

本例改的是輸出後處理，不能用來宣稱概念漂移。要查輸入與真值的關係，仍須比較原始資料及真值。

## 怎麼用、怎麼判讀

看見預測分布警報，先保留輸入、模型版本、閾值及資料窗。看見錯誤率警報，則先確認真值回收與評分規則，再追查變化來源。

:::supplement[來源：Google Cloud Introduction to Model Monitoring；SciPy ks_2samp]
真值延遲時，回報「已觀察到分布差異，效能待確認」。無標籤檢定只能提供分布差異的證據，不提供概念漂移、效能衰退或因果結論。
:::

| 場景 | 先取得什麼 | 再補什麼 |

| 持續部署監控 | 欄位、預測分布、延遲 | 錯誤率與回饋 |
| 零售促銷 | 消費金額分布 | 推薦真值及結果 |
| 授信（補充） | 客群與預測陽性率 | 到期違約結果 |
| 視覺檢測（補充） | 影像條件與預測陽性率 | 人工複驗真值 |
| 醫療分診（補充） | 病人特徵與分流結果 | 後續診斷與漏診 |

## 常見誤解

- 指引5-19的預測分布變化，不等於4-30描述的實際準確度下降。
- AUC相同仍可能有不同的預測陽性率與閾值成績。（補充）
- 預測陽性率不是真值正類比例，需另外回收真值。（補充）
- 分布檢定沒有替團隊找出變化原因。（補充）

## 進階

### 判讀順序不是因果鏈（補充）

輸入、關係及效能有時一起變，也可能只有部分改變。先按證據分流，才知道要查資料來源、外部條件，還是服務設定。

相同整體分數還可能掩蓋不同群體的相反變化。高風險使用情境要保留分群檢查，不能只用一個平均數結案。

## 小結

- 先分輸入、條件關係、預測分布及實測效能。
- 有哪些證據，就先回答哪些問題；真值未到要保留限制。（補充）
- AUC不變不能保證行為不變，更不能單獨完成漂移診斷。（補充）
