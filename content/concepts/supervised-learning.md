## 為什麼需要

只有輸入，模型不知道什麼答案算對。監督式學習用已配對的特徵與標籤，學會對新樣本預測。

資料量大不代表標籤可靠。若訓練答案本身不一致，模型可能很努力地學到錯誤標準。

## 直覺

每一列都包含「當時可看到的線索」與「希望學會預測的答案」。訓練時兩者都提供，上線時只給線索，答案由模型產生。

標籤（Label）可以是離散類別或數值。監督的意思是訓練有對照目標，不是每次預測都要有人站在旁邊。

## 定義與公式

模型學的是輸入到目標的映射：對相似、但未看過的新資料，也能給出合理預測。把訓練資料背熟，還不足以證明泛化能力。

### 本組配對資料（補充）

| 樣本 | 特徵：急迫詞、退款詞 | 類別標籤 | 數值目標：分鐘 |
|---|---|---|---|
| mail-027 | 3、2 | 一般 | 17 |
| mail-099 | 3、8 | 優先 | 35 |
| mail-088 | 4、7 | 優先 | 34 |

預測類別就取類別欄為答案；預測分鐘就取數值欄。這兩種目標不會自動變成彼此的輸入特徵。

## 走一次流程

1. 決定目標，例如預測影像物件類別，或病患的疾病類型。
2. 蒐集輸入與對應標籤，固定判定準則。
3. 用配對資料學習，再用未參與學習的資料檢查表現。

指引強調標籤一致、內容精準與定期品管，也列出雙人獨立判定後查核的做法。

### 錯標會教出什麼（補充）

假設把 mail-027 的「一般」誤寫成「優先」，訓練便會獎勵模型對 $(3,2)$ 預測優先。若同類錯誤集中在退款郵件，學到的偏差也會集中在這個子群。

查核先訂定優先等級準則，再請兩人獨立判定。對分歧案例回看原文與定義；訓練標籤及評估標籤都應查核，不能只修模型猜錯的資料。

## 程式（補充）

先重建客服資料與固定切分。每逢索引是 19 的倍數就翻轉類別，是刻意加入的教學變異，不是標籤人員的真實錯誤率。

```python
import numpy as np
i = np.arange(120)
X = np.column_stack((i % 12, i // 12))
y = (X.sum(axis=1) >= 10).astype(int)
y[i % 19 == 0] = 1 - y[i % 19 == 0]
order = np.random.default_rng(42).permutation(120)
train, val, test = order[:72], order[72:96], order[96:]
print("資料形狀", X.shape, "切分", len(train), len(val), len(test))
```
```text
資料形狀 (120, 2) 切分 72 24 24
```

接著只用訓練集擬合縮放與分類器；驗證集只拿來評估。

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
model = make_pipeline(StandardScaler(), LogisticRegression(random_state=42))
model.fit(X[train], y[train])
pred = model.predict(X[val])
print("驗證答對", int((pred == y[val]).sum()), "/", len(val))
print("示範輸入", model.predict([[3, 2], [3, 8]]).tolist())
```
```text
驗證答對 22 / 24
示範輸入 [0, 1]
```

:::tip[讀碼重點]
fit 接受特徵與標籤，predict 只接受特徵。這兩筆示範輸入是訓練集中的 mail-027、mail-099，不能用它們證明泛化。

Pipeline 把縮放參數留在訓練集內；不能先用全資料 fit_transform 再切分。
:::

## 怎麼用、怎麼判讀

錯誤多時，同時檢查特徵是否足夠、標籤定義是否一致。準確率低不一定是演算法太簡單；準確率高也可能只是評估標籤沿用了同一套錯誤。

### 換個場景

| 場景 | 指引的輸入與輸出 | 品質判讀 |
|---|---|---|
| 圖像分類 | 影像 → 物件類別 | 邊界案例是否一致 |
| 信用風險 | 客戶資料 → 信用等級 | 等級定義是否清楚 |
| 醫療診斷 | 病患資訊 → 疾病類型 | 診斷依據是否可靠 |
| 客服郵件（補充） | 詞次數 → 優先等級 | 定義「優先」與歧義處理 |
| 物流交期（補充） | 出貨資訊 → 天數 | 延誤與取消如何記錄 |

:::supplement[來源：scikit-learn Common pitfalls 12.2；科目 1 指引 guide-1:3-46 的品管原則延伸]
授信還要固定違約觀察期間，醫療要區分未確診與已排除疾病。把未知結果當成陰性，會產生有方向的標籤污染；複核時須回到原始紀錄。
:::

## 常見誤解

- 標籤是學習目標，不是保證正確的真理。（補充）
- 上線時仍須提供答案，才算監督式學習：這混淆了訓練與推論。
- 增加模型深度不能代替統一標籤準則。（補充）

## 小結

- 訓練資料要把特徵與目標正確配對。
- 標籤定義、特徵品質與新資料評估共同限制學習成效。
- 查核歧義與資料來源，比盲目換模型更能定位錯標問題。（補充）
