## 為什麼需要

暗部看不清、物件與背景太接近、感測器產生雜訊，是三種不同問題。影像畫質增強（Image Enhancement）調整亮度或對比；去噪（Denoising）則減少不希望存在的像素擾動。

指引列出直方圖均衡化、Gamma校正，以及平滑與邊緣保留濾波。目的是改善可用資訊，不是把所有影像變得越亮、越平滑越好。

## 定義與公式

低光源或對比不足時，可考慮Gamma校正與直方圖均衡化。拍攝或感測器帶來雜訊時，則考慮平滑或保邊濾波。

### Gamma的方向先說清楚（補充）

本頁採用scikit-image的冪次定義，增益固定為1：

$$
y=255\left(\frac{x}{255}\right)^\gamma
$$

$x$是0到255的輸入像素，$y$是輸出，$\gamma$是大於0的指數。對中間灰階，$0<\gamma<1$會變亮，$\gamma>1$會變暗；黑白端點維持不變。

有些實作把參數寫成指數的倒數，不能只記「Gamma越大越亮」。這裡也不是完整的相機色彩校正或線性光學成像模型。

## 算一次

### 從MD01辨認三種效果（補充）

把64代入公式：先算64÷255，再取平方根，最後乘255，得到約127.75，顯示時四捨五入為128。背景16同樣變成約63.87，顯示為64。

直方圖均衡化依整張圖的累積灰階分布重新配值。本例採扣除最小非零累積數的版本，原圖16、64、255分別映成0、204、255，並非每張圖都用這張對照表。

亮點中心的3×3鄰域有七個16、一個64、一個255。中值取排序第五個，得到16；直接平均則是431÷9，約47.89，亮點仍會影響周圍。

本例後續使用「中值後再Gamma」，送往資料準備與Grad-CAM頁。順序是示範設定，真實任務要用固定驗證資料比較，不能認定它永遠最佳。

## 程式

### 固定像素的中值與Gamma（補充）

以下常數來自`L21102-D-vision.json`的MD01。只用NumPy，3×3鄰域越界時複製邊界像素，不需另裝影像套件。

```python
import numpy as np
np.random.seed(21102)
x = np.array([[16,16,16,16], [16,255,16,16],
              [16,16,64,64], [16,16,64,64]], dtype=float)
p = np.pad(x, 1, mode="edge")
windows = np.lib.stride_tricks.sliding_window_view(p, (3, 3))
denoised = np.median(windows, axis=(-2, -1))
processed = 255 * np.sqrt(denoised / 255)
print("中心中值:", denoised[1, 1])
print("原中心鄰域平均:", f"{windows[1, 1].mean():.2f}")
print("處理後像素:", np.rint(processed).astype(int).tolist())
```
```text
中心中值: 16.0
原中心鄰域平均: 47.89
處理後像素: [[64, 64, 64, 64], [64, 64, 64, 64], [64, 64, 128, 128], [64, 64, 128, 128]]
```

:::tip[讀碼重點]
`np.pad`決定邊界規則；`median`沿每個視窗的兩個空間軸取中值。最後才把顯示值取整，避免提前取整改變後續熱區計算。
:::

## 怎麼用、怎麼判讀

指引的適用條件是低光源、品質差，以及感測器或拍攝產生雜訊。先辨認問題來源，再選亮度、對比或去噪方法。

### 選方法前先辨認問題

| 方法 | 指引的處理方向 | 選用細節與副作用（補充） |
|---|---|---|
| Gamma | 改善低光源或品質差影像的亮度 | 中間灰階偏暗可先試；雜訊也可能變明顯 |
| 直方圖均衡化 | 改善低光源或品質差影像的對比 | 灰階過度集中可先試；也可能放大雜訊 |
| 高斯平滑 | 減少感測器或拍攝產生的雜訊 | 小幅隨機雜訊可先試；細線也會被平滑 |
| 雙邊濾波 | 以邊緣保留濾波處理雜訊 | 希望保留邊界可先試；參數不當仍傷細節 |
| 中值濾波（補充） | 孤立亮暗點等脈衝雜訊 | 細小結構可能一起消失 |

### 換個場景

| 場景 | 處理方向 | 判讀重點 |
|---|---|---|
| 低光源、低品質影像 | 比較Gamma與均衡化 | 先確認是亮度還是對比問題 |
| 感測器或拍攝雜訊 | 比較平滑與保邊濾波 | 不能把有用邊界當雜訊 |
| 零售包裝（補充） | 讓暗處封口容易辨識 | 細字與封口紋理仍須保留 |
| 製造刮痕（補充） | 降低背景隨機擾動 | 不以抹除細刮痕換取平順 |
| 醫療影像（補充） | 依任務查核局部對比 | 不把視覺較好當診斷更準 |

## 常見誤解

- **均衡化就是去噪。** 它調整灰階分布，未區分訊號與雜訊。（補充）
- **保邊代表所有細節保證不變。** 細節能否保住仍受濾波參數與尺度影響。（補充）
- **修復與資料增強目的相同。** 改善既有輸入與刻意增加訓練變化是不同目的（補充）；指引也把模糊列為資料增強。
- **變亮就能恢復全部資訊。** 原本已全黑、飽和或嚴重模糊的區域，不會因轉換便恢復真實細節。（補充）

## 進階

### 彩色圖與輸入一致性（補充）

逐RGB通道各做均衡化可能改變色彩，實務可考慮處理亮度通道。訓練與推論要記錄相同處理及參數；若用模型學去噪，也要避免評估資料參與學習。

## 小結

- 亮度、對比與雜訊是不同問題，先診斷再選方法。
- Gamma與均衡化調整明暗，平滑與保邊濾波處理雜訊。
- 濾波可能傷害細節，須檢查任務訊號。（補充）
- 本組固定處理結果會繼續送往資料準備與熱區檢查。（補充）
