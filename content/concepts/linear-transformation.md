## 為什麼需要

資料原本的特徵軸未必最適合模型處理。矩陣可以重組特徵、對齊方向，或把多維資料投影到較小空間。

線性變換（Linear transformation）包括縮放、旋轉、剪切（Shear）與投影（Projection）。

## 直覺

想像原點發出兩支基底箭頭：向右一格與向上一格。矩陣決定這兩支箭頭各自移到哪裡，其他點跟著同樣的組合規則移動。

:::supplement[來源：Interactive Linear Algebra 3.1]
下圖每格都由相同二維網格變換而來，虛線是原網格，實線是結果。原點始終不動；投影（Projection）後網格會壓到水平線上。
:::

## 定義與公式

指引用矩陣左乘欄向量表示：

$$
y=Ax,\qquad A\in\mathbb R^{k\times d},\ x\in\mathbb R^d,\ y\in\mathbb R^k
$$

$x$ 是 $d$ 維輸入，$A$ 是變換矩陣，$y$ 是 $k$ 維輸出。同維變換可改變幾何形狀，跨維變換可改變座標數量。

### 四種二維矩陣（補充）

本例固定使用以下矩陣：

$$
S=\begin{bmatrix}2&0\\0&1\end{bmatrix},\quad
R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}
$$

$S$ 只把水平軸放大 2 倍；$R$ 是逆時針旋轉 90 度，座標變成 $(-x_2,x_1)$。

$$
H=\begin{bmatrix}1&1\\0&1\end{bmatrix},\quad
P=\begin{bmatrix}1&0\\0&0\end{bmatrix}
$$

$H$ 是水平剪切（Shear），把第一座標改成 $x_1+x_2$；$P$ 投影到水平軸，把第二座標歸零。這裡 $x_1,x_2$ 是輸入兩座標。

四者都滿足線性結構：

$$
T(\alpha u+\beta v)=\alpha T(u)+\beta T(v)
$$

$T$ 是矩陣定義的映射，$u,v$ 是輸入向量，$\alpha,\beta$ 是純量。

取 $u=(1,0)$、$v=(0,1)$、$\alpha=\beta=1$，以 $S$ 為例：$S(u+v)=(2,1)=Su+Sv$。這也說明為何知道兩個基底的去向就能決定其他點。

## 算一次（補充）

共用幾何點集包含原點、兩個基底與 $x=(1,1)$。此點經縮放與剪切恰巧同為 $(2,1)$；單看一點無法分辨映射，還要比較兩個基底的去向。

| 變換 | 第一基底 $(1,0)$ | 第二基底 $(0,1)$ | $x=(1,1)$ |
|---|---|---|---|
| 縮放 $S$ | $(2,0)$ | $(0,1)$ | $(2,1)$ |
| 旋轉 $R$ | $(0,1)$ | $(-1,0)$ | $(-1,1)$ |
| 剪切 $H$ | $(1,0)$ | $(1,1)$ | $(2,1)$ |
| 投影 $P$ | $(1,0)$ | $(0,0)$ | $(1,0)$ |

原向量斜率為 1，縮放後為 $1/2$，所以方向變了。指引的「縮放不改方向」需加條件：要對所有非零向量保持方向，須為係數大於 0 的等向縮放。

本例非等向縮放的兩軸係數不同且為正，只有沿座標軸的非零向量保持方向。負的等向係數會使方向反轉；係數為零則使向量失去方向。

旋轉前後長度同為 $\sqrt2$。投影則把 $(1,1)$ 和 $(1,0)$ 都變成 $(1,0)$，丟失的第二座標無法只靠輸出找回。

## 程式（補充）

```python
import numpy as np
x = np.array([1, 1])
maps = {"縮放": [[2, 0], [0, 1]], "旋轉": [[0, -1], [1, 0]],
        "剪切": [[1, 1], [0, 1]], "投影": [[1, 0], [0, 0]]}
for name, values in maps.items():
    A = np.array(values)
    print(name, (A @ x).tolist(), "原點", (A @ np.zeros(2, dtype=int)).tolist())
```
```text
縮放 [2, 1] 原點 [0, 0]
旋轉 [-1, 1] 原點 [0, 0]
剪切 [2, 1] 原點 [0, 0]
投影 [1, 0] 原點 [0, 0]
```

:::tip[讀碼重點]
這裡採欄向量 A @ x；若每個橫列是一筆資料，整批同一變換要用 X @ A.T。
:::

## 怎麼用、怎麼判讀

剪切常由非對角元素產生方向傾斜；但非對角矩陣也可能是旋轉，仍須看實際作用。

線性變換能調整不同方向的敏感度，但結果好不好要依任務檢驗。投影可降低冗餘，也可能把分類所需的差異一起壓掉。

### 換個場景

| 場景 | 指引的操作或條件 | 判讀 |
|---|---|---|
| 特徵工程、神經網路 | 重新組合特徵 | 先確認權重與方向 |
| 正交對齊 | 使用旋轉 | 長度保留、方向改變 |
| 降維、PCA | 投影到子空間 | 需衡量資訊保留 |
| 分類超平面 | 投影到邊界所在空間 | 檢查投影後是否保留類別差異 |
| 能源感測（補充） | 兩個感測方向換座標 | 轉換不是任意交換欄位 |
| 授信表示（補充） | 多指標壓成少數方向 | 不保證保留風險差異 |

## 常見誤解

- 線性變換必須把原點留在原點，但這條件單獨成立仍不足以證明線性。（補充）
- 指引說縮放不改方向，實際上非等向縮放可能改方向；旋轉則保持長度。（補充）
- 降維不保證提升任務表現，投影也不保證可逆。（補充）

## 進階

### 教材勘誤（補充）

指引 3-11 對縮放的方向描述過廣。正的等向縮放才對所有非零向量保持方向；本頁 $S$ 讓斜率由 1 變為 $1/2$，可直接反證一般化的說法。

指引以分類超平面說明投影；若邊界不通過原點，投影需另含平移，屬仿射操作。投影到超平面與投影到其法向量也是不同操作。

## 小結

- 矩陣的每個直欄描述一個輸入基底的去向。（補充）
- 縮放、旋轉、剪切與投影有不同的幾何效果。
- 先看原點、基底與資訊是否丟失，再判讀變換。（補充）
