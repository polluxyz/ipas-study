## 為什麼需要

「用 AI 看影像」還不是可交付的需求。只問有沒有行人、要知道行人在哪裡、要分開每個人的輪廓，需要的輸出都不同。

電腦視覺（Computer Vision, CV）從影像或影片擷取可供分析的資訊。先定義輸出，才能決定資料要標到哪一層，以及模型要學什麼。

## 直覺

同一張街景不必只配一種任務。分類看整圖；物件偵測找各個物件；語意分割替每個像素判類；實例分割再把同類的不同個體分開。

## 定義與公式

### 技術角色與歷史定位

| 技術 | 做什麼 | 典型輸出 |
|---|---|---|
| 影像處理（Image Processing） | 去雜訊、改善亮度或清晰度 | 處理後的像素影像 |
| 模式辨識（Pattern Recognition） | 依影像模式判別類別或位置 | 類別、位置等資訊 |
| 機器學習（Machine Learning） | 從資料學出特徵或判別規則 | 可用來預測的模型 |

這些角色可以出現在同一系統裡。深度學習能把特徵學習和辨識接在一起；並非所有影像處理都需要機器學習。

![沿箭頭看資料由像素走向判斷；機器學習可負責中間的特徵與辨識規則。](figure:l21102-computer-vision-tasks-roles)

電腦視覺研究早在 1960 年代已展開。2012 年 AlexNet 在 ImageNet 影像分類競賽的突破，使大量標註資料、GPU 與卷積神經網路的組合受到重視。

AlexNet 是深度學習視覺發展的重要轉折，不能當作整個電腦視覺領域的起點。

### 輸出決定標註粒度

| 任務 | 要回答的問題 | 標準答案 |
|---|---|---|
| 影像分類 | 整張圖屬於哪一類？ | 每圖類別標籤 |
| 物件偵測 | 物件是什麼、在哪裡？ | 每物件類別與邊界框 |
| 語意分割 | 每個像素是什麼？ | 與原圖對齊的像素類別圖 |
| 實例分割 | 哪些像素屬於哪個個體？ | 每個體遮罩、類別與 ID |

框描述物件的外接矩形，遮罩（Mask）描述像素範圍。語意圖中兩名行人可共用「行人」類別，實例輸出則要分成兩個個體。

## 走一次流程

### 固定一張圖，再換問題

共用檔 `L21102-A-vision.json` 有交通、製造各 20 張圖，使用相同索引與資料分割。下面只切換 T01 的任務，不更換底圖。

1. 只問是否有行人：整圖標籤是「有行人」，不回答人數。
2. 要找位置：記下兩個「行人」框，分別是 `[1,1,3,4]`、`[5,1,7,4]`。
3. 要可行走區域：像素類別圖同時記「道路」與「行人」，兩名行人的類別值相同。
4. 要分開兩個人的範圍：各給一份遮罩，連到個體 ID 1、2。

:::supplement[來源：TorchVision Object Detection Finetuning Tutorial 的 Defining the Dataset；必要前置：把輸出差異落實為可核對標記]
這份教學資料中，兩個人的遮罩各含 6 個像素。分類標籤只有一個值，不能從它倒推出兩個框或 12 個行人像素。

製造領域的 M01 也有兩個零件：整圖可以判斷「有刮痕」，若要求各零件的外形，則要額外標框或遮罩。兩個領域的類別定義各自獨立。
:::

### 理解與生成

影像理解判斷輸入影像已有的內容；影像生成與合成（Image Generation and Synthesis）則產生新的像素內容，也能以既有圖像為條件做編輯。

| 需求 | 輸入 | 輸出 |
|---|---|---|
| 醫療輔助診斷 | 既有醫療掃描影像 | 病灶類別或區域 |
| 設計草圖 | 風格與內容的文字描述 | 新的設計圖像 |
| 風格轉換 | 原圖與指定風格 | 保留部分內容的新影像 |

:::caution[注意]
去雜訊也會改像素，但通常仍歸在影像處理。判斷任務時，要看主要目的究竟是改善輸入品質、辨識內容，還是創造視覺內容。
:::

## 怎麼用、怎麼判讀

把需求寫成「輸入什麼，輸出什麼」。若要求形狀，就不能只交框；若要個別計數，也不能只交整張圖的類別。

分類、偵測與分割可在一個系統內協作，例如自駕同時需要道路區域及障礙物位置。生成圖像可用於設計，也可擴充訓練資料；使用時須區分合成來源與真實觀測。

### 換個場景

| 場景 | 適合的輸出 | 判讀重點 |
|---|---|---|
| 商品辨識、社群內容分類 | 整圖類別 | 不需要逐像素輪廓 |
| 自駕、安防與人流偵測 | 物件框或個體區域 | 同類的不同物件要分開 |
| 城市街景、農作物與醫學影像 | 像素類別或個體遮罩 | 是否需要分個體決定粒度 |
| AR 虛實分離、精密製造 | 個體遮罩 | 同類物件仍須分別處理 |
| 設計、遊戲、風格轉換與訓練資料生成 | 新影像 | 合成資料須記錄來源，另外驗證適用性 |
| 水產養殖（補充） | 每尾魚的遮罩 | 要量個體大小時，整圖類別不足 |

:::supplement[來源：TensorFlow Image segmentation 的 What is image segmentation；核心延伸：以輸出粒度選任務]
其他領域也可照此選擇：倉儲機器人先找包裹框，再視抓取需求取輪廓；衛星地表分析可逐像素判斷土地類別。任務名稱不由產業決定，而由交付資訊決定。
:::

## 常見誤解

- **辨識到行人就知道有幾人。** 整圖分類只表示該類別存在，沒有個體清單。
- **語意圖中同值的像素都屬於同一物體。** 值代表類別，不代表個體身分。
- **新模型能省掉輸出規格。** 架構再強，也要先決定要學類別、框、遮罩或新影像。

## 小結

- 先說清楚要輸出類別、位置、區域，還是新影像。
- 影像處理改善像素，模式辨識解讀模式，機器學習由資料學規則。
- 語意分割標類別；實例分割還要區分同類個體。
- 標註粒度必須支援交付需求。
