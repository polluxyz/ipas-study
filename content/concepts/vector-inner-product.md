## 為什麼需要

一筆建物資料有面積、人數與冷氣時數。把它們排成固定順序的向量（Vector），模型才能知道每個權重該乘哪個特徵。

把多筆資料排成矩陣（Matrix），就能一次做整批預測。指引以這種表示串起特徵、參數與線性模型。

## 直覺

內積（Inner Product），指引稱點積（Dot Product），就是把特徵和權重配對相乘，再加總成分數。可把它想成每個特徵按權重投票；三個特徵就要配三個權重。

### 投影怎麼讀

指引以投影與相似度說明點積的幾何意義。圖中把原向量沿水平方向投影，虛線標示垂直落點。

![原箭頭長 5，沿水平單位方向的投影長 3，內積在此才等於帶符號投影長。](figure:l23102-vector-inner-product-projection)

:::supplement[來源：Deep Learning 第 2 章]
用二維 $u=(3,4)$ 與單位方向 $e=(1,0)$，內積為 3，投影箭頭是 $(3,0)$。這個內積等於帶符號投影長，是因為投影方向的向量長度為 1；原向量長度則為 5。
:::

## 定義與公式

指引用 $\theta$ 表示模型參數，本頁改寫為 $w$；下式的 $\theta$ 則專指夾角。

把單筆輸入 $x$ 與參數 $w$ 都寫成 $d$ 維欄向量，不加偏差的預測是 $w^\top x$。上標 $\top$ 表示轉置，讓 $1\times d$ 乘 $d\times1$ 得到一個數。

指引以 $n\times d$ 的矩陣表示整批資料：$n$ 是樣本數，$d$ 是每筆的特徵數。每個橫列放一筆樣本，乘上同一組權重就得到各筆預測。

:::supplement[來源：NumPy dot；Deep Learning 第 2 章]
實數向量的內積展開為：

$$
w^\top x=\sum_{j=1}^{d}w_jx_j
$$

$j$ 是特徵索引，$x_j$ 是第 $j$ 個特徵，$w_j$ 是對應權重。兩者維數、特徵順序必須一致；逐元素乘法則保留每項結果，尚未加總。

非零向量的餘弦相似度（Cosine Similarity）是：

$$
\cos\theta=\frac{w^\top x}{\lVert w\rVert_2\lVert x\rVert_2}
$$

$\theta$ 是兩向量夾角，$\lVert w\rVert_2$ 就是向量 $w$ 的長度，計算見向量範數與線性組合。餘弦排除長度影響；零向量沒有方向，不能套用此式。
:::

## 算一次（補充）

### 共用資料

本組使用固定的能源與授信合成資料，各 4 筆、3 特徵。能源三欄依序為面積指數、使用人數指數、冷氣時數，第一筆是 $(1,2,3)$。

授信三欄是年收入、往來年數、存款，第一筆是 $(1,1,0)$。兩領域的單位與意義不同，權重只是教學設定，不代表實務因果或決策規則。

### 逐項加權

取能源第一筆 $x=(1,2,3)^\top$，以及共用權重矩陣第一欄 $w=(1,2,-1)^\top$。

| 運算 | 逐項結果 | 最後輸出 |
|---|---|---|
| 逐元素乘法 | $(1,4,-3)$ | 三維向量 |
| 內積 | $1+4-3$ | $2$ |

此時兩向量長度為 $\sqrt{14}$ 與 $\sqrt6$，故餘弦是 $2/\sqrt{84}\approx0.2182$。把權重乘 2，內積變 4，餘弦仍約 0.2182。

### 資料表示到預測

| 物件 | 形狀 | 軸的語意 |
|---|---|---|
| 一筆能源資料 $x$ | $3\times1$ | 3 個特徵 |
| 整批能源資料 $X$ | $4\times3$ | 4 筆樣本、3 個特徵 |
| 一組權重 $w$ | $3\times1$ | 每個特徵的權重 |
| 整批預測 $Xw$ | $4\times1$ | 每筆各一個輸出 |

依序取資料、確認特徵順序、算每列內積，就得到 $(2,4,0,2)^\top$。這是沒有偏差的預測流程；偏差的作用見仿射運算與線性預測。

## 程式（補充）

```python
import numpy as np
x = np.array([1, 2, 3])
w = np.array([1, 2, -1])
print("逐項", (x * w).tolist())
print("內積", np.dot(x, w).item(), (x @ w).item())
cosine = (x @ w) / (np.linalg.norm(x) * np.linalg.norm(w))
print("餘弦", round(float(cosine), 4))
```
```text
逐項 [1, 4, -3]
內積 2 2
餘弦 0.2182
```

:::tip[讀碼重點]
一維 NumPy 陣列的形狀是 $(3,)$，不是明確的欄向量；兩個一維陣列用 @ 得到純量。星號只做逐項乘法。
:::

## 怎麼用、怎麼判讀

線性模型用內積將多特徵濃縮成一個分數。指引提到的相似度，還要區分是否保留向量大小的資訊。

### 換個場景

| 場景 | 適用條件 | 判讀 |
|---|---|---|
| 線性模型預測 | 同長度的特徵與參數向量 | 每個分量順序一致才有意義 |
| 方向比較 | 指引提及投影與相似度 | 先確認大小是否應影響結果 |
| 能源預測（補充） | 面積、人數與時數輸入 | 權重需配合各特徵單位 |
| 授信額度（補充） | 收入、年資與存款輸入 | 分數不是自動合規的決策 |
| 文件檢索（補充） | 非零文字向量 | 比方向時可用餘弦 |

## 常見誤解

- 內積不是逐元素乘法的另一個名字：還差一次加總。
- 內積較大不必然表示方向較近，可能只是向量更長。（補充）
- 特徵順序錯置仍可能算得出數字，但數字已失去原意。（補充）

- 一筆資料是向量，多筆可排成矩陣。
