## 為什麼需要

:::supplement[來源：NIST/SEMATECH e-Handbook 4.4.4]
均方誤差與決定係數 R² 能把模型濃縮成數字，卻不告訴我們錯在哪一段。殘差分析（Residual Analysis）把每筆實際值與預測值的差距攤開看，尋找遺漏的規律。
:::

指引列出線性、誤差常態、變異數齊一、誤差獨立與無多重共線性等條件。診斷時要分別檢查，不能只憑一個好看的指標宣布全部符合。

## 直覺

:::supplement[來源：NIST/SEMATECH e-Handbook 4.4.4；本站 L23303 網店出貨量教學模擬資料]
殘差圖（Residual Plot）把預測值放橫軸、殘差放縱軸。落在零線上方表示實際值較大、模型低估；下方表示高估。

共用出貨資料前七筆在零線上下各 1 箱，第八筆卻在 +20 箱。看圖能直接定位嚴重失準的營業日，不必只猜 MSE 為什麼升高。

![前七筆殘差為正負 1 箱，預測 80 箱的第八筆卻低估 20 箱，須先查這個離群點。](figure:l23303-residual-analysis-orders)

這八筆只是小型教學資料，第八筆因額外團購而離群。單一遠點可以提醒我們查原因，還不足以推定整個高出貨區都存在變異不齊。
:::

## 定義與公式

:::supplement[來源：NIST/SEMATECH e-Handbook 4.4.4；scikit-learn PredictionErrorDisplay API]
本單元固定使用「實際值減預測值」定義殘差：

$$
e_i=y_i-\hat y_i
$$

$i$ 是樣本索引，$y_i$ 是實際值，$\hat y_i$ 是同一筆預測值，$e_i$ 是殘差。兩組數字必須逐筆配對、單位相同且為有限值。

出貨例子第八筆為 $e_8=100-80=+20$ 箱，代表少估 20 箱；第一筆 $e_1=10-11=-1$ 箱，代表多估 1 箱。

訓練資料上的殘差可診斷擬合形狀；要觀察泛化誤差，還需檢查留出或交叉驗證預測。為便於比較，本頁對兩者都沿用同一個正負號規則。
:::

## 算一次

:::supplement[來源：本站 L23303 網店出貨量教學模擬資料]
先按 `L23303-regression.json` 算差，再把點標在圖上；圖形本身不重新訓練模型。

| 樣本 | 預測值（箱） | 殘差（箱） | 圖上座標 |
|---|---|---|---|
| 1、2 | 11；19 | −1；+1 | (11,−1)；(19,+1) |
| 3、4 | 31；39 | −1；+1 | (31,−1)；(39,+1) |
| 5、6 | 51；59 | −1；+1 | (51,−1)；(59,+1) |
| 7 | 71 | −1 | (71,−1) |
| 8 | 80 | +20 | (80,+20) |

絕對誤差和 $7+20=27$，平方誤差和 $7+400=407$。因此 MAE＝3.375 箱、MSE＝50.875 箱平方、RMSE 約 7.133 箱，與其他指標頁一致。

R² 約 0.932，卻仍有 +20 箱的遠點。總分與殘差圖回答不同問題，要一起看。
:::

這張圖的中心仍在零附近，問題是高負載處的誤差散布較寬，稱為變異數不齊（Heteroscedasticity）。它與整批持續低估、或只有一個遠點不同。

## 程式

:::supplement[來源：scikit-learn PredictionErrorDisplay API；本站教學模擬資料]
下面實際輸出主圖座標，與讀圖表核對。圖由相同原始資料的宣告重建，不手填殘差或指標結果。

```python
import numpy as np
y_true = np.array([10, 20, 30, 40, 50, 60, 70, 100])
y_pred = np.array([11, 19, 31, 39, 51, 59, 71, 80])
residual = y_true - y_pred
print("預測／殘差:", list(zip(y_pred.tolist(), residual.tolist())))
print(f"最大絕對殘差的樣本: {np.argmax(np.abs(residual)) + 1}")
```
```text
預測／殘差: [(11, -1), (19, 1), (31, -1), (39, 1), (51, -1), (59, 1), (71, -1), (80, 20)]
最大絕對殘差的樣本: 8
```
:::

:::tip[讀碼重點]
`y_true - y_pred` 的順序決定正負號；畫圖與表格須一致。`np.argmax` 回傳從 0 開始的索引，顯示樣本編號時才加 1。
:::

## 怎麼用、怎麼判讀

線性迴歸的變異數齊一條件，要求不同特徵取值下的誤差散布相近。誤差獨立則關於觀測之間的關係，與散布是否隨預測值擴大是不同問題。

### 圖形對照與下一步（補充）

| 看到的型態 | 優先懷疑 | 下一步 |
|---|---|---|
| 零線附近無明顯型態、寬度相近 | 尚未看到明顯非線性或變異不齊 | 另外檢查常態、時間與特徵條件 |
| 殘差中心形成 U 形 | 遺漏非線性關係 | 檢查特徵轉換或更合適的模型 |
| 殘差上下幅度逐漸擴大 | 變異數不齊 | 按負載分群，評估變數轉換或加權擬合 |
| 少數點離零線很遠 | 離群值、資料錯誤或未建模事件 | 查原始紀錄，保留查核依據 |
| 依時間持續同號或呈週期 | 遺漏時間結構 | 檢查時間圖、自相關及季節性 |

圖形提供診斷線索，並不唯一決定原因。轉換、加權或換模型後，要回到驗證資料重查；不能只為了讓圖變漂亮而刪除真實的困難樣本。

### 換個場景

| 場景 | 判讀重點 |
|---|---|
| 連續目標、關係近似線性 | 指引的線性迴歸場景；對照線性、誤差散布與獨立條件 |
| 需解釋特徵影響、資料與特徵數適中 | 指引列出的條件；除了殘差，還要查特徵之間是否高度相關 |
| 電力負載（補充） | 高負載漏斗形提示誤差尺度改變，依時間有週期則另查季節性 |
| 房價估算（補充） | 高價區彎曲可能遺漏非線性，個別豪宅遠點須查物件特性 |
| 交通流量（補充） | 上下班時段連續同號，應查時間依賴與遺漏時段特徵 |

### 一張圖不能驗證全部假設（補充）

預測值對殘差圖主要看形狀、中心與寬度。誤差是否近似常態，可搭配 Q-Q 圖；是否有順序依賴，要依時間排列並看自相關。

多重共線性是特徵彼此高度相關，可查特徵相關結構或變異膨脹因子（VIF）。殘差呈漏斗形，不能當成特徵高度相關的證據。

常態性主要影響傳統線性模型的部分推論與預測區間做法；計算 MAE、MSE 或 R² 本身並不要求常態。殘差圖看起來隨機，也只能說尚未發現明顯問題。

## 常見誤解

:::supplement[來源：NIST/SEMATECH e-Handbook 4.4.4.1～4.4.4.5；Hyndman、Athanasopoulos，第 5 章]
- **「正殘差代表高估。」** 本頁用實際減預測，正值代表預測太小。
- **「漏斗形代表誤差不獨立。」** 漏斗形首先指向變異不齊；獨立性要另查觀測順序。
- **「一個 +20 的點就證明有漏斗形。」** 漏斗形是散布隨尺度改變的整體型態，需要多筆支持。
- **「R² 很高，或殘差平均為零，就不必檢查。」** 平均與總分會隱藏彎曲和散布改變。
:::

## 進階

### 時間序列殘差與白噪音（補充）

自相關函數（Autocorrelation Function，ACF）檢查殘差與先前時刻殘差的關聯。如果多個時滯仍有明顯關聯，表示模型可能尚未抓住時間結構。

對 ARIMA 類模型，可重新檢查自迴歸、移動平均與季節性設定；不應只因看到週期，就認定某一個參數必須增加。先確認時間順序與預測步長，再選檢查方式。

白噪音（White Noise）通常指平均為零、變異固定且不同時刻不相關的序列。沒有顯著自相關，不等於已證明獨立或常態，也不保證目前模型最佳。

本頁的網店廣告費 `x` 不是時間索引，不能直接對它做時間自相關判讀。

## 小結

- 殘差固定為實際減預測，正號表示低估。
- 共用例子的第八筆在 (80,+20)，總分良好仍需查這個遠點。
- 彎曲看中心、漏斗看寬度、時間依賴看順序，不要混成同一種問題。
- 隨機散布不能證明全部條件成立，應搭配其他診斷與留出資料。
