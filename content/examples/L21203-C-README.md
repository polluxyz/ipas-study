# L21203-C 漂移共用資料

`L21203-C-drift.json`是教學合成資料，供本組五頁共用。授信與視覺檢測各四期，每期100筆摘要；兩領域數字相同是刻意控制比較，並非同一批真實個案。

欄位約定：`counts`依低、高組順序記總數，`positives`記組內真值1的人數，兩者差是負例數。授信真值1表示到期違約；視覺真值1表示人工判定瑕疵。兩個領域的分組界線分別為負債比40%與刮痕面積10 mm²。

模型`v1-fixed`對低、高組分別給0.2、0.8分，閾值0.5，分數達閾值即判陽性。所有頁使用同一P0參考窗；P1僅改輸入、P2僅改條件關係、P3兩者都改。

批次互不重疊，各期索引001–100；組內依正例、負例排列，`index_prefix`加索引可重建唯一識別。沒有切成訓練與測試，也沒有調參；所有樣本都是監控資料。`seed=42`為共用契約，本檔按精確計數建構，不依賴隨機抽樣。

P0至P1輸入比例的KL(P∥Q)=0.2231435513，反方向0.1927447570，PSI=0.4158883083。另設5+5筆毫米量測，KS的D=0.4；它不是由分箱摘要還原的原始資料。

`output_counterfactual`是同一P0的另一次輸出後處理比較：0.2／0.8變成0.6／0.9，AUC仍0.9，固定閾值的準確率0.5、預測陽性率1.0。它不是固定v1四期中的第五期，不用來證明概念漂移。

`smoothing_example`示範兩期各10筆、每箱加1，參考(0,10)變(1/12,11/12)，當期(5,5)變(6/12,6/12)。

## 頁面與圖

- `data-drift`：P0／P1輸入改變、P2未改變及準確率未變的反例。
- `concept-drift`：P0／P2同輸入不同條件關係；P1為僅輸入改變的反例。
- `model-drift`：四期固定模型的效能與預測分布對照。
- `drift-detection`：四期分流，以及獨立的AUC不變反例。
- `distribution-drift-detection`：KL、PSI、平滑、ECDF與KS核算。
