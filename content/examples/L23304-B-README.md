# L23304-B：穩定更新、容量與能力保留

`L23304-B-training.json` 是本組四頁的共同教材資料。能源與客服各128筆，原始列、索引、切分及種子直接承接 `L23103-C-energy.json`、`L23103-C-text.json`；客服沿用前組文字意圖分類的數值表示，不是真實對話紀錄。

- `seed=23103`；每領域索引0–95訓練、96–111驗證、112–127測試。只用驗證挑設定，測試保留到選定後。
- `upstream_gradients` 指向前置組 `L23103-C-updates.json`；固定初值[1,-1]、兩步梯度[3,4]與[-1,2]。優化器頁與裁剪頁直接讀該檔，後續梯度不依更新後參數重算。
- `architectures` 列出逐層寬度，包含輸入與輸出；每個全連接層有偏差。small/base/wide/deep分別為5/17/129/117個參數，deep有6個隱藏層，base和wide各1個。
- `capacity_logs` 是12輪的教學日誌，`train`/`validation`為同領域相同損失尺度。能源以標準化需求指標的平均平方誤差為單位；客服以二元交叉熵為單位。兩領域數值刻意相同方便教學，不代表兩種損失可直接互比。
- 容量候選相對base只改一項架構設定：small/wide改寬度，deep改隱藏層數；其他條件固定。驗證值不是實際框架訓練產生，不能據此推薦某架構普遍較好。
- `forgetting`記錄新舊任務各16筆固定留樣的逐筆正誤遮罩。能源以是否達誤差容許範圍判為正確，客服以意圖正確判為正確；它們是獨立教學任務，不能從原始回歸target或label推算遮罩。
- `full_log`是全量微調12輪的正誤日誌。before/full/freeze/lora/replay的舊、新正確筆數分別為(15,8)/(10,15)/(14,12)/(13,14)/(14,14)，分母都是16。
- 保留策略各自相對full只改一項：凍結主幹、低秩更新、或混合舊資料。replay每批固定16筆、舊4新12，其他每批新16；因此總樣本處理預算相同，新任務曝光量不同，屬策略代價。凍結與LoRA只是比較情境，未實作大型模型。

使用頁面：優化器選擇（固定梯度、狀態記憶體）、梯度裁剪與迴圈位置（固定向量、更新）、網路深度寬度與容量（架構與日誌）、災難性遺忘（新舊任務逐筆正誤）。

圖重建：在repo根目錄執行 `node tmp/rollout/groups/W-L23304-B/figure-scripts/make-assets.mjs`。它從原始固定設定生成資料及圖；不修改任何前置組檔案。獨立核算見本組工作資料夾 `examples-check.md`。
