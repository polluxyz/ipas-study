# L21102-C：定位、辨識與跨影格流程

`L21102-C-events.json` 為教學合成資料，製造 M01–M12、交通 T01–T12 各 12 事件。沒有真實影像、病歷、車牌或生物特徵；相似度及預測都是固定的教學輸入。

## 固定規則

- 種子固定 21102；本例使用決定式規則，不執行隨機抽樣或模型訓練。
- 各領域 01–04 訓練、05–08 驗證、09–12 測試；每四事件是一段獨立示意片段，同片段不跨切分。所有頁都沿用同一事件索引。
- 與前置 B 組共用「左上原點、右下不含」框約定；本組為新事件，未搬用或改動 B 組資料。框以示意像素為單位，軌跡位置以公尺為單位，兩者不可直接互換。
- 每個事件是一個多任務容器：偵測物件、分類裁切、人臉、文字及互動軌跡分屬不同標註，不把匿名身分當成物件類別。分類輸入是 `[40,0,48,8]` 的獨立裁切圖，不是偵測框 `[0,0,4,4]` 的同一物件；分類正常不代表整個事件沒有其他瑕疵。評分與該任務、該事件的真值比較。
- 同領域六類分類與兩類偵測各有類別表；製造與交通分別評分，不合成跨領域 mAP。
- AP 使用全點精確率包絡積分、IoU ≥ 0.5、一對一同影格同類別匹配；不含 crowd、ignore、大小分組。偵測信心同分按事件與預測 ID 升序。Top-k 同分按較大類別索引優先，與 scikit-learn 相同。

## 欄位

| 欄位 | 意義 |
|---|---|
| `event_id/domain/clip_id/split` | 索引、領域、片段與固定切分 |
| `detection` | 含物件 ID、類別、框的真值與含偵測信心的預測 |
| `classification` | 獨立分類裁切區域、單一真值索引及六類分數，分數合計 1 |
| `face` | 人臉框、偵測信心、匿名真值、候選身分與示意相似度 |
| `ocr` | 文字真值框及字串、示意預測框及預測字串 |
| `timestamp_ms/tracking` | 片段內時間、軌跡 ID、位置、角度、追蹤有效性及互動 |

## 關鍵參考數值

各領域測試集的偵測兩類各 2 個真值。第一類偵測信心排序的 TP/FP 為 `[1,0,1]`，AP = 5/6；第二類為 `[0,1,1]`，AP = 2/3，兩類 mAP = 3/4。第二類偏框 IoU = 4/28 = 1/7；第一類的重複正框 IoU = 1，仍算 FP。

各領域測試集的六類真值名次為 1、2、5、6；Top-1 正確率 = 1/4，Top-5 正確率 = 3/4、錯誤率 = 1/4。評測只用 09–12；01–08 雖保留分數，並不參與這些結果。

M09 文字為 `LOT-204`、T09 為 `QX-204`，真值區域均為 `[10,10,70,30]`。M10/T10 故意偏框並缺末字，M11/T11 則在正確框內把 `2` 轉成 `Z`，用於區分定位錯與轉錄錯。

09–12 的時戳為 0、100、200、300 ms，真實位置 x 為 0.1、0.2、0.3、0.4 m。最後一筆追蹤無效，位置是離線真值，不可當成線上已量得位置；200 ms 捏合對應虛擬縮放 1.2。

## 使用頁與重建

六頁共同使用本資料：`detection-map` 核算匹配與 AP；`top-k-error` 核算排名；`face-recognition`、`ocr`、`visual-tracking` 走各自流程；`vision-application-planning` 比較同事件的不同輸出責任。醫療及零售需求另以文字案例說明，不混入製造／交通評分。

重建腳本：`tmp/rollout/groups/W-L21102-C/figure-scripts/create-assets.mjs`。執行位置為 worktree 根目錄；數值另由 `examples-check.md` 核算。七張 SVG 的數字、排名及座標由本檔資料生成；流程框只表達角色，未冒充模型實驗結果。
