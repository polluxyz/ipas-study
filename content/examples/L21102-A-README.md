# L21102-A：視覺任務與標註共用例子

`L21102-A-vision.json` 是完全合成的教學資料，交通與製造各 20 張，沒有照片或個資。每張是 8×6 RGB 像素陣列；矩形積木代表行人或零件，不可用來證明模型效能。兩個領域只共用格式，不混合類別訓練。

## 固定規則

- 固定種子記號為 21102；資料由索引規則產生，沒有隨機抽樣。
- 索引 T01～T20、M01～M20，領域內 01～12 預留訓練、13～16 驗證、17～20 測試。互相比較的頁面不更換索引或切分；實際使用另須排除隔離資料。
- 交通奇數索引有兩名行人，偶數沒有；製造每張都有兩個零件，奇數有一格白色刮痕、偶數沒有。每領域兩個整圖類別各 10 張。
- 圖邊左上為 (0,0)，x 向右、y 向下，單位為像素。xyxy 框右下界不含；像素矩陣使用 `[y][x]`。
- 有物件時，兩框固定為 `[1,1,3,4]`、`[5,1,7,4]`；物件各占 6 格。下方兩列是道路或輸送帶，共 16 格。
- 點位可用小數，v=0 未標且以 (0,0) 佔位，v=1 已標但不可見，v=2 已標且可見。這裡使用 COCO 的可見性語意，但不是其完整人體點集。
- T03、M03 的 RGB 以截邊 3×3 鄰域平均做一次模糊，類別、框與遮罩保留合成來源。`quality` 是畫質條件；T03 的裁決為隔離，所有點位改成 v=0、x=y=0，表示無可靠人工位置。
- `review_status` 為 `ready` 時可用於格式練習；`quarantined` 表示須排除、等待覆核。T03 保留的類別、框及遮罩只供追溯合成來源，不能因已知真值就視為可靠人工標準答案。

## 欄位

| 欄位 | 意義 |
|---|---|
| `image_id`、`domain`、`split` | 影像 ID、領域、預先保留的資料分割；不是核准使用狀態 |
| `width`、`height`、`channels`、`pixel_rgb` | 影像尺寸、通道與實際 RGB 像素 |
| `image_class`、`quality` | 每圖單一類別與畫質條件；兩者不互相替代 |
| `semantic_map`、`instance_map` | 每像素類別與本圖個體 ID；0 的意義各查規則 |
| `objects` | 每物件的 ID、類別、框、二元遮罩、點位與遮擋旗標 |
| `review_records` | 教學雙人標記分歧、裁決、覆核者與規範版本 |

使用訓練資料時，同時篩選 `split === "train"` 與 `review_status === "ready"`。預留訓練各 12 張；排除 T03 後，交通可用 11 張、製造可用 12 張，驗證與測試仍各 4 張。

`category_maps` 分領域定義：交通的 0／1／2 是其他背景／行人／道路，製造是其他背景／零件／輸送帶。個體圖的 0 只表示不屬於任何已標個體，不等於語意類別 0。

`objects[].keypoints` 的固定順序：交通是 `head,left_wrist,right_wrist`，製造是 `left_hole,right_hole,notch`。人體例子約定行人背對鏡頭，左右依本人。點名是本例的示意定義；圖形沒有真實人體關節或工業幾何的精度。

## 關鍵參考數值

| 項目 | T01 | M01 |
|---|---|---|
| 整圖分類 | 有行人 | 有刮痕 |
| 語意 0／1／2 的格數 | 20／12／16 | 20／12／16 |
| 個體 1／2 的面積 | 6／6 格 | 6／6 格 |
| 兩框轉 xywh | [1,1,2,3]、[5,1,2,3] | 相同 |
| 第一物件的 v=0／1／2 點數 | 0／1／2 | 1／0／2 |

T02 無物件，語意 0／1／2 的格數為 32／0／16，個體圖全為 0。M02 仍有兩個零件，只是沒有刮痕；整圖「無刮痕」不等於「沒有零件」。

## 使用頁面與圖

- `computer-vision-tasks`：同圖四種輸出與技術角色。
- `handcrafted-visual-features`：固定圖像的邊緣、特徵點、色彩紋理概念示意；SVG 不是 Canny／SIFT 實際輸出。
- `image-annotation`：整圖類別、兩框格式、邊界與品質覆核。
- `image-mask-annotation`：語意矩陣、兩份遮罩與個體表。
- `keypoint-annotation`：人體與工業第一物件的三點表、可見性檢查。

SVG 中積木格的相對位置與 T01 對齊；關鍵點圖的工業面板為局部放大示意，座標以 JSON 與表格為準。所有圖均為本組自製的 SVG，不引用遠端圖資。
