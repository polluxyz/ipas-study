# L23402-C 工具與公平治理共用案例

`L23402-C-audit.json`是教學合成清冊，不代表真實招聘、信貸、語言或影像群體表現。四頁共用它；來源資料保留在前置組B的招聘、信貸檔案，不修改或複製成另一套人員資料。

招聘與信貸刻意使用相同的三版本及週窗計數，只比較面試與核准的決策語意、傷害及責任；不把換領域名稱當成另一組獨立實證。

## 欄位與固定規則

- `domains`：招聘、信貸各一個命名空間。`source`指向前置組B檔案，`record_ids`列出完整40筆固定稽核索引；每群20筆、正負各10筆，種子23402。
- `versions`：base-v1讀`y_pred`，middle-v2讀`constraint_middle_pred`，strict-v3讀`constraint_strict_pred`。三版是前置組預設候選輸出，沒有執行AIF360或Fairlearn重訓，也不宣稱由特定演算法產生。
- `groups`：保留`count,tp,fn,fp,tn,selection_rate,TPR,FPR`。分別是總數、四格計數、有利決策比例、正類召回率與負類誤選比例。所有結果從指定來源逐筆重新計算。
- `domains[].policy`：先按陣列項目的`id`選`recruitment`或`credit`。準確率至少65%，TPR及FPR群體差距均至多10個百分點；每群至少20筆僅為初步檢視門檻，沒有統計穩定或法律合規保證。
- `weeks`：W1至W4日期、版本、兩群計數、具名責任與動作。每領域每期40筆獨立合成事件，與固定稽核集分離；相同計數不表示相同人員。
- 每週表是完整計數清冊，不宣稱已有原始模型、特徵或影像可重新推論。真值在示例窗尾完整可用；真實信貸需依成熟時間及可觀測範圍另報。W3沒有拿來訓練W2。
- `slices`：獨立語言、影像分類切片，每列40筆，正負各20筆；保留同樣四格與率。語言正類為需優先處理的客服請求，影像正類為存在待檢目標。不能把這些表與招聘／信貸視為同一模型。
- 頂層`review_roles`與`domains[].complaint`：教學責任、期限及閉環。招聘與信貸各一則W3申訴；兩工作日回應、五日安排調查只是示例政策。
- 承接`L21302-E-operations.json`的真值成熟、分群監控及責任回應原則；本清冊未沿用其1000筆資料或日期因果鏈。

## 關鍵參考數值

| 版本 | A的TP/FN/FP/TN | B的TP/FN/FP/TN | 準確率／最大兩率差距 |
|---|---|---|---|
| base-v1 | 8/2/2/8 | 8/2/6/4 | 70%／40點 |
| middle-v2 | 7/3/3/7 | 6/4/4/6 | 65%／10點 |
| strict-v3 | 6/4/4/6 | 6/4/4/6 | 60%／0點 |

選取率差B減A：base為+0.20，其餘為0。只有middle同時通過本例公平及最低效能門檻。W1至W4的FPR差分別40、10、30、10點。

語言切片召回率90%／70%、FPR10%／30%；影像條件切片召回率90%／60%、FPR10%／40%。少數語言漏判率30%，主流10%；低光低解析漏判率40%，標準10%。

## 頁面用途與重建

`aif360`教輸入契約、方向與三階段選擇；`fairlearn`用同一版本表教分群及約束流程；`fairness-governance`教政策及決議；`fairness-audit`教週窗、跨語言／影像切片、證據與申訴。

本組生成與核算腳本在`tmp/rollout/groups/W-L23402-C/`，數字核算在`examples-check.md`。三張圖均是流程示意圖，沒有手填數據曲線或宣稱工具已執行。範例是固定輸出評估，不是訓練重現包；真實系統須另保存模型權重、程式版本、環境鎖檔與受控資料接取。
