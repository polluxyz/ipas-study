# L23302-B 共用解釋與搜尋例子

`L23302-B-explanations.json` 是教學合成資料，供 explainable-ai、shap、lime、partial-dependence-plot、automl 五頁共用。授信與醫療各80筆，沒有真實個資，也不是可採用的授信或診斷規則。

## 固定規則

- `X` 是4種第一特徵 × 4種第二特徵 × 5種年齡的笛卡兒積，順序固定；三欄平均皆0。
- 授信 `raw_X`：月收入千元為60＋20×第一欄、負債比為0.4＋0.2×第二欄、年齡為45＋20×第三欄。醫療則是收縮壓125＋20×第一欄、檢驗值5＋2×第二欄、年齡同前。
- `reference` 是事先指定、已凍結的解釋用模型，截距−0.4；授信係數[−0.8,1.2,0.4]、醫療[0.8,1.2,0.4]。先算log-odds，再經Sigmoid轉正類機率。正類是授信違約或醫療診斷陽性。
- `reference.background_indices` 為80筆無標籤參考人口；用來解釋參考模型，不用來選搜尋候選。授信固定個案[−1,1,0.5]，醫療[1,1,0.5]，兩者log-odds均1.8，機率0.858149。
- `label` 是依參考機率、種子23302（醫療23303）抽取的二元標籤。資料是獨立合成個體，不代表有時間或群組依賴。
- `dev_indices` 60筆、`test_indices` 20筆，`cv_indices` 為開發集內3摺的全域索引；候選、摺與種子一致才比較分數。

## 衍生結果

- `candidates` 是另外在開發資料擬合的邏輯迴歸、深度2決策樹、40棵深度3森林；儲存參數、每摺Logloss、80筆及固定個案預測。解釋頁使用`reference`，不可把搜尋候選預測混入其解釋。
- `winner` 只按開發集平均Logloss選擇；`winner_test_logloss` 是定案後的封存測試結果。授信勝出邏輯迴歸，CV 0.630642／測試0.489431；醫療勝出森林，CV 0.560165／測試0.561024。
- `lime` 儲存種子7與11各120個擾動、距離權重、原模型機率與中心化替代模型。取樣標準差0.35，裁切到[−1,1]；核寬0.5。獨立種子99的120筆鄰域用於忠實度核算。
- `pdp` 對第一特徵網格[−1,−0.5,0,0.5,1]逐值替換80筆、保留其餘欄位，再存機率與平均；授信為[0.580041,0.500000,0.419959,0.342992,0.271999]。
- `feature_grid` 是圖上連續切面的81個位置；圖稿從JSON計算，不手填結果。

## 參考數字與用途

授信個案SHAP（log-odds）為[0.8,1.2,0.2]，基準−0.4；80筆平均絕對貢獻為[0.6,0.9,0.24]。機率尺度的平均背景輸出是0.423758，不能以Sigmoid(−0.4)=0.401312替代。

授信LIME核心種子7的中心預測0.859191、獨立鄰域加權R² 0.989759；種子11則0.859593、0.990104。這是三特徵、無懲罰的教學線性替代擬合，未重現套件的離散化與特徵挑選。
