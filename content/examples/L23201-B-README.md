# L23201-B 共用教學資料

兩份資料各 24 筆，都是自行設計的合成資料。電商與製造各自固定兩維特徵，四個概念頁使用相同索引與候選輸出；不可把合成結果當成實際效益。

## 檔案與欄位

- `L23201-B-commerce.json`：E01–E24，電商顧客。
- `L23201-B-equipment.json`：M01–M24，製造設備。
- `index` 為零起算索引；`id` 是閱讀用索引，不作特徵。
- `features` 是固定二維座標，`observed` 是對應原始單位。電商為訂單次數與金額／1,000 元；製造為（溫度−50）／5 與（振動−0.5）／0.1。
- 上述換算為事先指定的單位轉換，不是由全體資料估計的標準化。若另用 StandardScaler，必須依評估目的限制 fit 的資料。
- `reference_group` 是保留的三群參考分組；無標籤視圖必須隱藏它。分群、距離與投影均只使用 `features`。
- `binary_target`、`numeric_target`、`positive_probability_A/B`、`prediction_A/B` 是損失選擇頁的獨立監督任務與候選預測；都不得混入無標籤擬合。
- `numeric_target` 與對應預測的電商單位為百元，製造可解讀為剩餘壽命小時。數字只是示範任務配對，不是故障風險估計。
- 電商 `numeric_target` 是獨立設計的下月金額目標，與 `observed` 的 30 日金額沒有換算關係；量級差不代表已驗證的消費成長。
- `candidate_separate`、`candidate_merge`、`candidate_mixed` 是人造候選群編號，不是實際演算法的預測。分別為三群分開、前兩群合併、各群交錯混成兩群。

## 固定規則

每群八筆相對偏移依序為 (0,0)、(0,2)、(1,0)、(1,2)、(0,1)、(1,1)、(0,3)、(1,3)。電商三個起點為 (1,1)、(7,1)、(13,1)；製造為 (1,1)、(7,1)、(4,7)。起點不是八點平均的群中心。

`binary_target` 為索引除以 2 的餘數。甲的正類機率每六筆循環 0.1、0.8、0.2、0.7、0.3、0.6；乙對負類給 0.4、正類給 0.6。這是人工假設，不是讓模型偷看答案的做法。

二元標籤按索引安排，沒有設計成可由特徵學出的關係；它只供比較固定預測的損失，不用來展示模型訓練成效。

`numeric_target` 為 100 加第一維的兩倍及第二維的三倍。甲的預測誤差每六筆為 1、1、1、1、1、6；乙每筆為 2。

手算子集 `hand_indices` 固定為 [0,1,8,9]，即 E01、E02、E09、E10 或對應 M 索引。此子集是獨立的距離教學，不充當未來泛化的驗證或測試。

另備手動固定的 16／4／4 切分，兩領域共用：

- 訓練：[16,15,18,19,9,7,17,23,6,10,3,0,20,12,5,11]。
- 驗證：[14,22,2,4]。
- 測試：[21,1,13,8]。

`seed: 42` 用於需要亂數的模型初始化，例如獨立核算腳本中的 KMeans；切分索引本身直接固定，不宣稱由該種子抽出。頁面裡的人工候選沒有亂數。
