# L23203-B 激活與批次統計例子

`L23203-B-activations.json` 是教學合成資料，沒有臨床效度或實際客服成效。

## 欄位與固定規則

- `seed=23203` 是本組重現識別；資料以固定索引規則列出，並未隨機抽樣。
- `probes=[-4,-1,0,1,4]`：ReLU、Sigmoid、Tanh 逐項轉換；Softmax 把整組視為同一筆五類分數。`curve` 固定繪圖範圍與步長。
- `split`：兩領域均用索引 0–15 訓練、16–19 驗證、20–23 測試。本組不訓練模型或據此宣稱泛化成效，保留索引供後續比較。
- `medical.rows`：24 筆；`index` 是零起算索引，`id` 是識別字串，`x1/x2` 是示意特徵，`logit` 是給定的未壓縮分數，`binary_label` 以正分數標 1。標籤與分數的人為配對不代表真實模型能力。
- `service.rows`：24 筆；`embedding_1/embedding_2` 為示意嵌入，`logits_3` 對應查詢／退款／變更三類，`intent` 是給定的整數標籤。`tag_logits` 為另外一個「可同時成立」的多標籤任務，依序代表需退款／有客訴／需改址，不能與三類單選混用。
- `logits_3` 是給定分數，不是由 `intent` 訓練出的模型輸出，兩者可不一致。例如 S01 的標籤為查詢，但最高分屬變更；本組只示範轉換，不據此聲稱預測正確。
- `batch_norm`：醫療 M01–M04 與客服 S01–S04 的另一組給定中間激活，均為相同的 4×2 矩陣；不是由上述原始特徵計算所得。欄為特徵，列為樣本。`gamma/beta` 是指定的可學習仿射參數，`initial_mean/initial_var` 是訓練前移動統計，`momentum` 採 PyTorch 的新批權重慣例。

## 使用頁與重建

ReLU、Sigmoid、Tanh 共用五值與醫療索引；Softmax 共用五值及客服 S01。BN 用兩領域相同索引的四筆中間激活；各頁的換景延伸均明示為補充。
