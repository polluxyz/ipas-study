# L23101-A：隨機變數與分佈的共用教學資料

全部是教學合成資料，不作實際製程或客服效能的證據。各頁先區分「固定觀察」「假設的機率模型」「依模型抽樣」，不得用一次觀察反證模型的期望。

## 製造資料

`L23101-A-manufacturing.json` 共100件，`item_id` 為固定索引 M001–M100；前50件日班、後50件夜班，班別不改變本例的生成機率。`defect` 為0或1，1代表瑕疵；`thickness_mm` 的單位是毫米。

- 前五筆固定：標籤 `[0,1,0,0,0]`，厚度 `[8,10,12,11,9]` mm。它們是手算示例，不宣稱是隨機抽中的五筆。
- 其餘95筆使用 NumPy `default_rng(23101)`，先抽 `binomial(1,0.2,95)`，再抽 `normal(10,2,95)`，厚度存到小數第6位。瑕疵與厚度獨立生成，並未以厚度門檻定義瑕疵。
- 教學模型參數為單件瑕疵機率0.2、厚度平均10 mm及標準差2 mm；不要求樣本比例、平均或標準差恰好等於模型參數。
- 條件輸出例固定為日班、厚度12 mm，瑕疵機率0.2、正常機率0.8；因本例獨立生成，與邊際機率一致。
- 決策例假設複檢可完全消除每件100元的漏檢損失，正常品放行零損失，複檢成本分別為8元、30元。放行的預期損失20元，故兩個情境有不同決策。

## 客服資料

`L23101-A-customer.json` 有48個不重疊的30分鐘窗口，索引為 W01–W48，從第0分鐘連續記到第1440分鐘。`calls` 是窗口內來電通數；`events` 按到達時刻遞增排列。

- 前兩個窗口固定供手算：W01在第10分鐘有1通；W02在第35、40、55分鐘有3通。前兩個窗口刻意固定，分析生成模型時要排除。
- W03起使用 NumPy `default_rng(23102)`，逐窗口先抽 `poisson(2)` 個事件，再抽相同數目的 `uniform(0,30)` 窗口內位置並排序。計數加條件均勻時刻的構造對應同質泊松過程的窗口抽樣。
- `interval_min` 是相鄰來電的間隔，可以跨窗口；事件表第一筆從觀察起點計。窗口表的同名陣列依該窗口事件順序列出，空窗口是空陣列。
- 到達時刻與間隔各保留6位小數；相鄰到達時刻相減，與儲存的間隔可能相差約0.000001分鐘，這是分別捨入造成的差異。
- `wait_min` 是從窗口起點等到該窗口第一通來電的時間。空窗口為 `null`，表示30分鐘內未觀察到第一通，不能改填0，也不是顧客排隊時間。
- 率為每分鐘1/15通，30分鐘平均次數2、60分鐘平均次數4；指數間隔平均15分鐘。這些是理論參數，不是從前兩窗口估出來的結論。

## 各自獨立的手算模型

`pmf_hand_model` 的完整取值只有0、1、2，質量為0.2、0.5、0.3。這是有限取值示意，不是泊松分佈，也不是48窗口資料的頻率表；合法總和1，至少1通的機率0.8。

`uniform_demo` 是客服系統的提示延遲，均勻落在0至2分鐘。它與來電過程無關：密度0.5／分鐘，0.5至1.5分鐘的機率0.5，兩端CDF為0.25、0.75。初始化的另例為均勻2至6，3至5的機率也是0.5。

`slow_failure_demo` 是第二領域的設備壽命假設：固定率0.5／小時。壽命超過2小時的機率與已運作3小時後再運作超過2小時的條件機率，皆為 `exp(-1)`；不能延伸到具有老化故障率的設備。

## 關鍵核對值與使用頁

| 頁面 | 共用資料 | 核對值 |
|---|---|---|
| probabilistic-modeling | 製造條件輸出、客服W01/W02 | 機率0.2/0.8；放行預期損失20元 |
| discrete-random-variable | 有限取值PMF模型 | 總和1；至少1通0.8 |
| bernoulli-binomial | 製造前五筆與單件模型 | 恰1件0.4096；總數期望1、變異0.8 |
| poisson-distribution | 客服窗口模型 | 零通：30分鐘0.135335；60分鐘0.018316 |
| continuous-random-variable | 提示延遲模型 | 密度面積與CDF差值皆0.5 |
| normal-uniform-distributions | 厚度模型、初始化另例 | 12 mm對應z=1；常態10至12面積0.341345 |

`exponential-distribution` 使用客服的固定率與設備壽命另例：`exp(-1)=0.3678794412`。上表限制為6筆，將本頁另列於此。

程式段落自足地重設相同領域種子，示範同一組模型參數，並非重播整份資料的抽樣順序。例如製造檔先抽95個單件標籤再抽厚度；常態頁則重設種子後直接抽厚度，因此兩者隨機樣本不必逐筆一致。本組不進行訓練／測試切分。

## 示意圖

本組7張SVG均為解析機率模型、有限取值表或流程示意，具 `title`、`desc`、本機文字、來源與單位。常態／均勻採相同橫縱座標，密度面積與CDF採同一均勻延遲模型；泊松兩面板則比較30與60分鐘的PMF，只畫0–10通，更大通數仍可能發生。

既有JSON模板僅支援ROC、PR、學習曲線、殘差及混淆矩陣，本組沒有使用這五類數據圖。分佈圖從兩份例子JSON的模型欄位計算座標、標籤與面積；生成腳本為 `tmp/rollout/groups/W-L23101-A/figure-scripts/generate.py`，360px視覺驗證腳本留在同組工作資料夾。
