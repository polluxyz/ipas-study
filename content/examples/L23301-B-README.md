# L23301-B：重複、型別、離群值與NumPy共用例子

`L23301-B-cleaning.json`是教學合成資料，含製造與零售各32筆原始快照，不含真實個資。五頁共同使用：data-consistency、data-types-time-parsing、outlier-detection、outlier-treatment、numpy-data-operations。

## 與前置組的關係

參照`L23301-A-missing-data.json`的真值週期10、20、30、80、25、45，以及驗證列加20的規則。本檔是另一批完整採集的品質教學快照，沿用固定索引與數字；不是將A組的truth當作補值輸入，也不改寫A組原檔。

製造M01–M04的正確溫度仍是10、20、30、80°C，M04原始176°F；零售同索引金額為10倍。A組資料不在本worktree時，依序列規則與本檔`provenance`仍可重建；主checkout合併後可再交叉核對。

## 欄位與固定規則

- `index`：0起算、不可重編的匯入列位置。`row_id`識別原始匯入列；`event_id`識別業務事件，兩者不可混當去重鍵。
- `group_id`：每4列同一機台或顧客；同群不同事件可合法保留。`split`固定訓練0–23、驗證24–31；種子23301，沒有另抽切分。
- `raw`：原始字串、單位、含時區時間、類別、質量及質量單位。質量2500公克與2.5公斤相同，類別A/a需依表統一。
- `expected`：合成生成時的核對真值；不當作清理器或模型可取得的輸入。無法查回的999不直接以此欄還原。
- `evidence`：已由外部日誌或儀表查證的教學情境，不是根據待預測標籤決定清理。
- `cleaning_result.cleaned`：從原始值依已知規則清理的結果，保留索引、群組、單位及時間失敗旗標；數值可用不代表所有時間分析也可用。

## 注入的品質事件

- 索引3：製造176°F轉回80°C；零售800元，兩者都是已確認的有效極端值。
- 索引10：999為已查證錯誤碼，無法由該碼找回原值；本例排除該列的數值建模輸入。
- 索引12：時間字串是不存在的2026-02-30；保留原字串，清理後時間為null、失敗旗標為true，數值欄仍可用。
- 索引30與31：同為索引28的重送；索引31另有空白、小數表示及小寫類別。去重保留索引28，兩份副本都在原驗證區內。

每域32→事件去重30→排除已知錯誤碼29列；訓練剩23列、驗證剩6列。時間失敗列仍包含在29列內，若做依時間的分析則須另決定處置，不默默換成任意日期。

## 校準、程式與圖的小例

- `calibration.indices=[0,1,2,4,6,7,8,3]`，取製造10、20、30、25、10、20、30、80°C；全是原訓練列。這是八筆教學校準子集，不是全24列的估計結果。
- 標準差採`ddof=0`；分位數採`method=linear`；Z候選門檻絕對值嚴格大於3；IQR候選嚴格小於下界或大於上界，係數1.5。
- 總和225、均值28.125、平方偏差總和3496.875、變異數437.109375、標準差20.9071608546。80的Z約2.4812072936，未標記；IQR上界48.75，會標記80。
- Q1=17.5、中位數22.5、Q3=30、IQR=12.5，下界−1.25、上界48.75；界內實際鬚端10、30。限界後80成48.75，差31.25；八筆均值由28.125降至24.21875。
- 零售同索引的金額皆為10倍，Z不變；IQR界線−12.5～487.5元，800元仍為候選。`log1p(80)=4.3944491547`、`log1p(800)=6.6858609471`，轉換後不是原單位的量測值。
- `parsing_fixture`保存001識別碼、10/20/30/bad與含時區的時間。08:00 +08:00即00:00 UTC，Unix秒1767225600；至00:30 UTC相隔1800秒／30分鐘，第三個不存在日期解析失敗。
- `numpy_fixture`把索引0–3重排成2×2同單位矩陣：axis=0均值[20,50]、axis=1均值[15,55]；第二欄>50只留[30,80]。權重[1,2]的逐元素乘積[[10,40],[30,160]]，矩陣向量乘積[50,190]。
- `density_fixture`是獨立的22個同尺度二維座標：12個密群、8個疏群、局部候選與全域候選各1；只供局部密度直覺，不是溫度時間圖的另一次座標投影，也不手宣告LOF分類。

## 使用與重建

- data-consistency：零售索引28、30、31、29的重送小表；兩域主鍵去重、質量單位與合法重複事件。
- data-types-time-parsing：原始欄位型別、M01–M04單位、`parsing_fixture`的失敗與時區。
- outlier-detection：共用校準、兩域倍率比較、製造前12筆時序、`density_fixture`。
- outlier-treatment：八筆校準加索引10的錯誤碼；完整快照列數、有效原值與限界特徵比較。
- numpy-data-operations：同四筆數值的2×2陣列、同索引零售換景。
