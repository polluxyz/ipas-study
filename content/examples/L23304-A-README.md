# L23304-A 共用搜尋案例

`L23304-A-search.json` 是自編教學合成資料，不代表真實授信規則、製程或演算法效能排行。六頁共同使用它；模型優化流程的 0.99／0.74 與 180 MB 是另設的診斷情境，不是 SVC 搜尋結果。

## 資料與欄位

- `credit.rows`：240 位不同合成客戶，一人一筆。`income` 為月收入，單位千元；`debt_ratio` 為無單位負債比；`default` 為 0／1 違約標籤，1 是正類；`group_id` 是唯一客戶代碼。
- `manufacturing.rows`：240 個不同合成批次，一批一筆。`temperature` 單位 °C；`vibration` 單位 mm/s；`defect` 為 0／1 瑕疵標籤，1 是正類；`batch_id` 是唯一批次代碼。
- 模型只讀 `feature_columns` 指定的兩個數值特徵，不讀 ID、群組碼或標籤。實務上若同群多筆，必須改用群組驗證；此例因每群只有一筆，可用分層隨機分割。
- `development_indices`、`test_indices` 是 rows 的零起算索引。各 192／48 筆、互斥且合起來涵蓋 240 筆；測試標籤雖保留於教學檔，搜尋程式不讀它評分。
- `folds` 內的 train／validation 皆為 rows 的全域索引；頭兩摺為 153／39，後三摺 154／38。教材程式的 `cv` 則是 `X[dev]` 內的局部索引，兩者可由 dev 對照。

## 固定規則

資料以 make_classification 產生，授信種子 17、製造種子 29；其餘參數見教材程式。原始兩軸各經可逆的量尺轉換，再固定小數位，以保留可重現的工程單位。分割與五摺種子 42；每摺都用自己的訓練資料擬合 StandardScaler，再訓練 RBF SVC。

三策略共用 ROC AUC 評分、資料與索引；每個領域各用 20 組候選、每組五摺，共 100 次候選模型擬合。最終 refit 另計 1 次；本 JSON 不包含測試成績或最終重訓權重。

| 策略 | 空間與候選來源 |
|---|---|
| grid | C=[0.01,0.1,1,10]；γ=[0.001,0.01,0.1,1,10]，交叉列舉 20 組 |
| random | 同範圍對數均勻分布，ParameterSampler 種子 42，20 組 |
| bayesian | 同範圍內固定 150 點候選池（種子 123）；先試前 5 點，再選 15 點 |

`searches` 每筆的 `params` 是候選設定，`fold_scores` 是五個真實驗證 AUC，`mean` 是算術平均。`svc__C` 是誤差懲罰參數，`svc__gamma` 是 RBF 核的尺度參數，均為超參數。

貝氏例子採固定尺度 Matérn 高斯過程，對 AUC 減 0.5 後擬合；預測平均再加回 0.5。`optimizer=None`，不另調代理核超參數；`alpha=0.0001`，選點用 μ+σ（κ=1）。這是有限候選池的可重現教學配置，不主張代表所有貝氏實作。

`bayesian_pool` 保存完整候選池，`bayesian_chosen_pool_ids` 記錄 20 次選取順序；`bayesian_replay` 保存第 6～20 次實驗前的前三名代理輸出、選中 ID、先前最佳值與實際新評分。代理只使用該輪以前已評估的候選，不使用之後的結果。

## 關鍵數值與使用頁面

| 領域 | 網格最佳 | 隨機最佳 | 貝氏最佳 |
|---|---:|---:|---:|
| 授信 | 0.9203047091 | 0.9219113573 | 0.9223268698 |
| 製造 | 0.9124176670 | 0.9122499231 | 0.9161357341 |

- `optimization-workflow`：沿用資料角色；另外明列假設的診斷情境。
- `hyperparameter-tuning`：授信資料重建、資料角色、網格候選及 refit。
- `hyperparameter-search`：同預算三策略、雙領域結果比較。
- `grid-search`：4×5 組候選與 100／101 次擬合。五維 2700／2701 次是另設練習。
- `random-search`：相同資料與對數範圍，候選抽樣種子與預算。
- `bayesian-optimization`：製造第 6 次選點的代理快照、真實評分回饋與授信候選圖。

數據 SVG 均由 JSON 的候選參數算座標，使用 log₁₀ C／log₁₀ γ 軸。散點只表示選了哪些位置，不把位置覆蓋解讀為品質保證。
