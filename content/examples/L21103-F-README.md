# L21103-F 語音共用例子

資料檔：`L21103-F-speech.json`。有聲教材 E01–E10、客服 C01–C10 各 10 段，全部為作者自編文字與模擬數字，沒有真實聲音、真人評分或效能測量。

- `reference_tokens` 是已斷詞的參考文字；序數詞「第一」「第二」各算一詞，後面的「章」「堂」另計。`asr_tokens` 是假設「TTS 輸出再經固定 ASR」的轉寫，並非模型實際輸出。
- `alignment` 為動態規劃最少編輯對齊的 S 替換、D 刪除、I 插入與 N 參考詞數；同分優先次序記在 JSON。
- `tts` 記模型、語者、預期語者、語速、情緒與種子；語者 B 是故意放入的設定不一致。
- `mos_simulated` 為五個虛構的 1–5 整數評分，示範平均算法。`timing_simulated` 的時間戳以毫秒計，起點為送出合成請求。
- `source` 記作者自編稿本、虛構語者、模擬同意編號、用途及能否發布；SIM 編號不能當成法律文件或真實授權。
- 每領域 01–06 調設定、07–08 驗證、選定方案後才用 09–10 檢查，避免只適合看過的稿本。可設定種子的模型或服務固定為 42，不可設定時記錄版本與日期；不為挑較好結果重切資料，沒有實際訓練流程。

關鍵值：E01 N=10、S=1、D=1、I=1，WER=30%，MOS=4.0，首段延遲 260 ms、完成延遲 1200 ms；C01 N=10、S=2、D=0、I=0，WER=20%，MOS=4.0，首段延遲 180 ms、完成延遲 800 ms。邊界反例參考 1 詞、假設輸出 3 詞，可有 2 次插入，WER=200%；空參考的手算式不定義。

使用頁：`text-to-speech` 追蹤 E01／E08／C01；`voice-generation-workflow` 盤點全組、詳走 E01／C01；`speech-quality-metrics` 核算 E01／C01 及全組；`synthetic-content-authenticity` 使用 E09／C09 來源與回撥、E10／C10 發布限制。

修正後 E09 參考與轉寫均為「第二 章 現在 開始」，N=4、WER=0%。全組仍有 12 次最少編輯，參考詞總數改為 102，合併 WER 約 11.76%；逐句等權平均為 10.5%，兩者的權重不同。
