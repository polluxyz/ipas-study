# L23202-E：平行整合與逐輪提升

所有資料均為教學合成，不是房市行情、授信規則或模型效能基準。使用於Bagging策略、Boosting策略、隨機森林、梯度提升與XGBoost、XGBoost、LightGBM六頁。

## 共用固定規則

- `L23202-E-housing.json`與`L23202-E-credit.json`各100筆，`index`為0–99。種子23202固定給所有估計器。
- `index % 5`為0、1、2的60筆作訓練，餘3的20筆作驗證，餘4的20筆保留最終測試。模型不使用保留測試集調參或評估此處小表。
- `feature_order`對應`rows[].features`與`rows[].missing_features`的欄序。後者僅特徵含缺值，目標不變。
- 缺值版在索引為13倍數者的第二欄、17倍數者的第一欄放入`null`，包含索引0；Python轉換成`NaN`。完整與缺值版本分別訓練。
- 所有模型單執行緒，三樹／三輪、最大深度2；XGBoost與LightGBM學習率0.5。完整參數與版本在JSON的`models.*.parameters`與`versions`，不是主張相同超參數等於相同容量。
- XGBoost的`missing`省略時沿用API預設`NaN`；參數紀錄不寫入非標準JSON常數，資料列的缺值仍保存為`null`。

## 欄位與產生方式

以下的`i`均指0起算索引。這些公式也是各頁可獨立執行程式所使用的資料定義。

### 房價

- `area`：面積，10 + (i × 7) % 51，單位為教學坪數。
- `age`：屋齡，5 + (i × 3) % 21，單位年。
- `region`：區域編碼，floor(i / 10) % 3，僅是簡化的教學數值編碼，不推論真實區域大小順序。
- `target`：價格點，3 × area − age + 20 × region + 25 × [area > 35] + ((i × 5) % 9 − 4)。不是實際貨幣。
- `bagging`：三棵深度2決策樹的Bagging實測；抽樣位置對應60筆訓練陣列內位置，非原始索引。

### 授信

- `income`：收入點，30 + (i × 11) % 91，非實際貨幣。
- `debt_ratio`：負債比，((i × 7) % 61) / 100。
- `age`：年齡，22 + (i × 3) % 40。
- `target`：若（負債比 > 0.35且收入 < 90）或收入 < 45則為1，否則0。1為教學違約標籤，非真實授信決策。
- `models.*.first3`：驗證索引3、8、13的正類機率；房價檔同欄是價格點預測。先依任務辨認單位。

## 四筆微型例與前置教材

`L23202-E-steps.json`另列四筆微型資料：面積20、25、40、45，價格100、120、180、200。它不是上述100筆資料的子集，不混作驗證成績。

- 迴歸起點150，學習率0.5，兩輪深度1樹的修正依序為（−40、−40、40、40）與（−20、−20、20、20），預測依序130、130、170、170與120、120、180、180。
- 訓練內MSE為1700 → 500 → 200。
- 分類標籤0、0、1、1，起始分數0，固定步幅示例更新為−0.5、−0.5、0.5、0.5，平均Logloss為0.693147 → 0.474077。它不是宣稱任何套件的第一輪最佳葉值。
- XGBoost微型葉：梯度−2、−1，Hessian各1，L2係數1，葉值1。兩葉值±1、γ=0.2、λ=1時，複雜度1.4。
- 生長圖的四葉拓樸是示意，不是100筆資料實測的樹。

前置組`L23202-A-housing.json`有80筆，與本組要求的100筆不混用。只沿用其`demonstrations`內「100、110、120平均110」和「高價、高價、一般」硬投票的示意數值；授信換成違約、違約、正常的類別對應。前置組D的多類投票檔未用來擬合此處二元授信。
