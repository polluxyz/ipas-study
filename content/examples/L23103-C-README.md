# L23103-C 取樣與更新：共用教學資料

本組五頁共用同一份更新設定。資料全為合成，數字不是實證成效；不沿用前置組六筆迴歸的損失，也不宣稱本組與前置組是同一次訓練。

- `L23103-C-energy.json`：128 筆能源預測。`id` 是固定索引；`x` 是兩個無單位的轉換後特徵；`target` 是中心化、標準尺度的用量指標，因此允許負值。模型為兩參數線性預測，無偏差，每筆損失為平方殘差的一半。
- `L23103-C-text.json`：128 筆文字分類。`x` 兩欄依序是常見詞、少見詞的出現指標，分別每 4、16 筆出現；`label=1` 表示目標意圖。模型為無偏差的邏輯迴歸，以二元交叉熵訓練。
- 兩檔都以索引 0–95 訓練、96–111 驗證、112–127 測試，種子 23103 決定第一輪固定洗牌；`epoch1_batches` 共六批，每批 16 筆。不把留出資料用於更新。
- `L23103-C-updates.json`：`initial=[1,-1]`、`lr=0.1`、`epsilon=1e-8`，`replay` 是指定梯度 [3,4]、[−1,2]。五種方法皆重播同序列；後續梯度不依新參數重算，因此只驗算更新器。
- 能源第 0、1 筆在同一初值，真梯度恰為 [3,4]、[−1,2]，平均為 [1,3]；這不代表循序更新後梯度仍不變。文字資料不宣稱會產生同一梯度序列。
- `sparse_replay` 把第一步第二座標設零，供 Adagrad 展示兩步稀疏累積；`scale_replay` 在共同兩步後接十步 [0.2,0.2]，供 Adagrad／RMSprop 比較歷史記憶。
- `valley` 是獨立幾何例子：J(a,b)=0.1a²+2b²，初值 [1,−1]、學習率 0.4、動量 0.5，共 14 步。軌跡使用各方法在當前位置重新計算的真梯度，不是重播資料，也不是能源／文字模型成效。

關鍵核對數值：

| 方法 | 第 1 步參數 | 第 2 步參數 |
|---|---|---|
| SGD | [0.7,−1.4] | [0.8,−1.6] |
| 動量法 | [0.7,−1.4] | [0.53,−1.96] |
| Adagrad | [0.9,−1.1] | [0.9316,−1.1447] |
| RMSprop | [0.6838,−1.3162] | [0.7886,−1.4637] |
| Adam | [0.9,−1.1] | [0.8600,−1.1932] |

五頁皆使用 `updates` 的主序列及兩領域換景；SGD 另比較能源同參數點的平均梯度，動量頁使用 `valley`，Adagrad／RMSprop 使用稀疏與尺度序列。所有公式群維持 pending，等非作者審查。
