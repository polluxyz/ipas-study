# W-L23101-C 共用例子

`L23101-C-energy-service.json` 是教學合成資料，含能源48期與客服48期的並列表；同一期別只是共用索引，不代表兩個領域有因果關係。沒有沿用前置組 A 的觀測數字，也沒有修改或複製前置組檔案。

| 欄位 | 意義 | 固定規則 |
|---|---|---|
| period_id、split | P01–P48；訓練／留出 | P01–P36為train，後12期holdout |
| temperature_c、hvac_kwh | 溫度、空調用量 | 溫度14.5–25.5重複4輪；空調為溫差平方的U形 |
| energy_kwh、meter_wh | 用量與同量不同單位 | 基本線性用量加輪次偏移；P48改為210；Wh為1000倍 |
| wait_min | 客服等待分鐘 | 固定12值重複4輪；P48改為90 |
| hand_examples | 中心、變異、期望、形狀、相關小例 | 用於逐步計算，不假裝是隨機抽樣實測 |

統計摘要與探索圖描述全部48期；相關矩陣的篩選示範只用train，圖中48期相關則明確標示為全資料探索。沒有使用holdout挑選模型，沒有訓練成績。

模擬用種子231013，每次重新建立NumPy Generator。能源／客服模擬從48列有放回等機率抽取，保留同列配對；骰子另建同種子Generator，抽1到6（`integers`上界7不包含）。全部比較使用同一亂數前綴，並不對每個樣本數重新抽樣。

關鍵數值：能源平均101.833333、母體式標準差20.767897；客服平均7.916667、中位4、標準差13.771700。客服偏態4.634906、超額峰度23.721142；對數後0.898369、1.223291。

能源與Wh的相關為1；溫度與用量的全48期相關0.805531；溫度與U形空調量相關約0。能源超過120 kWh有3/48期，等待超過10分鐘有8/48期。

以前36期能源用量為目標，溫度與空調量對目標的相關分別約0.993與0；只供線性候選排序。Wh是能源目標的換單位複本，不得作為該任務的輸入；能源／Wh相關矩陣僅供欄位重複盤點。

種子231013抽10000期：能源事件622、等待事件1684、超額用電損失平均4.1292元。骰子條件大於3有4982次，同時為偶數有3377次，條件率0.677840；解析值2/3。

四頁都使用本例：`descriptive-statistics`、`distribution-shape`、`pearson-correlation`、`monte-carlo-method`。圖資由工作檔 `tmp/rollout/groups/W-L23101-C/figure-scripts/build_examples.py` 從JSON同源資料計算，產出自足SVG；另有唯讀重建腳本 `render_from_json.py` 直接讀JSON重畫供核查。

數值完整核算與程式實測報告放在同組工作資料夾；版本固定後仍須非作者 reviewer 審查公式。
