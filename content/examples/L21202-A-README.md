# L21202-A 共用例子

`L21202-A-projects.json` 是製造地端檢測、零售推薦兩案的教學合成資料。與前置組的客服、預測維護案例是不同專案，沒有沿用或更改前置組現金流。

## 固定規則

- 兩案各六個任務、六個核心職務席位。UXB 席位兼任設計師與業務顧問，兩項責任分開；主管、法務資安及業務審查者不算核心開發席位。
- `tasks` 的 `lead/approve/consult` 為共同責任矩陣；`output` 是交付物，`hours` 為全任務合計人時，單價固定每人時 1,000 元。
- `weeks` 是含起訖週的工作窗口，不可用總人時直接推算完工週；任務可並行，單價也不代表真實薪資。
- 任務預算等於人力、硬軟體、外部合作三類加總；硬軟體包含試辦資源，不再重複計入。指引將來源列為自有、補助、外包；本例記帳另將外包支出與支付款項分開核對。
- `budget_items` 是同一預算的採購明細，與任務分攤總額核對，不能再與任務額相加。製造借用既有 GPU，新增購租費為零；零售 500 節點時為試辦窗口總量，兩節點同時運作可用 250 小時，不是八週全天服務。
- 資料索引、版本、切分與種子 42 固定。製造按批次隔離、零售按時間排序是教學分配假設；JSON 未提供逐筆批次或事件時間，腳本只能驗證索引互斥與完整，不能實證分組或時間條件。同案比較不得重抽測試集。
- `prototype` 是獨立的假設驗收計數，未宣稱用 JSON 資料訓練出模型。製造測試集 200 筆中正類 100 筆；零售留出 100 次請求。
- `training/inference` 分開記錄記憶體配置，單位 GiB。分項為互不重複的預算額度，並非只靠權重大小預測實際峰值。
- `stage_budget_ms` 是同一串行路徑分段預算，不是各段 p95；相加不等於量測端到端 p95。`tested_node_rps` 是假設在指定工作程序數與延遲條件下得到的單節點壓測能力。
- 節點數為尖峰流量除以單節點能力乘目標負載比例後向上取整，未涵蓋節點故障冗餘。四類審查有責任人、期限、進場條件及未結狀態。
- `testing` 是功能 20 例、異常 10 例、壓測 15 分鐘及錯誤率不超過 1% 的計畫門檻；只有教學假設，沒有執行線上壓測。

## 關鍵參考數值

| 項目 | 製造 | 零售 |
|---|---|---|
| 人時與人力費 | 216；216,000 元 | 176；176,000 元 |
| 硬軟體與合作費 | 48,000；16,000 元 | 30,000；12,000 元 |
| 八週總額 | 280,000 元 | 218,000 元 |
| 訓練／推論記憶體 | 12／4 GiB | 8／4 GiB |
| 延遲預算／上限 | 45／50 ms | 100／120 ms |
| 容量所需節點 | 2 | 2 |

製造品質：覆核 960/1,000=96%，模型假設召回率 95/100=95%。零售覆核 490/500=98%，模型假設前五名命中率 70/100=70%，基準 65%。這些不代表可省下多少現金。

製造變更情境：增加資料工時 16 與硬軟體 6,000 元，需追加 22,000 元，總額 302,000 元，延至第 10 週；零售變更追加 11,000 元，總額 229,000 元，延至第 9 週。

## 預算分攤對照

以下為同一批採購費用在任務間的教學分攤，單位為新臺幣元。欄名對應 JSON 的 `budget_items.item`；每列合計對應該任務的 `hardware_software_twd`，未列任務此項為零。

| 製造任務 | 廠內推論節點租用 | 平台軟體授權 | 任務硬軟體小計 |
|---|---|---|---|
| M2 | 0 | 8,000 | 8,000 |
| M3 | 16,000 | 8,000 | 24,000 |
| M5 | 16,000 | 0 | 16,000 |

節點是租用後放在廠內的 CPU 設備，訓練用既有 GPU 不另收費。平台授權供資料及模型任務共用；節點費由模型任務的部署相容驗證與整合任務共同分攤。

| 零售任務 | CPU 雲端資源 | 平台軟體授權 | 任務硬軟體小計 |
|---|---|---|---|
| R2 | 4,000 | 2,000 | 6,000 |
| R3 | 12,000 | 6,000 | 18,000 |
| R5 | 4,000 | 2,000 | 6,000 |

零售將雲端及授權費依 20%、60%、20% 分給資料、模型與整合任務。外部合作另分攤製造 M2 標註 12,000、M6 獨立測試 4,000；零售 R2 標註 8,000、R6 獨立測試 4,000。

內部工時按各任務的 `hours` 乘 1,000 元，兩案分別對回「內部工作」216,000 與 176,000 元。分攤只供歸屬追溯，不能再次加到採購總額。

## 使用頁面

七頁皆使用本檔：`ai-implementation-plan`、`ai-project-roles`、`ai-delivery-roles`、`cross-functional-collaboration`、`compute-resource-planning`、`development-toolchain`、`planning-deliverables`。算力及預算頁的 Python 直接讀 JSON；其他頁依相同任務、版本及審查紀錄走流程。
