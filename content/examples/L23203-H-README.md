# L23203-H 共用例子

教學合成資料，種子 42。法律 L01–L08、農作病葉 A01–A08 各八組，並非真實契約或影像資料。重複文本刻意控制詞元條件，不能用來估計泛化成績。

- split：各領域索引 1–4 訓練、5–6 驗證、7–8 最終測試；所有比較固定索引與種子，不跨領域混訓。
- legal：tokens 為人工切分的八詞元；valid_mask 全為 1；mlm_positions 為零起算，位置 2 的原詞是標的；mlm_input 只替換該處。summary_tokens 為教學生成標的；class_label 為句級類別；ner_tags 為逐詞當事人標註。
- leaves：pixels 為 8×8×3 整數，patch_size=4，依左上、右上、左下、右下展平；patch_ids 為 0–3，patch_mask 全有效。class_label 為影像分類，patch_labels 為各區是否有病斑。embedding_dim=6。
- attention：長度 8、16；局部半徑 1（含自身），序列兩端不環繞；全域位置為 0，雙向連結，重複連結只算一次。
- multitask：initial_loss 是同一共享模型、同一時點的兩個平均損失，與各自單任務基準分開；validation 各兩個數值依序對應驗證索引 5、6，是固定驗證樣本的合成損失，非實際訓練輸出。較低較好，兩任務皆用相同的各自計算規則。

參考值：四個 patch，各 48 維，投影成四個 6 維向量；含分類詞元共五個。密集 8/16 長度為 64/256 配對，局部為 22/46，局部加全域為 34/74。等權初始損失 1.2，調權後 0.6，權重不同不得據此比較模型品質。另列單任務基準為分類 0.38、NER 0.75；共享等權為 0.30、1.00，調權為 0.35、0.70。

五頁都使用本檔：三家族與預訓練頁用法律序列；ViT 用農作影像並以法律文件轉為頁面影像換景；長序列共用八詞元/四 patch 計數規則；多任務用法律分類/NER、病葉分類/區塊病斑兩種支路。
