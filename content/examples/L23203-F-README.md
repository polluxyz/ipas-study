# L23203-F 共用序列

`L23203-F-sequences.json` 是能源需求與醫療感測各 20 時點的教學合成資料，沒有真實個人資料。

- `energy.rows`：`t` 是索引，`day` 是日標籤，`temperature` 是示意背景欄，`demand` 為每日用電 kWh。程式僅用 `demand`，未把溫度放入模型。
- `medical.rows`：`timestamp` 是時點標籤，`heart_rate` 為每分鐘心跳數，`event` 是預先編定的教學事件標籤，不是醫療診斷。主例預測下一時點心率，未使用事件標籤。
- `available_at=t`：當下量測在時點 t 可取得。預測截止點為收齊 t 後，輸入 t−3～t，標籤在 t+1。
- `normalized`：能源用 `(demand−100)/100`，醫療用 `(heart_rate−60)/20`。這是事先指定的單位換算，不是全資料估計的平均與標準差。
- 兩領域刻意使用相同換算後軌跡；`first_windows` 依序放能源與醫療的首個四步視窗，形狀 `(2,4,1)`，值皆為 `[0,0.1,0.2,0.3]`。
- 目標時點 5～12 為訓練、13～16 為驗證、17～20 為測試，視窗長度固定為 4，種子固定 23。後段視窗可讀到之前已觀測的歷史，絕不讀目標時點或更晚量測。
- 各獨立視窗重設初始狀態。門控探針另給 t=4 的舊狀態，不冒充前三步訓練或推論所得的狀態。

| 探針 | 固定規則 | 關鍵參考數值 |
|---|---|---|
| RNN | 輸入權重 1、遞迴權重 0.5、無偏差、初始狀態 0 | 四步狀態由程式核算 |
| LSTM | 舊細胞狀態 0.5；門值 i=0.25、f=0.8、o=0.5；候選值 0.4 | 新細胞狀態 0.5、隱藏狀態約 0.2311；f 改 0.2 時分別 0.2、0.0987 |
| GRU | 舊狀態 0.5；r=0.5、z=0.8；候選輸入 0.3、遞迴權重 0.5 | 候選值 tanh(0.425)，新狀態約 0.4802 |
| 梯度 | 初始梯度 1，局部導數固定為 0.5 或 1.5，四次連乘 | 0.0625 與 5.0625 |
| 參數比較 | 單層、單向、輸入 1、隱藏寬度 2、無偏差、不含輸出頭 | RNN 6、GRU 18、LSTM 24 |

七頁 `rnn`、`recurrent-gradients`、`lstm`、`gru`、`bidirectional-rnn`、`stacked-rnn`、`sequence-models` 共用此檔。這些小樣本與未訓練模型只驗證資訊流、形狀及運算，不用來排名真實任務準確率或速度。
