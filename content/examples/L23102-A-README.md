# L23102-A 共用例子

本組七頁使用 `L23102-A-energy-credit.json`。全部是教學合成資料，權重手設，不是經驗模型或真實決策建議。

## 欄位與固定規則

- `domains.energy.X`：4 棟建物 × 3 特徵，順序固定為面積指數（每單位 100 平方公尺）、使用人數指數（每單位 10 人）、冷氣時數（小時）；輸出用電指數每單位 10 度。
- `domains.credit.X`：4 位申請人 × 3 特徵，順序為年收入（百萬元）、往來年數（年）、存款（百萬元）；輸出額度指數每單位 10 萬元。兩個輸出欄位只當候選分數，不是機率。
- `W1`、`W2`：兩組固定的 3×2 權重，列為特徵、欄為輸出；`b` 為兩個輸出的共用偏差 `(1,-1)`。
- `ids` 與矩陣列同序；`split` 使用零起算索引：訓練 `[0,1]`、驗證 `[2]`、測試 `[3]`。頁面沒有重新擬合模型；固定切分只供後續比較沿用，四筆不足以估計真實泛化表現。
- `seed=42`；資料與幾何都是固定宣告，無亂數採樣。涉及框架初始化的範例也固定種子。
- `geometry`：固定二維點集與四種矩陣，採欄向量 `A @ x`；若整批點每列一筆，使用 `X @ A.T`。`translation=(2,1)` 只用於幾何平移，不是預測層的 `b`。
- `vectors`：`u=(3,4)`、`v=(1,2)`；`actual=(4,6)`、`predicted=(1,2)` 是兩筆輸出組成的獨立殘差示例，並非宣稱它們由 `W1` 或 `W2` 產生。
- `embedding`：四類手設 4×2 表格；索引從 0 起，查詢順序 `[1,0,2,1]`。能源可視為設備型號，授信可視為申請管道，兩者只是換景，類別向量沒有預設真實語意。

## 可核對的結果

| 矩陣 | W1 加 b | W2 加 b |
|---|---|---|
| 能源 | `[[3,7],[5,0],[1,4],[3,1]]` | `[[6,0],[5,-2],[3,0],[8,-4]]` |
| 授信 | `[[4,0],[2,1],[4,3],[4,4]]` | `[[3,-1],[6,-3],[2,1],[9,-3]]` |

- 能源第一列與 `W1` 第一欄的內積為 2，逐項乘積 `[1,4,-3]`，餘弦 `2/√84≈0.218218`。
- 向量範數：`||u||₂=5`，平方範數 25；`u+v=(4,6)`、`u-v=(2,2)`、`u-0.5v=(2.5,3)`。
- 能源前兩筆乘 `W1`：`[[2,8],[4,1]]`；反向乘積為 3×3，不能視為同一運算。
- 奇異矩陣 `S=[[1,1],[2,2]]` 的偽逆為 `[[0.1,0.2],[0.1,0.2]]`，對目標 `[2,4]` 得最小範數解 `[1,1]`。
- 二維 `(1,1)` 依序經縮放、旋轉、剪切、投影：`(2,1)`、`(-1,1)`、`(2,1)`、`(1,0)`；縮放再加平移後為 `(4,2)`。
- 嵌入查表結果 `[[0,1],[1,0],[1,1],[0,1]]`，與 one-hot 乘表一致。

## 使用頁面

七頁依序為：向量表示與內積、向量範數與線性組合、矩陣形狀與維度對齊、矩陣乘法、轉置與偽逆、線性變換與幾何、仿射運算與線性預測、嵌入與低維表示。

前四頁以能源矩陣為主、授信換景；幾何頁使用固定二維點集；仿射頁比較兩組權重；嵌入頁將同一類別查表流程套到兩個領域。
