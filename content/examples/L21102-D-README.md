# L21102-D：從畫質與時間取樣到資料準備及熱區

`L21102-D-vision.json`是教學合成快照：零售、製造各12張靜態圖與各12個帶時間戳影格。不是實際照片或可作效能估計的資料集；4×4單通道刻意方便逐格核算。

承接D2影像前處理與D4原圖／熱圖並列的方向；沿用前置組`L23301-E-images.json`的來源先切分與不覆寫原圖慣例。本組沒有重用其像素與16張切分數字，避免把不同快照混算。

## 欄位與固定規則

- `index`是域內零起算索引；`sample_id`用RD或MD區分零售、製造，`group_id`保存同來源關係。
- `pixel_array[y][x]`是0–255灰階；`width=height=4`、`channels=1`。CNN批次可表示為N×1×4×4，不用RGB三通道假冒灰階。
- `class_label`保留原始標籤，`reviewed_label`是審查後標籤。兩域分別有正常／封口異常、正常／表面異常，索引相同不表示語意相同。
- `quality`含教學用`blur_score`、低光源、孤立亮點旗標；分數為人工合成的品質欄位，不是執行模糊偵測器的結果。
- `duplicate_of`指出索引11完全重複索引0。索引10過度模糊、排除；索引9標錯、修正。排除項保留在快照，方便核對清理計數。
- 靜態圖固定切分：訓練0、1、2、3、6、7；驗證4、8；測試5、9；其餘excluded。兩域使用相同清單。
- `fixed_region=[xmin,ymin,xmax,ymax]`右／下不含。製造在右下2×2、零售在左上2×2；是圖形結構的固定區域，不是Grad-CAM真值或所有類別的瑕疵遮罩。
- 每域一段示意影片，影格時間0–1100ms，每100ms一格；事件區間[450,650)，500、600ms有事件。全部影片影格屬train示範來源，不參與靜態圖的驗證或測試。
- 種子21102；沒有依亂數重切。本例明訂清單，固定種子只是同組後續若引入亂數時的契約，不能取代來源與版本。

## 關鍵參考數值

- 每域原12張標籤數9／3；移除兩張正常問題圖後7／3，修正一張錯標後6／4，共10張。
- 每域訓練4／2、驗證1／1、測試1／1；兩域合計12訓練、4驗證、4測試。整數限制使各集比例不完全相同，分層不代表類別平衡。
- MD01背景16、右下四格64，位置(1,1)亮點255。3×3中值採edge補邊，去亮點後是背景16、右下64。
- Gamma採`255*(x/255)**0.5`，16→63.87487769，64→127.74975538；畫圖才取整為64、128。
- 原圖亮點鄰域：七個16、一個64、一個255；平均431/9≈47.88889，中值16。
- 原圖均衡化採扣除最小非零CDF的版本：16→0、64→204、255→255；常數圖保持原值。
- 400ms時間取樣保留0、400、800，事件0格；200ms保留0、200、400、600、800、1000，事件1格，只有2種不同像素。
- 均勻索引含首末、向下取整：4格為0、3、7、11；6格為0、2、4、6、8、11。
- 固定小卷積2×2、步幅2、四權重0.25、無偏置；目標為四個特徵的平均亮度分數，另一分數可取其負。**模型未訓練，不是實際瑕疵分類器。**
- 經中值、Gamma、除255後，特徵前三格約0.25049、右下0.50098；對目標的四梯度皆0.25；相對熱度為0.5、0.5、0.5、1。
- 原圖特徵左上75.75/255、右下64/255，相對熱度約[[1,0.21122],[0.21122,0.84488]]。亮點使最熱區偏到左上。

## 使用頁面與重建

四頁：image-enhancement、video-frame-sampling、image-dataset-preparation、grad-cam。

資料生成：`node tmp/rollout/groups/W-L21102-D/figure-scripts/build-examples.mjs`。

圖重建：`node tmp/rollout/groups/W-L21102-D/figure-scripts/build-figures.mjs`。其中數據SVG全部從快照計算，沒有手填結果。圖ID與獨立核算見`tmp/rollout/groups/W-L21102-D/examples-check.md`。

圖與頁面的PyTorch熱度由兩套計算核對：SVG使用JavaScript解析式，頁面用PyTorch自動微分。所有Python輸出另經run-code實測。
