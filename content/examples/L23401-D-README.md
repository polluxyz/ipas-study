# L23401-D 分散運算共用例子

`L23401-D-distributed.json` 是教學合成資料，不含真實病人、交易、可用金鑰或密文。跨院與跨銀行各 24 列，分甲乙丙三方，各 8 列；兩領域刻意使用同一組數字，以便比較技術責任。

## 欄位與固定規則

- `record_id`：H01–H24 或 B01–B24，兩領域各自唯一；`site`：A、B、C。
- `local_index`：每方 0–7；前 6 列為 `train`，後 2 列為 `validation`。沒有最終測試集，不用這個例子聲稱泛化效果。
- `x`：自編、無單位的風險特徵，依索引輪流取 1、2；`y`：0／1，跨院為疾病標記，銀行為風險事件標記。
- `seed=23401`：全組固定重現識別；資料與切分採明定順序，沒有抽樣。學習率 0.4、初始權重 0。
- `messages`：`sender`、`receiver`、`payload`、`key_owner`、`nonce`、`round` 是訊息契約。`payload` 為工件標籤，`Enc(...)` 是符號，不是生成的密文；`key_owner` 為設計角色，不含金鑰。
- `signature_evidence`：待簽清單含訊息欄位、資料與模型版本、更新工件摘要，另附清單 SHA-256、金鑰 ID 及簽章工件代號。`update_artifact` 保留可重算摘要的輸出內容；版本 `teaching-v0` 對應本檔固定資料。
- 簽章狀態 `illustrative_not_generated` 與驗簽狀態 `not_executed` 不可解讀成驗簽通過。摘要使用 UTF-8 JSON、原欄位順序及無額外空格的編碼，未進行公鑰認證。

## 關鍵參考數值

每領域甲乙丙全體正類數為 4、5、6，總數 15／24。訓練列各 6 筆，正類數 3、4、5，總數 12／18。同態與 MPC 總和用全體 24 列，聯邦更新只用 18 筆訓練列，兩者的分母不可混用。

無截距單特徵 logistic 模型在權重 0 時，各列預測皆為 0.5。每方一步梯度為 −1／12、−1／4、−7／12；本地權重為 1／30、1／10、7／30。按各方 6 筆加權的新權重為 11／90，約 0.122222。

## 使用頁面

- 聯邦學習：本地資料分割、一步更新、中央聚合與訊息邊界。
- 同態加密：4、5、6 三個計數的符號密文加法；不實作加密。
- 安全通訊：同一訊息契約的 HMAC 與重放拒絕分支；不實作 TLS。
- 安全多方計算：相同三個輸入與總和，說明多方信任模型；不實作協議。
- 不可否認性與簽章稽核：沿用更新訊息的輸入、輸出與簽署者欄位；不虛構驗簽結果。

生成工具與獨立核算放在 `tmp/rollout/groups/W-L23401-D/`，沒有修改其他組例子。
