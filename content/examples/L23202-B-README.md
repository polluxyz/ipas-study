# L23202-B：任務、分類模型與樹切分

這是一組教學合成資料，不能用來訂定實際授信或工業安全標準。金融、製造各90筆，列索引皆為0–89；金融ID為F000–F089，製造為M000–M089。

## 檔案與固定規則

- `L23202-B-finance.json`：月收入、負債、支出、借款餘額四欄，單位皆為千元。收入與支出相關，負債與借款餘額相關，供討論重複資訊與係數解釋。
- `L23202-B-manufacturing.json`：壓力kPa、振動mm/s、溫度°C、備援壓力kPa。振動與溫度相關，兩個壓力欄相關。
- `L23202-B-classification.json`：種子42、共用切分索引、六筆手算節點、兩個候選切分、KNN查詢、指定邏輯迴歸係數、指定SVM支持點。
- `L23202-B-model-results.json`：scikit-learn實測版本、二元／三類任務的訓練與驗證類別筆數、五模型驗證預測，並留六筆的機率／決策分數供後續投票教材使用。機率欄依類別代碼0、1、2遞增排列，SVC二元決策分數正向為1類；測試集未評估。

令`a=i%9`、`b=i//9`，固定工程座標為`[a,b]`。金融收入為`20+10a`、負債為`100b`；製造壓力為`80+2a`、振動為`0.5+0.5b`。這些換算是已知單位規則，不是用全資料估計的標準化；模型比較另以StandardScaler只擬合訓練集。

金融的四欄刻意用規則格點產生，其中收入／支出、負債／借款餘額兩組各自近乎共線，方便對照係數與重複資訊；不是所有欄位兩兩都近乎共線。真實資料通常不會這麼規則。

金融風險分數`r=b-a-1`：二元標籤為`r>=0`；三類標籤依`r<-1`、`-1<=r<2`、`r>=2`分低／中／高風險。二元版與三類版是不同的教學目標定義，不把三類編碼當成二元違約機率。

製造三類：`b>=7`為振動異常；否則`a<=2`為壓力異常；其餘正常。若同時符合兩個異常條件，固定優先標振動異常。二元版合併兩種異常為瑕疵。

## 切分與模型

手算六筆索引`10,28,11,38,12,48`先放訓練集。其餘84個索引用`np.random.default_rng(42).permutation`排列，前48個加入訓練，接18個驗證，最後18個測試，因此兩領域均為54／18／18。這是教學固定切分，不是分層抽樣；實務另檢查時間、群組與類別比例。

五模型皆用四個原始特徵：LogisticRegression（max_iter=1000）、RBF SVC（C=1、gamma=0.5）、DecisionTreeClassifier（max_depth=3、min_samples_leaf=3）、KNeighborsClassifier（K=5）、GaussianNB。除樹外均放StandardScaler之後；可調參方法不可用測試集挑選。

分類樹路徑圖另外用criterion=entropy、max_depth=2、min_samples_leaf=3，同54筆訓練集。它的驗證答對13／18，與比較表的深度3、Gini樹不是同一設定。

## 可核對數值

六筆依ID列出：F010(1,1,0)、F028(1,3,1)、F011(2,1,0)、F038(2,4,1)、F012(3,1,0)、F048(3,5,1)，括號為收入座標、負債座標、二元標籤。

- 父節點：3負、3正，熵1 bit、Gini 0.5。
- 負債≤350：左3負1正、右0負2正；加權子熵0.540852083、資訊增益0.459147917；加權Gini 0.25、Gini下降0.25。
- 收入≤35：左1負1正、右2負2正；加權子熵1、增益0；加權Gini 0.5、下降0。
- KNN查詢座標(2.45,2.75)，換回金融原值為收入44.5千元、負債275千元；座標距離最近依序F038、F028、F011、F012、F010、F048，K=1、3判違約，K=5判未違約。
- 指定邏輯迴歸分數`z=-1-x1+x2`；z=-2、0、1時機率約0.119203、0.5、0.731059。係數用於手算，並非四特徵模型擬合值。
- 指定線性SVM權重(-1,1)、截距-1；F020(2,2)與F028(1,3)分數為-1、1，兩個alpha皆為1，兩條間隔邊線總寬2/√2。這是支持向量幾何教學，不是宣稱它們是完整54筆擬合後唯一的支持向量。

## 使用頁面

- algorithm-selection、classification-model-selection：兩領域的目標定義、固定切分及五模型比較。
- logistic-regression：金融座標、指定分數、二元與三類擬合。
- support-vector-machine：同金融資料與C／gamma比較、製造的非線性目標。
- classification-tree：金融54筆的小樹、葉節點與路徑。
- tree-impurity、information-gain：同六筆、同兩個候選切分。
- knn：同六筆的距離與K變化，製造作換景。
