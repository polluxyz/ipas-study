# L23203-G 注意力組共用資料

`L23203-G-attention.json` 為教學合成資料，客服、醫療各六句，每句配置四個詞元位置，沒有訓練模型或臨床效力。

- `vocabulary`：詞元 ID 對照，0 為填補、1 為起始、2 為結束。`embedding` 的列索引與詞元 ID 相同，每列固定二維。
- `service`、`medical`：各六筆，`token_id` 是四格索引，`position` 從 0 起算，`valid_mask=true` 表示有效詞元，`label` 是整句標籤；`tokens` 供人閱讀。
- `seed=23` 與 `split`：兩領域皆固定列索引 0–3 訓練、4 驗證、5 測試。所有矩陣人工指定，沒有隨機抽樣；不以十二句宣稱泛化效能。
- `probe`：S01 的原位置 0、3，取出「客戶／退款」，嵌入為二階單位矩陣；醫療 M01 位置 0、2 的「病人／疼痛」也有同組玩具向量。
- `Wq`、`Wk`、`Wv`：固定二維單位投影，刻意相同以便手算；真實模型的三組參數可各自學習。`heads=2` 時，每頭取一個投影欄。
- `Wo`：多頭拼接後的輸出投影；不可省略後聲稱最終輸出不變。
- `ffn`：兩層權重與偏置，寬度 2→3→2，兩位置共享同一組參數。
- `norm`：獨立的兩筆兩維軸向探針；與詞嵌入無關，使用分母為特徵數的變異，epsilon 為 0.00001。
- `decoder`：右移輸入與對應標籤，各四格；`lengths` 為四格與八格成本比較。

| 單頭因果遮罩首列 | 權重及輸出（1，0） |
| 兩頭首列拼接／輸出投影 | （0.731059，0.5）／（1.231059，0.231059） |

| FFN 兩列輸出 | （1，0）、（1，2） |
| LN 兩列輸出 | 均約（−0.999995，0.999995） |

`norm` 的二維當批 BN 對照：欄平均（3，5）、欄變異（4，4），首列約（−0.999999，−0.999999）。前置組四筆 BN 的數字只引用其頁面及資料檔，沒有複製前置組檔案。

指代探針保留完整 S01：位置 2「他」對四個鍵「客戶／提交／他／退款」的權重約為（0.334881，0.165119，0.334881，0.165119）。這不是二詞元探針的子矩陣；Softmax 的分母改為四個鍵，需重新計算。

本組七頁全部使用此資料。Transformer 頁用四格、八格及雙領域情境；編解碼頁用右移目標與有效遮罩；單頭、多頭、位置、FFN 頁共用 probe；LayerNorm 頁用 norm 探針。位置頁取出二詞元後重編位置為 0、1，其他三個算例保留來源索引 0、3 作為標籤，不藉此注入位置向量。

編解碼頁的程式另取 S02 作為目標端遮罩測試序列，合併目標自身的有效鍵與因果條件；它不是 S01 的來源遮罩，也不是 decoder 欄位中無填補的右移輸入。
