# L23304-E：壓縮與精度共用例子

所有值是教學合成資料，不代表真實模型訓練、法律摘要品質或裝置效能。

- `vision`：60 筆三類行動影像，`image_id`、`class_id` 與教師／學生三維 logits；類別輪流為 0、1、2。每第 17 筆教師、每第 11 筆學生交換前兩類分數，保留教師會錯的反例。
- `legal`：60 筆法律摘要教學卡，`doc_id`、輸入 token 數、教師／學生品質分數（0–100 人工評分的假設值）與單篇延遲毫秒。摘要不使用影像的準確率；未提供原文、生成摘要或可訓練語料。
- `seed=23203` 沿用前置組；索引 0–35 訓練、36–47 驗證、48–59 測試。影像各區三類均衡；校準資料僅用訓練索引 0–11。任何策略都不重切。
- `teacher_layers` 沿用 `L23203-C-frameworks.json` 的 `dense_layers`（4→5→3，43 參數）；本組把它視為四維影像特徵的教學分類頭。沒有宣稱它是完整影像或摘要模型。
- `student_layers` 為 4→2→3，19 參數；`pruned_layers` 為同教師移除兩個隱藏單元及下一層對應欄後的 4→3→3，27 參數。層表只計權重、偏置；不包含特徵擷取器。
- `network` 是剪枝示範的固定非零張量；W1 20、b1 5、W2 15、b2 3 個值。非結構化只把 W1 最小的 8 個權重置零，密集儲存仍有 43 個位置；結構化保留隱藏索引 0、1、2。
- `distillation` 指定影像索引 0、溫度 2、硬標籤權重 0.5。教師 logits=[4,2,0]、學生=[2,1,0]；三類機率須由 softmax 重算，KL 方向為教師對學生，使用自然對數。
- `quantization` 採對稱教學格點 [-127,127]、scale=1/127、zero_point=0；不使用 INT8 的 -128 格。探針 1.5 用來展示超出校準範圍的飽和誤差，不能只看四捨五入誤差。
- `amp`：120 個激活元素只用來估儲存量；梯度 1e-8、縮放 1024 用來示範 FP16 下溢。CPU GradScaler 示範時序，不作 GPU 加速結論。
- `latency_cards` 是明定的假設卡，前提為同裝置、batch=1、固定輸入、暖機與同步計時。任何頁面使用時都必須標「假設」，不能說是本機實測。

關鍵值：43 個 FP32 參數 172 bytes；19 個為 76 bytes；結構化後 108 bytes；35 個權重 INT8 加 8 個 FP32 偏置為 67 bytes（未含尺度等 metadata）。FP32 激活 480 bytes、FP16 240 bytes；43 個 FP32 權重與梯度合計 344 bytes。

使用頁面：`knowledge-distillation`、`model-pruning`、`quantization`、`mixed-precision-training`。獨立重算記錄與建立程式在 `tmp/rollout/groups/W-L23304-E/`，不列入正式內容資料。
