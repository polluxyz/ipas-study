# L21103-D 共用例子

`L21103-D-customization.json` 是教學合成資料，包含客服問答與醫療摘要各 20 筆。沒有呼叫生成模型，也沒有使用真人或病歷資料；醫療僅整理文字，不提供治療判斷。

- `records`：`id` 是固定索引，`domain` 是領域，`task`、`instruction`、`input`、`ideal_answer` 是 SFT 示範欄位；`label` 用於零／少樣本分類。
- `preference`：同輸入的 `chosen`、`rejected` 及其排序，1 優於 2。`preference_basis` 是合成偏好依據，不是模型獎勵分數。
- 各領域 01–12 訓練、13–16 驗證、17–20 最終測試；示例只選訓練資料。提示比較用 S13、S14、M13、M14，不用測試資料調提示。固定種子 42；本資料建立不含亂數。
- 訓練、驗證、測試的句型刻意相近，主要示範索引切分與資料用途，不能用這份小資料證明對新句型或真實業務的泛化能力；正式驗收須另備具代表性的未見資料。
- `prompt_trials`：v0、v1 的提示與人工編排候選，以及格式、內容、可靠性布林驗收。它是失敗後迭代的教材紀錄，不是提示效果實測。不得解讀成模型通過率。
- `budget`：所有比較共享 8×6 的基底矩陣，兩個相同尺寸的教學層、每層一個目標矩陣；不代表完整語言模型。`A` 為 2×6、`B` 為 8×2，`alpha/r=1`；`x` 是六維欄向量。
- LoRA 每層 28 個可訓練參數，兩層 56；只計兩個基底矩陣的完整微調為 96。rank 4 套一層也是 56，不能由參數相同推得品質相同。
- 軟提示 P 為 4×6，共 24 個可訓練值；float32 僅提示權重為 96 bytes，不含基底、梯度、優化器狀態、啟用值或快取。
- 五頁全部引用本資料；`prompt-engineering` 使用提示紀錄，SFT 與對齊頁使用示範及偏好，`prompt-tuning`、`lora` 使用預算卡。

重建資料：在本 worktree 根目錄執行 `node tmp/rollout/groups/W-L21103-D/create-examples.cjs`。該腳本為交付報告附件；正式資料已存於本目錄。
