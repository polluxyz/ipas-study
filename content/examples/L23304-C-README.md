# L23304-C：正則化與 Dropout 共用例子

`L23304-C-penalties-dropout.json` 全為教學合成資料，不代表任何真實房價、客服結果或方法優劣。各頁用相同樣本、切分與尺度，避免比較時混入資料差異。

## 欄位與固定規則

- `seed`：資料生成種子 23304，使用 NumPy `default_rng`。
- `domains.housing.rows`：120 筆房價例子。`area`、`total_area`、`age` 分別代表面積、總面積、屋齡；`target` 是中心化房價的教學單位，1 單位代表 100 萬元。
- `domains.customer.rows`：120 筆客服例子。`feature_1`、`feature_2` 是高度相關的文字表示，`context` 是第三項情境表示；`target` 是合成的連續情緒強度，不是機率或分類標籤。
- 每列的 `id` 就是零起算索引，兩領域各自從 0 到 119。兩領域使用相同的索引切分，不把兩種任務的誤差混在一起排名。
- `split`：訓練 72、驗證 24、測試 24 筆，無重疊且合起來涵蓋全部 120 個索引。測試標籤未用來調參或繪製強度比較圖。
- `feature_mean_train`、`feature_scale_train`：僅用原訓練集估計的平均與母體標準差。標準化後的權重才是本組比較用的座標。
- `weights=[2,-1,0.5]`：共同的固定檢查點，截距為 0。資料損失定義為平方誤差總和除以訓練筆數的兩倍，即 MSE 的一半。
- 合成目標由「標準化特徵乘固定權重」加上雜訊得到；雜訊在訓練索引上平均為零，均方為 1.6，所以固定檢查點的資料損失為 0.8。這個檢查點不等於經懲罰最佳化後的係數。
- `lambda=0.2`：純 L1、純 L2 的檢查係數。混合項用 `lambda1=0.12`、`lambda2=0.08`，均不另加二分之一。
- `lambda_grid=[0.02,0.2,2]`：在完全相同訓練集重新擬合三種強度。資料圖採 Lasso，縱軸另用完整 MSE。
- `bootstrap_seeds` 與 `bootstrap_indices`：用 11、22、33、44、55 在原訓練集內各重抽 72 筆、允許重複。係數穩定性範例固定原訓練集的標準化，只改抽樣；這是隔離抽樣影響的實驗，不是交叉驗證分數。
- `geometry`：等向限制圖的預算為 1，混合項係數 0.6 與 0.4；三種區域的截軸點都為正負 1，僅比較形狀，並未宣稱相同強度或相同資料誤差。
- `dropout`：四個固定隱藏輸出 `[2,-1,0.5,3]`、遮罩 `[1,0,1,0]`、保留率 0.75、丟棄率 0.25、PyTorch 種子 23304。固定遮罩只是合法的一次結果，不要求四個單元每次恰有三個保留。

## 套件與懲罰尺度

本組的資料損失是 `SSE/(2*n)`，截距不懲罰。若在 scikit-learn 重現模型，Lasso 的 `alpha=lambda`，Ridge 的 `alpha=2*n*lambda`，ElasticNet 的 `alpha=lambda1+2*lambda2`、`l1_ratio=lambda1/alpha`。

因此 n 為 72、lambda 為 0.2 時，Ridge 的 alpha 為 28.8；混合項的 alpha 為 0.28，l1_ratio 為 3/7。參數化對齊不代表三種懲罰在任何權重下都相同。

## 關鍵參考數值

固定權重的絕對值和為 3.5、平方和為 5.25。L1 懲罰 0.70、總目標 1.50；L2 懲罰 1.05、總目標 1.85；混合懲罰 0.84、總目標 1.64。

房價前兩欄的訓練集相關係數為 0.9999127167，客服為 0.9998949553。房價 Lasso 在三個強度下的驗證 MSE 分別為 1.2685、1.3352、2.7610；係數為 2 時全部斜率為零。

房價五次重抽樣中，Lasso 在兩個面積欄位間切換；Ridge 與 Elastic Net 都保留兩欄。這不是泛化表現的排序，也不表示客服資料必然出現相同切換。

固定遮罩的未縮放輸出為 `[2,0,0.5,0]`；inverted 輸出為 `[8/3,0,2/3,0]`。全部 16 種遮罩依 Bernoulli 機率加權後，inverted 輸出期望精確回到 `[2,-1,0.5,3]`。

## 使用頁面與圖

- `regularization`：三種懲罰的固定檢查點、重新訓練的強度比較。
- `l1-regularization`：固定檢查點、房價強度表、五次重抽樣選取穩定性。
- `l2-regularization`：固定檢查點、兩領域重新擬合係數；另附獨立的無訊號零係數邊界例子。
- `elastic-net`：兩項懲罰、係數映射、三種方法的共同資料比較。
- `dropout`：兩領域共用隱藏輸出、固定遮罩與期望核算。
- `l23304-regularization-lambda`：原始資料重新擬合產生的訓練／驗證 MSE。
- `l23304-l1-regularization-constraints`：三種等向限制區域，三頁共同引用。
- `l23304-dropout-mask`：由固定輸入、遮罩與保留率產生的輸出示意。
