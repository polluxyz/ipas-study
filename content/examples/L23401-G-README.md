# L23401-G 視覺系統風險審查共用例子

資料為教學合成，無真實人物、照片、第三方權重或商用資產。製造做瑕疵分類，零售做缺貨分類；每個領域各 12 張 4×4 灰階格網。

本組承接前置頁的任務、CNN 與隱私治理用語，未沿用前置組數值。格網不是攝影影像；人臉、車牌、兒童是虛構原始場景的審查註記，不能從這些格網測量真實去識別效果。

## 欄位

| 欄位 | 意義 |
|---|---|
| `id`、`pixels`、`label` | 影像索引、0～1 像素、二元真實標籤 |
| `origin_scene` | 原始場景的風險區域、範圍及拍攝光線 |
| `purpose`、`license_id` | 任務目的與來源台帳對照 |
| `roles`、`retention_days` | 教學角色及自行假設的 7 天保存期 |
| `baseline` | 自訂單格模型的原圖分數、原圖與攻擊後預測 |
| `licenses` | 五項資產的來源、版本、條件及待查處置 |

`defense_results` 保存本組實際訓練的權重與三種測試預測，方便獨立點積核算；不是手填的防禦結果。

## 固定規則

- 種子 42；像素生成本身採確定性算式，無抽樣。
- 陣列索引從 0 起：0～7 訓練，8～9 驗證，10～11 測試。兩領域使用相同索引，各自訓練，模型不混用。
- 第 i 張（i 從 0 起）的標籤為 `i % 2`。左上像素：正類 0.51、負類 0.49；中央四格：正類 0.7、負類 0.3。
- 其餘像素為 `0.45 + ((7*i + 3*r + 2*c + offset) % 11)/100`，製造 offset=0、零售 offset=3。每格保留兩位小數，r、c 從 0 起。
- 基準模型分數 `100*(左上像素-0.5)`，分數非負判 1。只改左上格：負類加 0.02、正類減 0.02，其他格不動。
- 新模型為 16 維無偏置線性層，輸入減 0.5，權重全零初始化。SGD 學習率 0.5、100 次全批次更新，只用 8 張訓練圖。
- 每輪擾動為 `(1-2*y)*0.02*sign(w)`，更新二元交叉熵；攻擊新模型時重算方向。所有像素距邊界足夠遠，0.02 與 0.25 攻擊都不需裁切。
- `origin_scene.region` 依索引循環人臉、車牌、兒童畫面；每類各 4 張。前 9 張光線甲、後 3 張光線乙，非人口群體代理。

## 關鍵參考數值

- M12、R12：基準分數 1 → 負 1；最大改動 0.02，標籤不變。
- 基準模型每領域原圖 12/12 判對、指定攻擊後 0/12 判對；兩張測試圖則 2/2 → 0/2。
- 新模型每領域兩張測試圖：原圖 2/2、幅度 0.02 為 2/2、幅度 0.25 為 0/2。後者超出威脅設定且可能改變任務內容，只作範圍外壓力測試。
- 新舊模型可用特徵與訓練方式同時改變，不能把差異全部歸因於對抗訓練。
- 台帳五項：自製格網、僅內部評估照片、缺授權權重、Apache-2.0 程式、CC BY 4.0 插圖。後四項是假設性審查項，並非實際納入像素或模型的上游資產。

## 使用頁面與圖

- `adversarial-examples`：單格模型、固定擾動與威脅分類。
- `adversarial-training`：同索引與相同擾動預算的更新及獨立測試。
- `visual-data-privacy`：相同影像 ID 的人物區域、用途、權限與期限盤點。
- `ai-license-governance`：同系統來源台帳與用途查核。

數據 SVG `l23401-adversarial-examples-perturbation` 由 `tmp/rollout/groups/W-L23401-G/figure-scripts/generate.mjs` 直接讀 JSON 產生；其餘兩圖是控制點與暴露路徑示意。程式實測及獨立核算見本組 `tmp/rollout/groups/W-L23401-G/` 報告。

重建順序：先執行本組 `make-example.mjs` 產生像素與台帳，再以共用 Python 環境跑 `experiment.py` 寫回實測權重及預測，最後執行 `figure-scripts/generate.mjs`。`check-numbers.py` 用標準函式庫核對分數、比例及切分。
