# L23102-B 共用矩陣

L23102-B-matrices.json是教學合成資料，不對應真實病人或設備。所有指數皆無物理或臨床單位，不得用來做實際診斷或控制。

## 欄位與固定規則

- row_ids固定01至06；兩領域列序相同，沒有跨領域配對的實務意義。
- manufacturing.X六列三欄依序是溫度、壓力、振動指數；medical.X是年齡、血壓、檢驗指數。
- 兩領域X的中心化偏差分別為(t,t,z)、(t,2t,z)。t=(-2,-1,0,0,1,2)，z=(-1,1,-1,1,1,-1)。
- y是固定的連續目標，製程為耗材量指數、醫療為照護成本指數。生成規則為截距+2t+3z+r；r=(1,0,-2,0,0,1)，截距分別10與30。
- seed固定23102；主矩陣完全確定，種子只用於NMF初始化。train_indices為0至3，validation_indices為4至5，全組比較沿用此切分。
- signal_label按z正負設為0或1，用來展示低變異方向也可能有分類訊息。
- nmf_parts另附六列兩部件係數W與兩列三特徵部件H，用於可手算的非負例，不冒充主矩陣的真實因子；noise只加到第0列第2欄0.2。
- eigen_demo是獨立二維對稱教學矩陣；variance_demo是獨立協方差特徵值6、3、1，不是主資料的測量結果。

## 關鍵參考數值

製程均值(10,20,5)，中心化矩陣秩2，協方差特徵值4、1.2、0，奇異值平方20、6、0。第一方向保留10/13變異，秩1重建SSE為6，秩2重建為0。

醫療均值(50,100,20)，協方差特徵值10、1.2、0，第一比例25/28，秩1重建SSE也是6。兩領域均未自動標準化；若各欄縮為單位變異，比例改為2/3、1/3、0。

製程OLS採[1,t,z]，係數(10,2,3)、殘差r、SSE6、MSE1；保留重複欄時最小範數解(10,1,1,3)。醫療[1,t,2t,z]解為(30,0.4,0.8,3)。

NMF原表WH可精確重建，加0.2後固定原因子的SSE為0.04；固定種子重擬合兩部件的SSE約0.005973586557，不要求因子唯一。

## 使用頁面

- matrix-factorization：中心化矩陣的精確兩因子與秩1近似。
- eigenvalue-decomposition：eigen_demo手算；主資料協方差作連結。
- svd：同一製程矩陣、三個奇異值與重建誤差。
- nonnegative-matrix-factorization：nmf_parts的加法部件、雜訊與非負近似。
- pca：製程投影、兩領域尺度對比、variance_demo、signal_label、固定切分。
- ordinary-least-squares：兩領域同索引的X與固定y，展示共線、正交殘差。
