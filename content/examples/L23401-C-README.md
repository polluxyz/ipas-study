# L23401-C 共用匿名模型例子

`L23401-C-privacy.json` 是教學合成資料，醫療、金融各 12 人，各人一列。兩領域共用相同索引次序、準識別分組及敏感類別代碼；沒有沿用前置組的數字，也不混合兩組資料。

- `index`：M01–M12／F01–F12，僅供教材核對，不是公開欄位。
- `age_band`、`district_group`：準識別欄位；北區 30–39、中區 40–49、南區 50–59 各四人。
- `sensitive`：醫療為疾病，金融為信用狀態。`homogeneous` 同質版、`skewed` 偏斜版、`balanced` 比例一致版只替換敏感值。
- `variants`：0／1／2 對應各領域 `labels` 的順序；每組四筆，保留全部 12 筆，不隨機切分。
- `distance`：不同類別搬移成本固定 1，使用等距類別 EMD，即總變差距離。門檻 t=0.3。
- `dp`：偏斜版計數第一種敏感值；刪 M01／F01 形成 11 人鄰近表。每人最多一列，計數全域敏感度 1。

固定規則：三個等價類大小永遠是 4；沒有補抽樣、刪不利紀錄或改群組。NumPy 示範種子固定 42，僅供教學重現，不能公開用來產生實際隱私輸出的種子。

| 版本 | 全體類別計數 | 最小 distinct-L | 最大距離 |
|---|---|---|---|
| 同質 | 4、4、4 | 1 | 2/3 |
| 偏斜 | 6、4、2 | 2 | 1/2 |
| 比例一致 | 6、3、3 | 3 | 0 |

偏斜版前三組的距離依序為 1/4、1/4、1/2。DP 計數從 6 變 5；epsilon=0.5 時 Laplace 尺度為 2；再釋出 epsilon=0.3 的同人查詢，基本組合上界為 0.8。

使用頁面：`k-anonymity` 列出偏斜版全部資料並計群大小；`l-diversity` 數敏感值種類；`t-closeness` 比較群內與全體比例；`differential-privacy` 用同表構造鄰近資料集與計數機制。圖由工作資料夾 `figure-scripts/make-figures.mjs` 從 JSON 重建。
