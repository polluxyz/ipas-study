# L21101-B 稀疏表示與靜態嵌入共用例子

`L21101-B-vectors.json` 全為教學合成資料，供六頁比較使用。原句、id、斷詞與資料分割沿用前置組 `L21101-A-corpus.json`；本檔只投影必要欄位並新增計數、視窗及手設向量，沒有改前置語料。

## 欄位與固定規則

- `source_ref` 保存前置檔的相對路徑與 SHA-256；前置檔合併後可驗證來源。本組生成時唯讀參照前置 worktree，不複製整份檔案。
- `documents` 有評論 R01–R12 與交通訂位 T01–T12 各 12 句。`domain` 是 review／transport，`text` 是原句，`tokens` 是原始人工斷詞，`length` 為斷詞後總詞數。
- `vocabulary` 按 R01–R12、T01–T12 首次出現順序固定，零起始索引。英文大小寫保持原樣，不做停用詞移除或詞形還原；`document_frequency` 數含詞文件篇數，不計同篇重複次數。
- `seed=42` 與 `split` 完全沿用前置組：train 16、validation 4、test 4。此組程式完全確定，不重新抽樣，也不訓練分類器或回報評估分數。
- 全 24 篇的詞表與 IDF 用於算術示範；實際模型評估要先切分，只在訓練文件擬合詞表與 IDF。不能把全語料示範當成無洩漏的評估流程。
- `bow_display_vocabulary` 只顯示「我、不、喜歡、書、訂、票」六欄，完整詞袋仍有 53 維。文件長度取完整 tokens，不取顯示欄位計數和。
- `window.radius=2`：左右最多兩詞、不跨文件、不補邊界，不降採樣、不做距離加權。每個中心到周邊算一個有向事件；句首句尾截短。CBOW 每個詞作一次中心；Skip-gram 每個有向事件是一個正樣本。
- `cooccurrence` 是「訂、改、要、明天、的、票」六詞子矩陣。先在完整原句取視窗，再挑六詞行列；禁止先刪詞後重新取視窗。此六詞順序與詞袋六欄是不同的顯示目的。
- `embedding.vectors` 有「訂、改、票、書、book、books」六詞的三維向量。全部是人工指定，方便核算餘弦與比較表示形式；**不是**由本語料、Word2Vec 或 GloVe 訓練所得。各維不命名為真實語意特徵。
- `probes` 固定評論 R02、交通 T03、CBOW T02 的零起始中心 3，以及起訖站顛倒的兩個序列反例。

## 關鍵核對數字

- 24 篇、120 詞、53 個不同詞；文件長度依次為 R：5、6、5、5、4、4、5、5、4、3、4、5，T：9、7、8、6、4、7、7、7、2、2、2、4。
- df：書 4、票 5、不 6、我 9。R02 書的正規化 TF 為 1/6，常用對數 IDF 為 log10(24/4)，乘積約 0.129692；T03 票的乘積約 0.085155。
- scikit-learn 預設約定下，書的平滑 IDF 約 2.609438，R02 完整向量的 L2 長度約 5.920944，書的正規化權重約 0.440713。
- T02 中心訂的上下文為「不、要、明天、的」：1 個 CBOW 樣本、4 個 Skip-gram 正樣本。全語料為 CBOW 120、Skip-gram 336；六詞共現子矩陣元素總和為 38，這不等於完整詞表全部事件數。
- 訂到明天 2 次、改到明天 1 次、的到票 4 次。左右等權使本表對稱；這不是所有 GloVe 視窗的必要設定。
- 三維餘弦：訂與改約 0.992331；訂與書約 0.228571；圖只畫前兩維，計算使用三維。
