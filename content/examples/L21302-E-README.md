# L21302-E：四期監控與候選驗證

`L21302-E-operations.json` 為固定教學合成資料。授信與視覺各有四個互不重疊的週窗，每窗 1,000 筆，W0 是固定參考；不得把 W1 改作 W2 的參考來掩蓋累積變動。

## 銜接與固定規則

- 沿用前置組的 API v1、特徵規則 f1 及 inspect-v3 名稱；本組是另一批監控資料，沒有沿用或改寫前置組的發布數值，也不合併其分母。
- 種子 21302；資料全明列，沒有隨機抽樣。同領域五頁共用索引、切分及門檻。
- 監控每期索引 1–950 是一般群、951–1000 是長尾群；組內前 `errors` 筆為錯誤。`feature_counts` 是特徵邊際分箱計數，不提供群體交叉分箱分布。
- TR、VA、EV 三套 ID 不重疊，分別用於訓練、調參及獨立晉升驗證。監控四期也不屬於上述三集；EV 的 1,000 個固定索引供現行及三個候選共同評分。
- 授信與視覺各自使用上述 ID 命名空間；共用索引及切分規則，不共用樣本或真值。`validation.candidates` 的 `main_errors`／`tail_errors` 屬授信，`vision_main_errors`／`vision_tail_errors` 屬視覺。
- 各期錯誤數是完整真值回收後摘要。授信窗結束時真值尚未成熟，視覺回收 800 筆；不得把完整摘要冒稱當日可得指標。
- 四期為不同自然時間的觀測，W3 同時含版本與環境變化，不能單憑 W3 改善歸因於新模型。
- 候選 TR／VA／EV 的歷史事件最晚 5/31，真值於 6/30 前齊備，7/21 已核准後進入 W3。授信 W2 的 30 天真值延遲至 8/14–8/20；成熟後啟動的是另一輪更新示範。
- 各領域現行版 EV 計數刻意設成與其 W2 摘要相同以便教學；EV 仍是獨立歷史樣本，沒有把未成熟 W2 真值提前用於驗證。

## 欄位

| 欄位 | 意義 | 單位／條件 |
|---|---|---|
| periods.dates、n | 參考／監控窗及總數 | 互不重疊週窗、筆 |
| feature_counts、bins | 消費金額或亮度的固定箱計數 | 同領域箱界固定 |
| groups | 一般與長尾群的分母、錯誤數 | 長尾固定 5% |
| labels、quality | 真值延遲、回收及輸入品質 | 延遲日數；模糊圖只用於視覺 |
| model_version、api、feature_rule | 當期實際版本 | 回復需一起核對 |
| validation | 固定獨立集的候選錯誤及資源 | 延遲 ms、記憶體 MB |

`service_alert` 保存每分鐘請求失敗計數、窗數規則與處理人；它和預測錯誤率是不同事件流。`for_minutes=3` 指三個完整的一分鐘窗，窗尾計數，不是 Prometheus 的 `for: 3m`；`evaluation_rule` 明寫此界線。

`gates.blur_rate_max=0.10` 是模糊圖比例超過 10% 即通知現場的教學門檻，分母是當窗全部影像。`faq` 保存知識過時與併發案例；`feature_pipeline` 保存事件、可用與請求時戳。

`labeling` 的 1,200 筆回收素材依序剔除 20 筆缺 ID、30 筆時間錯配、50 筆標註分歧，餘 1,100 筆通過品質門檻；不是直接拿來覆寫 EV 集。

## 關鍵核算

- 授信 W0／W1／W2／W3 完整回收錯誤率：2.4%／3.9%／5.8%／2.4%；長尾：10%／40%／40%／10%。
- 授信 W1 相對 W0 的 PSI：0.549774；W2 相同；W3 為 0.016425。
- 視覺 W1 的 PSI：約 0.425295；W2、W3 為 0。W2 長尾仍 30% 錯誤，說明輸入邊際恢復不保證品質恢復。
- 授信候選 A／B／C 整體錯誤率：3.8%／2.9%／2%；長尾：60%／10%／4%。現行版為 5.8%／40%。
- 視覺候選 A／B／C 整體錯誤率：3.1%／1.9%／1%；長尾：50%／8%／2%。現行版為 3.4%／30%。兩領域都只有 B 通過；A 因群體、C 因延遲遭拒。
- 即時鏈路各段配置合計 70 ms，100 ms 預算留 30 ms；倉儲改為同步讀取會變 238 ms。這是教學預算相加，不是各段 p95 的統計相加。

五頁均讀本檔：model-monitoring 用四期／告警／FAQ；population-stability-index 用分箱；model-retraining 用候選；retraining-pipeline 用標註及回復；realtime-feature-pipeline 用時戳與延遲。
