# L21102-B：偵測、分割與提示遮罩共用例子

`L21102-B-scenes.json` 是教學合成資料；交通 T01–T08、醫療 H01–H08 各八張 8×8 示意圖。交通採 RGB，醫療採單通道，兩領域各自使用類別名稱；示意像素不是實際照片、掃描或病歷。

## 固定規則

- 種子固定為 21102；資料本身由固定位置規則產生，不依隨機抽樣更換標準答案。各圖另加固定亮度偏移，像素內容不完全重複。
- 各領域 01–04 為訓練、05–06 為驗證、07–08 為測試，同領域的各頁與模型共用索引。這只是示意切分，不代表八張圖足以驗證真實系統。
- 左上原點，x 向右、y 向下，矩陣用 `[y][x]`。框為 `[x1,y1,x2,y2]`，右下邊界不含；遮罩只描述可見範圍。
- 各張圖保留兩個不重疊的可數個體。背景個體值為 0；類別 0 並非忽略區域。所有 64 格均有效。
- 類別 0／1／2：交通為道路／行人／建築；醫療為一般組織／病灶／器官區。
- `predicted_masks` 全是人工固定的教學預測，沒有下載或執行模型。理想遮罩不表示真實模型有完美表現；SAM 欄故意漏掉目標的一格。

## 欄位

| 欄位 | 意義 |
|---|---|
| `image_id`、尺寸、`channels`、`split` | 影像索引、形狀與固定分割 |
| `pixels` | 小型示意像素，來自固定類別配色 |
| `semantic_class_map`、`instance_map` | 全圖像素類別與可數個體值 |
| `object_boxes`、`objects` | 框、個體／類別值及各物件真值遮罩 |
| `prompt_points`、`prompt_box` | 提示點含前／背景標記；框為第一個物件的真值框 |
| `ground_truth_mask`、`predicted_masks` | 第一物件的真值與示意預測；Mask R-CNN 欄為兩份遮罩 |

`shapes.fcn` 固定 NCHW 的輸入、特徵、分數與上採樣形狀；`shapes.unet` 固定編碼跳接、解碼、上採樣與串接形狀。這些是最小教學層規格，不是原始論文的完整架構。

## 關鍵參考數值

| 項目 | 交通 T01 | 醫療 H01 |
|---|---|---|
| 類別 1 像素 | 9 | 5 |
| 個體 1／2 像素 | 5／4 | 2／3 |
| 類別 0／2 像素 | 30／25 | 31／28 |
| 第一框 | `[1,1,3,4]` | `[1,1,3,2]` |
| 第二框 | `[5,3,7,5]` | `[5,3,7,5]` |
| SAM 示意預測保留格 | 4（真值 5） | 1（真值 2） |

T01 第一名行人呈非矩形，外接框 6 格中只有 5 格屬於行人，另 1 格為建築。H01 第二病灶呈 L 形，框 4 格中病灶占 3 格，另 1 格為一般組織。這兩種輪廓沿用到各領域的八張圖，讓框與遮罩的差別可逐格核對。

FCN 分數由（1,3,2,2）放大四倍空間尺寸後為（1,3,8,8）；類別選擇後為（1,8,8）。U-Net 的（1,8,8,8）與（1,4,8,8）沿通道串接，得到（1,12,8,8）。

## 使用頁與重建

七頁 `object-detection`、`image-segmentation`、`fcn`、`u-net`、`mask-rcnn`、`panoptic-segmentation`、`segment-anything` 共同使用此檔。

- 偵測、Mask R-CNN：共用兩物件及框；分割與全景：共用類別和個體真值。
- FCN、U-Net：共用 `shapes`；程式僅核對分數頭、上採樣與串接形狀，不訓練完整模型。
- SAM：共用提示、真值與故意漏格的教學預測，不展示模型實測品質。

重建腳本是工作報告附件 `tmp/rollout/groups/W-L21102-B/figure-scripts/create-assets.mjs`，執行位置為 repo 根目錄。數字核對與圖檢查記於同資料夾的 `examples-check.md`；此腳本不修改其他組的資料或程式。
