# L23201-C 強化學習共用例子

這兩份 JSON 都是教學合成資料。四頁共用相同轉移 ID、順序、起點與折扣因子；不引用前置組的分佈數據，也沒有另造訓練／測試分數。

## 欄位與固定規則

- `states`：四個完整狀態的代碼與意義。倉儲狀態同時包含位置與貨物狀況；不是只看座標。
- `actions`：兩個動作的定義。倉儲的抓取包含由取貨格搬到交接格，放回則包含退回取貨格。
- `transitions`：每列是一個可能結果，含固定 `id`、目前狀態、動作、下一狀態、機率與單步獎勵。每份12列；每組狀態與動作的機率合計1。
- `reward`：任務導向獎勵。倉儲完成交付給10，其餘作業扣1；D的兩條零獎勵自迴圈只是吸收狀態的表格定義，實際進D即停。
- `grab_reward`：倉儲錯配版獎勵，只有成功抓取給8，忽略交付與時間成本。原版與修正版只換獎勵，不換轉移。
- 能源獎勵：正常供電4、充電成功-2、無效充電-1、有電量但放電失敗0；耗至空電或空電供電-6。模型未含電價或時段，若真實任務受其影響須擴充狀態。
- `trajectories`：固定的轉移 ID 清單，重播的是已指定的可能結果，不是機率抽樣，不能把軌跡回報當期望價值。
- `seed=42`：供日後跨頁抽樣統一使用；本組程式只列舉／重播，不消耗亂數。
- `evaluation`：倉儲最多5步、進D立即終止；能源看3步。沒有訓練或測試資料切分，沒有訓練成績。
- `policy`：示範用決策規則，並不宣稱最優。`potential`為獎勵塑形的教學勢能。

## 已核算的參考值

- 倉儲交付軌跡 W01、W05、W07：獎勵[-1,-1,10]，gamma=0.9時回報6.2；該軌跡的發生機率0.576（以指定動作為條件）。
- 倉儲重複抓取軌跡 W01、W05、W09、W05、W09：任務獎勵回報-4.0951；錯配版回報13.032。
- 同起點、同5步上限：交付軌跡錯配版回報7.2，修正版6.2，進D後不用補零動作。
- C只有1步可用時，作業前進的期望獎勵為0.9×10+0.1×(-1)=8.9。
- gamma=0.2時交付回報-0.8；gamma=0時只看第一步-1；gamma=1時三步加總8。
- 能源耗盡軌跡 E11、E08、E06：獎勵[4,4,-6]，折扣回報2.74。
- 能源保留軌跡 E11、E07、E11：獎勵[4,-2,4]，折扣回報5.44。
- 倉儲勢能塑形 F=gamma×Phi(next)-Phi(state)，交付三步F為[1.2,1.1,1]，塑形後獎勵[0.2,0.1,11]，回報9.2，等於6.2-Phi(A)。

## 頁面使用

- `reinforcement-learning`：代理人迴圈、三步交付、獎勵投機與第二領域。
- `markov-decision-process`：同表解釋轉移機率、策略／價值、三步回報、能源比較。
- `reinforcement-learning-methods`：同表比較模型、策略、價值、獎勵四種不同物件，不另造Q值。
- `reward-design`：同起點同上限比較重複抓取與交付；勢能塑形只在真正終止、終點勢能為0時示範。
