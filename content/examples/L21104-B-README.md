# L21104-B 共用事件與時間序列

`L21104-B-events.json` 全為教學合成資料，工廠巡檢與城市交通各 24 事件、各四對短序列。沒有實體影像、音訊，也沒有執行或評測模型；`synthetic://` 是不可下載的教學索引，不是外部連結。

## 欄位與固定規則

- `sample_id` 是事件 ID，`entity_id` 是本例互相獨立的設備／路口單位；F01–F24、T01–T24 各自固定。每領域 01–12 訓練、13–16 驗證、17–24 測試；這是獨立單位教學切分，不是時間外推試驗。
- `event_time_ms` 是共同時鐘上的事件時刻，從 10000 ms 起每事件增加 1000 ms。`raw_timestamp_ms` 是各來源原始時間，`clock_offset_ms` 的定義為原始時間減事件時間；影像 0、文字 20、感測 50 ms，因此校正時減去偏移。
- `image_ref`、`image_description`、`text_ref`、`note` 分別提供教學影像索引／描述與巡檢註記；沒有實際媒體。`sensor_value` 的工廠單位為振動 RMS 的 mm/s，交通單位為車流輛/min，不跨單位直接相減。
- `present_mask` 順序固定為 image、text、sensor；1 可用、0 缺失。每八筆依序為 111、111、101、101、110、110、011、000。缺失欄位及對應分支分數為 null；`image_description` 是供作者理解的場景說明，即使影像缺失也不作模型輸入。
- `branch_scores` 是各分支對同一正類「需複核」的合成分數，並非校準機率。`truth` 為布林值，每八筆依序為真、假、真、假、真、假、真、假。
- `approved_auto_masks` 固定 111、110、101、011；示例政策假設它們已驗證。只對可用分支取等權平均，分數 ≥0.5 判需複核；其餘組合轉人工，不能取空平均。此政策不是研究來源的通用建議，也不是已做實務驗收。
- `speech_reference_tokens` 與 `asr_hypothesis_tokens` 是獨立的語音查詢參考，不是上述巡檢文字模態；沒有音檔或 ASR 實測。每筆 5 個固定詞，第二與第六個循環位置把「三號」替換為「四號」，其餘相同。分詞、標點與數字不另作變換。
- `response_timing_ms` 以語音結束至首段可播放回覆計時；每八筆依序為 350、360、370、380、390、400、410、420 ms，均為模擬。它不同於前置 L21103-F 的 TTS 請求起點，因此沒有沿用或重編該組數字。
- `data_version`、`label_version`、`calibration_version` 固定 data-v1、label-v1、cal-v1。正文 label-v2 只是修訂設計示意，沒有生成第二版資料。
- `sequence_pairs` 每領域四對，都是同尺度的「正規化進度特徵」，不是原始振動與車流。DTW 局部成本為絕對差，不開根號、不除路徑長；1 起算路徑，按列 Y、欄 X 的表格，同分先對角、再左、再上。
- `seed=42` 作為資料／比較契約；本例生成與評分均為確定性規則，沒有假稱種子會保證真實模型完全重現。`sampling_hz`、20 ms 配對容許差及 100 ms 排程預算均為自訂教學條件。

兩領域刻意使用相同短序列，讓換景後仍可用同一局部成本與路徑核對實作；交通案例沒有提供額外的 DTW 泛化證據。不同領域的原始單位與事件身分，仍須先分清楚。

`note` 描述文字分支收到的觀察，與合成分數的高低方向一致，並非真值保證。少數正常事件仍帶疑似異常註記，刻意保留文字分支的誤報；分數是人工設定，沒有由註記執行模型推得。

語音素材的「三號」未與各事件的 `entity_id` 建立對照。語音串接頁僅借用素材示範辨識，查詢對象解析與回覆結果另作流程假設，不以 F17／T17 冒充三號的查詢紀錄。

## 關鍵核算值

- 每領域訓練／驗證／測試 =12／4／8；測試遮罩 111、101、110 各 2 筆，011、000 各 1 筆，自動覆蓋 7/8=87.5%。
- 每領域融合自動結果 TP=4、FP=1、TN=2、FN=0；準確率（Accuracy）=6/7、假陽性率（FPR）=1/3、精確率（Precision）=4/5、F1=8/9。保留的 000 是負類，但拒答不可算成自動判對。
- 工廠測試影像／文字／感測正確數 =4/6、4/5、5/5；交通 =4/6、4/5、4/5。共同完整來源子集只含各領域 17、18；工廠依序 1/2、2/2、2/2，交通 2/2、2/2、1/2，融合均 2/2。
- 每領域八段測試轉寫共 40 個參考詞、2 次替換，WER=2/40=5%；兩域合計4/80=5%。測試回覆延遲平均385 ms、範圍350–420 ms。
- F-S1/T-S1 的 X=[1,2,3]、Y=[1,1,2,3]，DTW=0，路徑(1,1)→(1,2)→(2,3)→(3,4)；其他三對成本依序0、1、0。
- F01 時間校正：10050−50=10000 ms；20 Hz=50 ms 間隔、10 Hz=100 ms 間隔。排程預算平行分支總計80 ms，串行105 ms；不是硬體效能測量。

## 使用頁與圖

- `sensor-fusion`：F01/T01、頻率、偏移、空間校正與預算。
- `multimodal-data-alignment`：三種錯配、F-S1/T-S1、四對序列及版本契約。
- `missing-modality`：F19/F24、T19/T24、遮罩計數、八種路由。
- `speech-recognition-pipeline`：F17/F18、T17 的查詢語音與事件索引。
- `multimodal-application-evaluation`：同一測試事件上的分模態計數、服務覆蓋、WER 與時間端點。
