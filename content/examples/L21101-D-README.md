# L21101-D 共用例子

所有文件、規範、權重、排名與輸出均為教學合成資料，不代表真實票務或勞動規則。

- `L21101-D-policies.json`：`domains.transport` 為交通退票，`domains.leave` 為公司請假；各有 8 區塊、8 查詢。
- `documents`：`doc_id` 是穩定區塊 ID；`title/text/terms` 是標題、內容與人工斷詞標籤；`version/source` 是版本及引用來源；`access/current/trusted` 控制權限、效期與攝入信任。
- `queries`：`query_id/query/terms` 固定輸入；`relevant_docs` 是現行、可存取文件的人工相關標註；`lexical_rank/vector_rank` 是兩份手設名次表；`rerank_reference` 是重排後應保留的人工參考，不是模型結果；`answer_reference/citations_reference` 是理想回答與引用。
- `settings`：快照 2026-10-01、索引 policy-v1、一規則一塊、種子 42。程式無亂數；每域查詢 1–4 作開發、5–8 作保留稽核，示例沒有調參。跨頁比較保持以上設定相同。
- 第 5 區塊過期、第 6 區塊超出一般讀者權限、第 7 區塊為已標記隔離的惡意片段。`trusted` 是攝入端既有測試標記，並非已能自動偵測未知注入。
- 每域查詢 6、8 的相關集為空，應拒答或轉人工；計算檢索召回率時不放進有答案查詢的分母，另看拒答品質。

## 關鍵核對值

第一查詢的兩路排名是 03→01→04 與 02→01→08（各域換相同前綴）。RRF 常數 60，01 得 2/62，02、03 各得 1/61，04、08 各得 1/63。同分按 ID 升冪，融合次序為 01、02、03、04、08。前二名找齊兩份相關文件，召回率為 2/2。

上述 2/2 依賴同分規則；若 02 與 03 同分時先取 03，前二名只命中 1/2。此反例在交通、請假兩域相同，不能據此宣稱 RRF 必然改善檢索。

交通本機字詞重疊檢索的第一查詢：T02 命中 2 詞、T01 命中 1 詞，其餘安全區塊 0 詞。前二名順序為 T02、T01；模板整合輸出仍使用 T01 的 90% 與 T02 的 100%。

`seq2seq` 的來源／目標詞元數（不含結束符號）為 6→3、2→4、6→3。詞元是教學切法，不宣稱對應特定 tokenizer。

若在目標最後另加 `eos`，三例的參考輸出步數依序為 4、5、4；seq2seq 頁的程式只列出這些既有參考序列，沒有執行模型生成。

`attention` 的兩張 4×4 熱圖由同一個 `before` 與指定 top-1 規則產生。原第四列加權值為 2.08；保留最大權重後為 8；刻意聚焦第一格的反例為 0。所有列非負、和為 1；歸一化權重的 L1 範數皆為 1。

## 使用頁面

- `rag`：版本、權限、文件引用、本機檢索、兩階段診斷。
- `hybrid-search`：同索引與第一查詢的雙排名、RRF 與相關性核對。
- `seq2seq`：交通翻譯／摘要及請假摘要的變長序列。
- `attention-collapse`：手設權重的加權平均、稀疏化及錯誤聚焦反例。
