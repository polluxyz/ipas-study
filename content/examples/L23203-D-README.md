# CNN 元件與尺寸共用例子

`L23203-D-images.json` 是教學合成資料，供 convolution-layer、pooling、flatten、cnn、cnn-tensor-shapes 五頁共用。製造瑕疵及交通標誌各 16 張，皆為 8×8×3；不能據此宣稱真實辨識成效。

- `rows.index`：各領域從 0 起算，同領域所有頁面共用；`id` 是可讀編號。
- `pixels`：高、寬、通道（HWC）的巢狀陣列；通道值介於 0 與 1。
- `label`：0 為直向，1 為橫向；`classes` 為顯示名稱。每個領域獨立訓練，不混用兩套任務標籤。
- `split`：0–11 訓練、12–13 驗證、14–15 測試；各份兩類平均。這只是索引展示，不可作獨立評估：每領域僅六種不同像素內容，驗證與測試影像全部在訓練集出現過。實際評估前須先按內容去重、重新切分，並增加樣本。
- `seed=23203`：與前置組對齊，資料本身依固定規則產生；PyTorch 權重以此初始化。
- `conv`：3×3、stride 1、valid、3→2 通道、groups=1、dilation=1、有 bias，規格承接 W-L23203-C；輸出 6×6×2，參數 56、單張 1944 MAC。
- `pool`：2×2、stride 2、不 padding、不 ceil；輸出 3×3×2，無可訓練參數。
- `head`：本組二類分類，展平 18 維接兩個 logits；Dense 參數 38、36 MAC，全網 94 參數、1980 MAC、3960 FLOPs。
- `hand`：3×3 單通道小圖供卷積手算；採相關運算、不翻核，2×2 核輸出 `[[0,-1],[-1,1]]`。保留的 `pool_kernel=2`、`pool_stride=1` 是原重疊算例的核算紀錄，正文池化已改用下一項。
- `pooling_demo`：把原小圖四個重疊視窗的值依原順序排成 4×4 圖，方便以 2×2、stride 2 示範非重疊池化。最大 `[[2,3],[2,3]]`、平均 `[[1,1.5],[1,1.25]]`；左上 [1,2,0,1] 也供 Softmax 比較。
- `flatten_demo`：依 CHW 先列通道內每列，再列下一通道；展平是 `[1,2,3,4,10,20,30,40]`，批次軸保留。
- `remainder_case`：8×8、3×3、stride 2、valid，輸出 3×3，含無法完整覆蓋的尾端。
- `cost_convention`：FP32 每值四 bytes；前向一 MAC 算兩 FLOPs，排除項明列，不能視為延遲或訓練峰值。

前置組的 `L23203-C-frameworks.json` 有 18 張製造資料與三類分類頭，本組依任務另建 16 張、二類資料。只沿用卷積規格，不把前置組的 275 參數誤寫成此處含池化模型的成本。

重建資料：`node tmp/rollout/groups/W-L23203-D/make-examples.cjs`。圖的數字皆由本例子算出，產圖腳本與獨立核算紀錄在本組暫存工作資料夾。
