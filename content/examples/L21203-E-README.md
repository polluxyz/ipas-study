# L21203-E 共用例子

`L21203-E-sector-flows.json` 是教學合成清冊 e1，沒有真實個資、真實公司或官方核准。四個領域各三條委外資料流，共十二條；所有法規適用與許可結果均留待官方核對。

## 欄位與固定規則

- `sectors`：金融 FIN、醫療 MED、電信 TEL、製造 MFG；各自固定用途、委託方、受託方、審核人及版本。
- `flows`：第一流是委託方到國內受託方，第二流是交付回委託方，第三流是海外複委託；列明來源、儲存及遠端接取地區、角色、資料、證據與缺口。
- `evidence`：虛構證據索引，用來練習串連責任，並非已取得的真實法律文件。`gap` 為本例未完成事項。
- `rules`：用途限定、最小權限及加密是教學控制；資料、模型與生成輸出的權利分開查。
- `contract`：十四日交付與逐項一致的驗收是本例約定，並非法定期限。
- `sandbox_plan`：一百人、八週、人工決定是未核准草案，並非法定人數或期間上限。
- `samples`：每領域十二筆固定合成記錄。索引 1–6 為訓練、7–8 為驗證、9–12 為測試；種子 21203 留作紀錄，沒有執行隨機抽樣或訓練。
- `model`：固定分數查表，並非真實訓練出的模型。`audit` 記錄閾值、程序、環境、審核與權限。

## 關鍵參考值

- 四領域共四十八筆樣本，二十四筆訓練、八筆驗證、十六筆測試；資料分割沒有交集。
- 每領域三條資料流；第三流都有一個待補缺口，暫停第三流不等於另兩流已獲法律核准。
- 金融測試索引 9–12 的分數為 0.2、0.7、0.8、0.4，標籤為 0、0、1、1。
- 醫療同索引分數為 0.1、0.6、0.9、0.3，標籤為 0、1、1、0。
- 閾值 0.5 且 `score >= threshold` 為正類時，金融及醫療的輸出皆為 0、1、1、0；金融兩筆判錯，醫療四筆均對。極小合成樣本不能推論實際效能。
- 金融閾值改為 0.75 時，輸出變成 0、0、1、0；必須記為程序變更，不能冒稱同一評估重現。

## 使用頁面

- `data-outsourcing-governance`：全部領域、FIN-3 缺口、契約與權利清單。
- `financial-regulatory-sandbox`：金融三流、未核准試驗草案；醫療及製造換景。
- `medical-device-regulation`：醫療三流、預期用途、醫材提問表；金融及製造換景。
- `telecom-regulation`：電信三流、海外除錯與消費爭議；醫療及製造換景。
- `audit-reproducibility`：金融與醫療共用索引、人工重做程序及權限紀錄。

## 讀者如何重做

完整人工程序 e2 寫在 `content/concepts/audit-reproducibility.md` 的「逐筆重做評估」小節。依清冊索引 9–12 逐筆比較分數與閾值，再對照保存輸出及標籤，不需取得 `tmp/` 的開發核算腳本。

`audit.code_version` 指向頁內程序版本，本例沒有另交評估程式；`audit.environment` 記錄人工十進位比較。正式模型仍須提供可取得的程式、環境、前處理及權重載入方法。

法源網址、版本與效力查核記於各頁。讀者替換成真實資料時，必須重新確認適用法規、授權與存取範圍。
