# CNN 架構比較共用例子

`L23203-E-tensors.json` 承接 `L23203-D-images.json`，供 cnn-architectures、residual-connections、densenet、efficient-cnn 四頁使用。全數為教學合成資料，沒有下載模型或宣稱辨識品質。

- `upstream`：上游檔案路徑與固定契約；製造瑕疵及交通標誌各 16 張 8×8×3，種子 23203。所有比較沿用相同索引與切分，兩領域分開看，不把兩者當成同一標籤任務。
- 上游影像不複製到本組。其切分存在相同像素跨集，僅作索引示範，不能作獨立評估；實際評估應先去重並重新切分。
- `manufacturing.x`、`traffic.x`：另設的 NCHW=1×2×2×2 中間特徵小張量。它們不是上游影像的模型輸出，也不以像素值解釋預測成效。殘差與 Dense 兩頁共用完全相同的 X 及第一層權重。
- `residual`：無偏置 1×1 卷積，對角權重 0.5，故 F(X)=0.5X；相加不改通道，參數 4。製造左上位置 X=(1,4)、F=(0.5,2)、Y=(1.5,6)；全部元素的 d(sum Y)/dX 都是 1.5。
- `dense`：第一層同 residual，第二層無偏置 1×1、4→2，權重均 0.5。通道 2→4→6，兩層合計 4+8=12 個參數。製造第二層每個位置、每個新增通道都是 3.75；第一個位置拼接 [1,4,0.5,2]，與相加 [1.5,6] 不同。
- `lightweight`：NCHW=1×3×3×3。三個通道和為 45、9、−9，逐通道 3×3 核全為 1，接 pointwise 的兩組權重，輸出 [45,54]，形狀 1×2×1×1。
- `resource_cards`：同輸入 1×3×8×8、3→2 通道、3×3 valid、stride 1、無偏置。標準卷積 54 參數、1944 MAC；深度可分離卷積 27+6=33 參數、1188 MAC，兩者輸出皆 1×2×6×6。這裡關掉偏置，上游有偏置為 56 參數，不能混用。
- `vgg_demo`：同寬 2 通道，一層 5×5 核 100 權重；兩層 3×3 合計 72。stride=dilation=1 時理論感受野皆 5×5；中間有 ReLU 時不代表函數相同。
- `inception_demo`：輸入 6×6×2，四分支輸出通道 2、2、1、1，適當 padding 保留高寬；拼接 6×6×6。只是教學區塊，不是完整 GoogLeNet。
- `scaling_demo`：深、寬、解析度倍率 1.2、1.1、1.15；一般卷積成本近似倍數 1.92027，不包含實際模型的整數取整與硬體時間。
