# L21101-C 共用例子

`L21101-C-context.json` 是銀行客服、河川教育各 10 句的教學合成資料。`霧嶼坪` 是虛構少見地名，不指涉真實銀行、地點或客戶。

- `documents`：`id` 固定為 B01–B10、R01–R10；`text` 是短文，`tokens` 是固定切分，`target_index` 與 `mask_position` 從零起算。`sense` 是人工指定的 bank 語境義，`intent` 是教學任務標籤，`entity` 記地名與類型；`continuation_reference` 供後續寫作組參考，不是模型生成結果。
- `split`：各領域第 1–6 句訓練、第 7–8 句驗證、第 9–10 句測試，共 12／4／4 句。此處只做教學計算，不用這個微型切分估計泛化能力。沿用相同索引與種子 42；實際算例沒有隨機步驟。
- `subword_demo`：在詞前後加入 `<`、`>`，固定字元 n=3；不做語素分析或 BPE。霧嶼坪的完整片段是 `<霧嶼`、`霧嶼坪`、`嶼坪>`。三向量和為 (3,3)，平均為 (1,1)；整詞不在詞表，沒有整詞專屬向量。
- `contextual_demo`：靜態 bank 固定為 (1,1)，B01、R01 的語境表示分別為 (0.9,0.1)、(0.2,0.8)。全是手設二維示意，不是從這 20 句訓練而得，也不能與 ELMo 範例跨空間比較。2／18／10 ms 是選型假設，並非任何工具的效能宣稱。
- `elmo_demo`：每方向寬度 2，串接寬度 4；第 0 層為已對齊寬度的詞表示，第 1、2 層為同位置正反向狀態串接。權重 (0.2,0.3,0.5) 加總為 1、縮放為 1；B01 混合為 (0.89,0.31,0.78,0.42)，R01 為 (0.89,0.31,0.39,0.81)。兩句的 bank 本身與共同前綴相同，因此輸入層及各層正向半部一致；只改後文時，本例只改反向半部。這遵守同模型、同初始狀態、無隨機遮罩的推論條件；向量仍為手設，沒有訓練 LSTM。
- `pragmatic_cases`：P01–P06 是附上下文的語用判讀例，保留資訊不足時的替代解讀，不把反語寫成單一關鍵字規則。P05、P06 的台語詞義依教育部臺灣台語常用詞辭典「歹勢」條目，情境自行設計。

使用頁面：`fasttext` 用字元片段與地名；`contextual-word-embedding` 用 B01／R01 與選型條件；`elmo` 用相同句子的雙向資訊與四維混層；`semantic-ambiguity` 用 B01／R01 與 P01–P06。
