# L23301-D 共用教學資料

資料全為教學合成，不能據此宣稱金融或製造模型效能。沒有真實個資，也不由考題改寫。

## 六特徵資料

`L23301-D-credit-manufacturing.json` 各含授信、製造 36 筆。兩領域逐列對應，索引從 0 起、顯示 ID 從 01 起；六特徵以 `credit_features`、`manufacturing_features` 決定順序。

- 授信：income 月收入（千元）、annual_income 年收入（千元）、debt_ratio 負債比、age 年齡（歲）、tenure 年資（年）、noise 人工編號型數值；default 為 0 未違約、1 違約。
- 製造：temperature 溫度（°C）、temperature_copy 完全相同的溫度副本、vibration 振動（mm/s）、pressure 壓力（kPa）、runtime 運轉年數、noise 人工編號型數值；defect 為 0 合格、1 瑕疵。
- 連續目標：授信 loss_amount 為損失金額（元），製造 loss_units 為損失量（單位）。它們只供迴歸教學，不是由分類結果得出的真實損失。
- noise 對分類標籤沒有單欄關係，但刻意加入連續目標；藉此說明欄名與任務有用性不同。

固定規則：對索引 i，令 j 為 i 除 2 的整數商、標籤為 i 除 2 的餘數。收入由 `50+5*(2*(j%6)-5)` 產生，負債比由 `0.5+0.1*(2*標籤-1)+0.02*(j//6-1)` 產生。

年收入為收入乘 12；年齡為 `25+7*j%17`，年資為 `1+5*j%9`，noise 為 `11*j%13`。授信連續目標為負債比乘 1000，加年齡乘 2，再加 noise 乘 3。

製造依序對應月收入、月收入副本、負債比乘 10、年齡、年資、noise；連續目標為授信損失除以 10。這保留相同的統計結構，不代表兩個領域有相同的業務意義。

## 切分與比較規則

- `j%3!=2` 為開發資料，共 24 筆、每類 12 筆；`j%3==2` 為測試，共 12 筆、每類 6 筆。兩領域共用索引。
- 訓練索引：0、1、2、3、6、7、8、9、12、13、14、15、18、19、20、21、24、25、26、27、30、31、32、33。
- 測試索引：4、5、10、11、16、17、22、23、28、29、34、35。
- 比較分類篩選時使用 StratifiedKFold，3 摺、shuffle=true、random_state=17；指標為 ROC AUC。估參數的縮放與篩選都在對應訓練邊界內。JSON 的 `train_indices` 在教材稱開發集，內部仍可分成訓練摺與驗證摺。
- 這是結構對稱的玩具資料，不刻意模擬不平衡、時間或群組相依。用於真實應用時需另外設計切分。

## 關鍵核對數值

- Filter k=1、RFE k=1、前向 k=1 都保留負債比；製造對應振動。Filter 分類三摺 AUC 為 1、1、1。
- 24 筆開發資料的 ANOVA：負債比分數 825，其他五欄均 0。選第二欄會碰到同分，不能視為額外訊號。
- 標準化後擬合連續損失，Lasso alpha=5 的係數為 0、0、96.4040、5.9599、0、7.6542。Ridge alpha=5 為 0.4479、0.4479、83.7717、8.8347、2.0016、8.6393。兩 API 的 alpha 尺度不同。
- 深度 2 的分類樹只用負債比，重要性向量為 0、0、1、0、0、0。
- LDA 圖用固定座標 `(income-50)/5` 及 `(debt_ratio-0.5)*20`，不是全資料估計的標準化。橫向 B=0、W=240、J=0；縱向 B=96、W=2.56、J=37.5。
- 授信 C01：月收入25、負債比0.38、標籤0、連續損失430；製造 M01：溫度25、振動3.8、標籤0、損失量43。
