# L23301-E：影像前處理與增強的共用例子

`L23301-E-images.json` 是教學合成資料，含製造瑕疵與零售 OCR 各 16 張固定的 8×8 RGB 影像。兩域共用索引、切分及種子 23301；沒有真實個資，不代表實際產線或 OCR 的影像分布。

承接 D2/L21102-C 與 D8/L23301-D 的教學方向；既有組沒有可直接沿用的影像資料檔，因此新建本組快照。L23301-B 的兩領域與固定索引原則延續，但其溫度與金額不是像素，不另拿來當本組數字。

用途僅限核對前處理、標籤變換與計數。32個來源ID只有7種不同像素陣列，其中4種跨切分重複；不同ID不代表獨立觀測，不能以本快照量測獨立泛化表現。

## 欄位與固定規則

- `pixels[y][x][c]`：高、寬、RGB 通道；整數範圍 0–255。原圖不覆寫，變換從原圖重新導出。
- `mask[y][x]`：0 背景、1 目標。`box` 為 `[xmin,ymin,xmax,ymax]`，零起算，右與下邊界不含；框包住所有目標像素。
- `class_label`：製造均為 scratch；零售前 8 張是 F、後 8 張是箭頭。`direction_label` 分別為 irrelevant、upright、right，僅為本例任務定義。
- `color_label`：偶數索引紅、奇數索引綠；只有要預測色別的任務才將它當標籤。
- `index`、`sample_id`、`group_id` 不因變換重編。每域索引 0–11 訓練、12–13 驗證、14–15 測試；變體繼承來源切分，不重新洗牌。
- M01 左上 2×2 的紅通道為 0、85、170、255；這四格不是瑕疵遮罩，僅供像素校準。

## 小例與參考數字

- 尺寸：從 M01 裁出 `[0,2,8,6]` 得到寬8、高4長方視圖，沒有裁掉瑕疵。直接變8×8的橫/縱比例為1與2；補邊上下各2列；中央取4×4再放大只留下4/8個原目標像素。
- 數值：四格除255是 0、1/3、2/3、1。固定教學均值0.5、標準差0.25後為 −2、−2/3、2/3、2；參數不是由全32張估計而來。
- 色彩：R01 紅字 `[255,0,0]` 灰階加權76.245，R02 綠字 `[0,130,0]` 為76.31，四捨五入都是76；HSV以角度與0–1表示時分別為(0,1,1)、(120,1,130/255)。圖中HSV各通道以灰深淺展示，不將HSV當RGB顯示。
- 幾何：M01框 `[1,2,3,6]` 水平翻轉為 `[5,2,7,6]`；遮罩8格保持8格。右半裁切 `[4,0,8,8]` 使目標剩0格，不得保留原來「有瑕疵」的分類標籤。
- 資料流：兩域共24訓練、4驗證、4測試來源。每個訓練原圖再加一個變體時為48次輸入，仍只有24個原始來源。
- 文字與音訊：「商品不容易故障」標籤為正面，否定詞移除會反轉為負面；同義改寫「商品不容易損壞」保留正面。音訊 `[0,0.4,-0.4,0]` 音量乘0.5成 `[0,0.2,-0.2,0]`；適用口令內容辨識前，仍須確認訊號可聽辨，不適用原音量判定。
